### EP01：世界開場（約 35 秒，冷開場第 1 場之前，取代「第一集沒有前情提要」）
只說「世界上每個人都知道的事」（`21` 第 3.1、4.1、5.1 節的表層認知），不碰任何真相：

> 九曜界，靠九條曜脈撐起天地。
> 曜脈流過的地方，草木生長，人與妖都在修行。
> 很久以前，大地上留下一道巨大的裂口和一片廢墟。人們叫它——天墟。
> 老人說，靠近它的地方，總會發生說不清的事。
> 天玄院，九州修行者的起點。
> 每一年，都有人走上那道山門。

畫面：九條光脈流過大地的俯瞰 → 遠方地平線上的巨大裂谷與廢墟（**天空保持乾淨**）→ 天玄院山門。之後接第 1 場（古林深處的狼群讓路）。
注意：天墟只講成「地上的裂口與廢墟」（`21` 第 3.1 節表層認知）；**天空裂痕留給第 13 場第一次出現**，否則角色會顯得比觀眾還不知情。

# 4. 世界生活設定（邏輯定案）

### 4.1 天玄院的「室」與住宿
- **宿舍男女分開**：男舍在東廊後院、女舍在西廊後院，入夜（宵禁鐘）後各回宿舍。
- **「室」是修行小組，不是寢室**：新生入院時四人編成一組，配一間「修習室」（小廳：矮桌、兵器架、方格窗），
  白天在這裡集合、上課前後討論、放兵器，晚上宵禁前也常待在這裡。修習室沿東廊排列，所以叫「東廊第七室」。
- **小組男女混編**是天玄院慣例（教官依流派互補編組，不看出身與性別）。
- 報到時執事給兩樣：小組（第七室）與宿舍床位。机遙先去第七室見組員，**行囊暫放修習室角落的兵器架旁**，傍晚才搬進男舍。
- **机遙是補錄、最後一個報到**：其他新生早幾天已入院編組，所以齊衡烈說「第七室最近正缺個能打的」★、陸鳴鸞說「那間吵死了」都說得通，也呼應他「考兩次」。

# 6. 第一季分集大綱

### EP01〈青嵐試煉〉（`43`，第 1 章）
世界開場旁白 → 冷開場：古林狼群讓路 → 片頭 → 入院、第七室報到（第八室陸鳴鸞先登場）→ 演武場（蕭曜霖、陸鳴鸞與齊衡烈互嗆、沈昭寧旁觀）
→ 修習室夜（宵禁前）→ 河谷：江祈璟與沈昭寧同組、阿黎嚮導、異化青牙狼、靈核 → 突破試煉 → 古林（阿黎「林子讓路的時候，就要跑」）
→ 陣眼殘響 → **赤瞳妖將先遣遭遇** → 裂口 → 撤回 → 院方議事廳（紀蘊之：「這不是第一次了」）→ 公告「局部曜脈震盪」→ 夜談 → 机遙的信。
章末鉤子：天空的裂痕。

### EP02〈青嵐異變〉（第 2 章，`26`）
前情提要 → 青嵐城連續異常（河谷靈流逆行、城內陣紋失效）→ 天玄院封鎖區 → 朽骨祭司線索 → 青嵐秘境 → 第八室組員在異化事件受傷，陸鳴鸞第一次害怕
→ **齊衡烈為了護住第八室組員出手失敗，組員受傷**——齊衡烈「保護同伴卻失敗」與陸鳴鸞第一次害怕合成同一件事
→ 厲若楓舊箭傷與隱瞞的家族情報曝光 → 聞人澈舊陣法事故被揭露 → 秘境核心：古代陣列不是單純遺跡 → 朽骨祭司撤退。
章末鉤子：有人在主動利用天墟異常；一枚古代陣紋指向青嵐之外；**「舊界」一詞第一次出現**（`21` 第 2 章結尾規定）。

### EP03〈裂谷回聲〉（第 3 章，`27`）
前情提要 → 青嵐裂谷的回聲 → 山脈異常生態 → 聯合演習：第七室奇襲打亂穿衡槍班，江祈璟失去第一名、沈昭寧第一個伸手
→ 古代陣列節點 → 斷陣裂王 → 聞人澈強開天幕護住全員【動畫補完】 → 回收陣列核心 → 靈府境突破。
（「聯合演習」為【動畫補完】，對應 `02` 江祈璟第 3 章弧線。）
章末鉤子：九州各地都有相似的節點——青嵐只是其中之一。第一季完。
