## 核心方向

- **引擎明確拍板：Unity（2022/2023 LTS）+ URP（通用渲染管線）**。因連線架構已定案採用
  Photon Fusion（主要支援 Unity 生態，Unreal 版生態成熟度差距明顯），引擎選擇實質已被
  連線決策間接鎖定，故此處正式明文定案，不再視為開放選項。
- URP 確保跨平台（PC/Mobile）光照、後處理與效能控管一致，並利於後續動態解析度、
  螢幕特效等擴充維持穩定幀率。
- 整體採模組化架構分離：渲染／戰鬥邏輯／連線同步／資產管理。技能樹、靈印效果、
  屬性克制表、BOSS機制腳本均用配置表下發（ScriptableObjects／JSON），降低改動成本、
  方便快速迭代與數值調整，呼應 CLAUDE.md 核心規則「資料驅動架構優先」。
- 客戶端效能：手機端實施 LOD 動態加載與資源熱更新機制，確保 50 人同屏戰鬥時幀率穩定。
- 邏輯驗證與防作弊：延續 01 已定案的伺服器權威（Server-Authoritative）原則，
  傷害計算、冷卻時間與物品交易一律由伺服器驗證，客戶端僅做預測與表現層演出。
