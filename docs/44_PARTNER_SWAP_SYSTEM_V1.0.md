# 《九曜：天墟》契友換手系統 V1.0

> 狀態：**設計定案候選**（2026-09-27）。數值全部為初版示意值，標記為「可調整」，需原型測試後校準。
> 產生緣由：咖哩裁定遊戲戰鬥參考《斗羅大陸：史萊克學院》的「切換職業時人物與技能一起換」，
> 以及「一次養很多個角色」的養成感。本文件把原本的**雙脈切換**（机遙一人帶兩種武器）改為**契友換手**
> （切換時換成另一位角色上場）。
> **取代範圍**：`03` 第 3 節雙脈切換規則、`20` 第 4 節宿命契友連攜技、`00` 第 7 節雙脈系統（`00` 為原始總綱不改字，以本文件為準）。
> 其他文件中「雙脈」「切脈」一詞，一律讀作本文件的「換手」。
> IP 原則：參考的是「換人＋多角色養成」的玩法結構，名詞、角色、系統細節全部原創，不使用斗羅系列專有名詞。

# 1. 系統總覽

戰鬥陣容由四種位置組成：

| 位置 | 人數 | 作用 |
|---|---|---|
| **主控：机遙** | 1 | 玩家本人。一個流派（開脈境突破時選定），穿全套裝備、掛 8 槽靈印 |
| **換手契友** | 1 | 第二脈。戰鬥中可隨時換上場，用他自己的流派與招式 |
| **助戰契友** | 0～2 | **僅限單人副本／劇情副本**，由 AI 控制在場協助。多人場景不開放（控制伺服器負擔） |
| **共鳴契友** | 其餘全部 | 不上場，依好感階段把自身屬性的一定比例轉給陣容（見第 4.4 節） |

同一時間**場上只有一名玩家可控角色**（机遙或換手契友）。星曜獸（`20` 第 1～3 節）不受影響，照原規則另開掛槽。

# 2. 換手規則（取代 `03` 第 3 節）

沿用原雙脈切換的節奏框架，只把「換武器」改成「換人」：

- **解鎖**：開脈境突破試煉完成後（第一章任務 05），與 `15` 的新手引導時點一致。
- **冷卻**：8 秒（沿用）。
- **代價**：消耗約 20 點靈力；切換瞬間約 0.4 秒硬直，可被閃避取消（沿用）。
- **限制**：受控制、硬直、破防狀態下不能換手（沿用）。
- **換手技**（合併原「切脈擊」與「羈絆連攜技」）：進場角色的第一擊固定為他的換手技，
  並獲得 3～4 秒流派增益（劍＋移速、重刃＋護盾……沿用 `03` 原設計）。
  六位契友的換手技沿用 `20` 第 4 節原連攜技名稱與效果：

| 契友 | 流派 | 換手技 |
|---|---|---|
| 郁岑燁 | 劍 | 霜劍破陣 |
| 厲若楓 | 弓 | 穿雲影矢 |
| 齊衡烈 | 刀 | 怒刃裂地 |
| 聞人澈 | 靈杖 | 澄息導流 |
| 蕭曜霖 | 重刃 | 山門壓影 |
| 江祈璟 | 槍 | 貫曜同鳴 |

  机遙換回場上時，也有一記依他流派決定的換手技（「歸位擊」，效果依流派，可調整）。
- **換手技強度**：隨該契友好感階段提升（沿用 `20` 第 4 節好感度分階）。
- **血量**：机遙與換手契友**各自有血量**。退場角色每秒回復最大生命約 2%（鼓勵輪替）。
  場上角色倒下時，若另一人還有血，自動換上並給 1.5 秒無敵；兩人都倒下才算戰敗。
- **同流派限制**：換手契友不能與机遙同流派（避免換了等於沒換）。
- **自動戰鬥**：全自動模式不換手（沿用 `03` 第 5 節第 4 條）；半自動模式由玩家手動換手
  （`01` 第 3 節表格中的「雙武器切換」即本機制）。
- **BOSS 極限爆發**：`09` 的「破綻觸發後 8 秒內完成一次雙脈切換」改為「完成一次換手」，數值不變。

# 3. 靈印（修訂 `04` 第 6 節的讀法，不改規則本身）

- 8 槽靈印掛在**陣容**上（由机遙裝配），換手契友上場時**同一套 8 槽照樣生效**。
- `04` 第 6 節「依當前啟用的脈重新計算」改讀為「**依當前在場角色的流派**重新計算」；
  其餘規則（不疊加、單脈限定、冷卻共用、連鎖限制、8 槽不翻倍）全部沿用。

# 4. 多角色養成（新增）

原則：**每位契友都值得養，但不要變成養五套完整角色**。机遙是完整養成，契友是精簡養成。

| 項目 | 机遙 | 契友（每人各自一條） |
|---|---|---|
| 境界 | 九大境界（`05`） | 有自己的境界，**上限不超過机遙目前境界** |
| 修為來源 | 戰鬥、任務、修行 | 「契友心得」（主線、支線、日常、羈絆事件產出）；上場戰鬥也會累積少量 |
| 屬性點 | 手動分配（`05` 第 2 節） | **自動分配**，依角色個性模板（例：齊衡烈偏力量、厲若楓偏敏捷），減少操作負擔 |
| 技能 | 自選流派技能 | 固定流派技能＋換手技，用契友心得升級 |
| 裝備 | 8 槽（`10`） | **2 格「信物」**：契友專屬裝備，來自他的個人支線與好感事件（例：郁岑燁的家族斷劍碎片、厲若楓的舊箭簇） |
| 武器 | 一般裝備 | 契友本命武器，隨好感階段突破外觀與基礎攻擊 |
| 靈印 | 8 槽（陣容共用） | 不另掛（共用陣容 8 槽） |

## 4.4 共鳴（對應「庇護」概念，原創設計）

- 未上場、未助戰的契友，依好感階段把自身基礎屬性的 **3%～10%** 轉為陣容加成。
- 目的：讓「每個人都養一點」有回報，而不是只養一位換手契友。
- 上限：共鳴總加成設封頂（示意：不超過机遙基礎屬性的 25%），避免囤角色堆戰力。

## 4.5 經濟掛鉤（沿用 `20` 第 5 節與 `14` 雙幣制）

- 契友心得、信物強化以**靈砥**（綁定）為主要消耗。
- 曜金只用於外觀與部分加速，設每日／每週上限，**不能直購契友或契友境界**。

# 5. 契友解鎖進度（依正史劇情）

| 契友 | 解鎖時點 | 劇情理由 |
|---|---|---|
| 郁岑燁、厲若楓、齊衡烈 | 第一章任務 05 開脈境突破後 | 第七室舍友，突破後開始並肩訓練 |
| 聞人澈 | 第一章任務 14 夜談後 | 正式進入第七室朋友圈 |
| 江祈璟 | 第三章章末 | 由競爭者轉為臨時合作（`21` 第 12 節江祈璟弧線） |
| 蕭曜霖 | 九州篇（第四章後，時點可調整） | 教官身分特殊，限定條件下「壓境相助」：換手時境界自動壓到机遙同階（可調整） |

- **劇情立場不變**：換手是戰鬥中的羈絆能力，不代表契友加入机遙的隊伍或服從机遙。
  六人主線立場仍然獨立（修訂 `34` 第七節）。
- **多人遊戲的讀法**：每位玩家都是自己故事裡的机遙，身邊的契友是自己的羈絆。
  多人場景中別的玩家也能換上齊衡烈，屬於 MMO 的常見抽象，劇情副本內則只出現一位。

# 7. 技術與美術影響（誠實揭露）

- **程式**：Phase 0-B 已做好六種武器的招式循環，契友直接沿用自己流派的招式；換手在技術上接近現有的武器切換，
  多了「換角色模型＋各自血量」。Phase 0 範圍不變，換手仍排在 Phase 2（`19`）。
- **美術（主要成本）**：六位契友原本只需要劇情 NPC 規格，現在要**可操作角色規格**的完整戰鬥動作組。
  這是本設計最大的成本增加，排程時要算進去。
- **平衡**：机遙只有一個流派，六位契友各鎖一種流派；玩家的流派選擇會影響「換誰最順」，這是預期中的 Build 深度。
