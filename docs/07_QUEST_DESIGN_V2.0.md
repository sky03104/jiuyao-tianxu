# 一、第一章：青嵐篇／《青嵐試煉》（任務級詳細）

## 章節目標

- 教玩家戰鬥（雙搖桿/普攻/技能/閃避/氣力）。
- 建立舍友關係（郁岑燁/厲若楓/齊衡烈/聞人澈）與競爭關係（江祈璟）。
- 完成玩家第一次境界突破（鍛骨境→開脈境），建立「境界＝地圖權限」的核心認知
  （呼應06已定案境界硬性屏障）。
- 第一次接觸天墟線索與異化妖獸，但不揭露最終真相。

## 主線起點與結束

起點：玩家通過入門考核成為「青嵐新契修」，進入天玄院東廊第七室。
結束：天空出現短暫裂痕，天玄院官方說法是「局部曜脈震盪」，玩家知道那不是普通震盪。

## 地圖解鎖（本章內完成）

天玄院/城門區/主街/河谷（鍛骨境起始可去）→ 骨脈相應突破試煉 → 開脈境 →
取得青嵐古林通行印記 → 青嵐古林（呼應06已定案：開脈境完成突破試煉後解鎖古林）。

## 系統首次解鎖節點

- 第1節點：戰鬥基礎教學（移動/普攻/技能/閃避/氣力管理）。
- 第3節點：突破試煉系統首次使用（呼應05已定案）。
- 第4節點：靈印系統首次獲得（突破獎勵，非完整8槽，僅開放前3槽）。
- 第7節點：裝備系統首次替換（古林掉落的裝備配方）。
- 支線任務起：好感度系統首次累積（呼應07v1與20已定案的好感度解鎖夥伴連攜技前置）。

# 二、第二章：青嵐異變（章節骨架）

## 核心主題

「問題不是妖獸變強了，而是有人知道它為什麼變強。」（呼應21已定案）

## 第一章事件如何造成後續影響

裂口事件後，天玄院官方說法與玩家親眼所見不一致，玩家開始主動追查真相，
而非被動接任務。

## 玩家下一個主要目的

追查「陣眼血光」與「裂口」背後的關聯，深入古林尚未清剿的區域，並首次接觸
星河殿留存在天玄院的曜脈資料。

## 新區域／新勢力／新問題

- 區域：青嵐秘境（呼應06已定案Instance秘境，作為本章重點副本，非新增地圖）。
- 勢力：星河殿資料首次登場（呼應00/21已定案勢力設定，非新增勢力）。
- 問題：異化並非獨立事件，不同區域指向同一種「回流現象」。

## 主要NPC關係推進

- 郁岑燁：從追求個人完美轉向團隊信任。
- 厲若楓：家族舊傷與過去任務曝光，開始懷疑有人刻意隱瞞情報。
- 齊衡烈：因保護同伴而失敗，理解「力量不等於保護能力」。
- 聞人澈：揭露過去法陣事故（呼應第一章「陣眼殘響」節點鋪的伏筆），說明他害怕
  大型陣法的原因。
- 江祈璟：真正把玩家視為競爭者，而不是拖後腿的新生。

## 墟息／天墟真相再揭露一層

玩家第一次聽見被天玄院高層刻意迴避的詞——「舊界」，但仍不知道舊界就是天墟
真正來源（呼應21已定案真相揭露節奏表）。

## 主要敵人／BOSS

**朽骨祭司**（呼應09已定案完整機制：召喚型・殘魂封域，三階段），設定為青嵐秘境
本章重點副本BOSS，呼應第一章「陣眼核心・精英前哨」出現過的朽骨祭司同源個體
的加強版/首領。

## 玩家境界與系統成長方向

維持開脈境，本章重點是「橫向養成」（裝備配方/靈印槽位擴充/生活系統解鎖），
不進行新的境界突破——境界突破留給第三章往靈府境推進，避免每章都塞一次突破試煉
造成節奏疲乏。

## 章末事件
