## 一、本機製作環境檢查結果（2026-09-20）

| 項目 | 結果 |
|---|---|
| GPU | NVIDIA GeForce GTX 1660 Ti，6GB VRAM |
| 驅動 / CUDA | Driver 596.49，CUDA 13.2（僅 driver 層，未裝 CUDA Toolkit，PyTorch 自帶 runtime 不需要另裝） |
| Python | 3.14.6（torch 2.14.0 已確認有對應 wheel） |
| PyTorch | 製作開始時未安裝，本次流程中安裝 |
| FFmpeg | 8.1.2 full build，含 NVENC / CUDA / libx264 / libx265，可用 |
| ComfyUI | 製作開始時不存在，本次流程 clone 到 `tools/ComfyUI/` |
| 既有角色/場景 Reference | 無，本次從零開始 |
| 磁碟空間（D槽） | 約 616GB 可用，足夠 |

**VRAM 限制評估**：6GB VRAM 對 SDXL 靜態圖生成可行（需用低顯存最佳化選項），但對主流影片擴散模型（如 SVD、CogVideoX、Wan2.1 等）非常吃緊，多數需要 8GB 以上才能穩定跑，之後會實測回報，不先假設能跑或不能跑。
