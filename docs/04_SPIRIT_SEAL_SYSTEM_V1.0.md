# 《九曜：天墟》靈印系統 V1.0

> 狀態：**細節定案（第二階段補完）**，具體數值為初版示意值，需 Phase 0 原型測試後調整，
> 標記為「可調整」。
> 產生方式：GPT/Gemini/DeepSeek 三方交叉草擬 → Claude審查抓到兩個錯誤：
> 1) 模型擅自發明不存在的境界名稱對應槽位解鎖，違反「不要擅自改變核心世界觀」規則；
> 2) 其中一版把雙脈設計成各自獨立8槽（等於偷偷變成16槽），與已定案的「8槽位」總量衝突。
> 三方修正後統一用已定案的9大境界名稱、確認角色共用固定8槽，定案。

## 1. 8槽位解鎖節點對照表

角色全系統共用固定 **8個靈印槽位**，依已定案的9大修行境界逐步解鎖：

| 修行境界（9階） | 累計解鎖槽位 | 備註 |
|---|---:|---|
| 鍛骨境（第1階） | 0 | 靈印系統尚未開啟 |
| **開脈境（第2階）** | **2** | 開放基礎靈印裝備 |
| **靈府境（第3階）** | **4** | 開放低階靈印融煉功能 |
| **天罡境（第4階）** | **5** | 觸發判定強化 |
| **神藏境（第5階）** | **6** | 可承載更高品質靈印 |
| **領域境（第6階）** | **8（全開）** | 8槽全開，解鎖連鎖組合機制 |
| 聖域境（第7階） | 8（不再開新槽） | 提升靈印品質上限與強化等級上限 |
| 天門境（第8階） | 8（不再開新槽） | 提升融煉成功率與稀有子效果上限 |
| 曜神境（第9階，最終） | 8（不再開新槽） | 提升子效果強度與觸發穩定性 |

（領域境為第6階，非最終境界；曜神境才是第9階/最終境界。領域境之後三個境界不再新增槽位，
改為強化槽位品質與觸發穩定性，避免高境界玩家戰力純靠堆槽位數量碾壓。）

## 2. 靈印稀有度分級

- **黃階（凡）**：基礎倍率1.0x，僅基礎數值與機率觸發效果。
- **玄階（靈）**：倍率1.5x，附帶1項被動機制改變。
- **地階（極）**：倍率2.2x，附帶1項主動/條件觸發技能變異。
- **天階（聖）**：倍率3.2x，可改變技能判定型態、解鎖終極連鎖，且悟性加成下效果翻倍。

## 3. 靈核融煉升階邏輯

- **升階（升品質）**：消耗3個同名同階靈印 + 天曜靈液，採「3合1」保底邏輯，100%成功晉升下一階。
- **升級（強化）**：消耗靈核精粹（分解多餘靈印取得），提升靈印等級（上限為當前境界×10）。
- **同屬性共鳴**：裝備2/4/6個同屬性靈印時觸發疊加效果（如2件+15%該屬性傷害/抗性，
  4件加快異常累積速度，6件縮短該屬性連鎖冷卻）。

## 4. 靈印範例（8個）

1. **赤炎（攻/火）**：命中造成火傷，可疊加2層燃燒（每層+8%後續火傷）。
2. **玄甲（防）**：受擊生成護盾，按已損HP比例回補；完美閃避成功後立即強化（持續4秒）。
3. **影遁（位移）**：短距瞬移並降低自身被命中判定；技能消耗後可觸發（每6秒一次）。
4. **疾風（加速）**：提升移速與施法/出招速度；連續移動後疊加「風勢」，下次攻擊必帶增傷。
5. **幻月（控制）**：對高魔力目標造成沉默/幻覺，使其短暫失去鎖定能力。
6. **雷鳴（爆發）**：絕技能量達50時發動重擊，召喚落雷造成大範圍雷屬性傷害。
7. **霜華（控制/冰，新增）**：完美閃避或招架成功時，以玩家為中心釋放霜環，凍結周圍敵人。
8. **碎金（破防/金，新增）**：破防值達上限時，額外造成真實傷害並延長受擊硬直。

## 5. 連鎖組合範例（3組）

**組合A：風助火勢（赤炎+疾風）**
- 觸發判定：目標帶有「燃燒」狀態，且玩家自身「風勢」≥2層，此時使用範圍流派招式命中該目標。
- 效果：引爆燃燒，轉化為擴散風暴，對範圍內敵人造成一次高倍率雙屬性爆裂傷害，並直接刷滿3層燃燒。
- 冷卻：組合共享6秒。

**組合B：刺客瞬殺（影遁+雷鳴）**
- 觸發判定：完美閃避觸發影遁隱身後，隱身期間內對同一目標完成首次命中，且絕技能量≥50。
- 效果：命中瞬間雷鳴蓄能層+1；蓄能層≥2立即觸發「雷爆瞬殺」高優先級單次爆發。
- 冷卻：8秒；被打斷或命中失敗則本次連鎖作廢。

**組合C：霜月封牢（霜華+幻月）**
- 觸發判定：完美閃避觸發霜華凍結後，2秒內對被凍結目標釋放消耗MP的流派技能（觸發幻月）。
- 效果：凍結時間延長至3.5秒，並轉化為「絕對冰封」（無法被傷害打斷凍結），解除瞬間造成
  相當於凍結期間所受總傷害40%的二次結算傷害。
- 冷卻：10秒。

## 6. 靈印與雙脈互動規則

- **共用固定8槽**：角色只有一套共用的8個靈印槽位，不因雙脈切換而變成兩套（不會變成16槽）。
- **動態重新加權**：槽位裡的靈印本體、品質、主效果固定於槽位，不隨切脈複製；但**子效果、
  觸發判定、傷害/治療/護盾與資源消耗，一律依「當前啟用的脈」重新計算**（例如赤炎在攻脈下
  燃燒疊加上限更高，在防脈下轉化為減傷燃燒）。
- **不疊加**：若靈印同時具備雙脈子效果，切脈時只切換為當前脈版本，另一脈版本休眠，
  不並存、不雙觸發，避免雙脈變相把效果量翻倍。
- **單脈限定靈印**：若靈印只適配單一脈，錯脈時僅保留通用主效果，子效果休眠。
- **冷卻共用**：靈印冷卻按槽位共用計算，切脈不刷新冷卻；切脈本身另有短冷卻（銜接
  `03_COMBAT_SYSTEM` 已定案的雙脈切換規則），防止瞬間雙重觸發。
- **連鎖限制**：連鎖組合以當前脈判定，同一觸發窗口只算一套，8槽總量與觸發上限不因雙脈翻倍。
