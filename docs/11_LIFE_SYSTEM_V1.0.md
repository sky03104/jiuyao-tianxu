## 1. 七種生活玩法具體操作機制

1. **釣魚**：浮標張力平衡型QTE。拋竿後等待魚咬鉤，進入弧形張力條，需按住/放開按鍵讓
   游標維持在安全區，過緊斷線、過鬆魚逃；起竿瞬間需完成一次時機判定QTE取得額外產量。
2. **採礦**：精準弱點打擊。礦石表面隨機浮現3個靈脈弱點光圈，需在光圈縮至最小瞬間點擊，
   全中觸發「礦脈爆裂」，掉落額外稀有副產物。
3. **採藥**：靈氣連線解謎。藥草觸發3x3靈脈微型盤面，需在時限內一筆畫連通相同屬性的
   靈氣節點，連通純度越高，藥材品質與數量越高。
4. **採集**：蓄力判定與伐材/剪裁。針對樹木與植被，操作蓄力條，在「完美臨界點」釋放
   工具，提供裝備鍛造輔材與宿舍裝修所需的木材與織物。
5. **烹飪**：多段式節奏掌控。分「切配（節奏按鍵）」與「控火（滑塊維持指定溫度區間）」
   兩階段，最終評分（S/A/B）決定菜餚增益數值與持續時間。
6. **煉丹**：火候滑塊與投藥順序。需依丹方順序放入藥材，並透過滑塊將鼎爐溫度維持在
   指定區間N秒，順序錯誤會使抗性轉為雜質，甚至「爆丹」產生廢渣。
7. **鍛造**：節奏敲擊與合金配比。選擇基礎胚模後，進行3次打鐵QTE決定基礎屬性浮動，
   再調配合金比例決定詞條出現機率與品質上限。

## 2. 生活等級與熟練度設計

- **生活等級體系**：生活等級（Lv.1~50），全生活玩法通用等級；各玩法另有獨立「熟練度」
  影響單項效率。
- **境界銜接**（呼應05已定案的9大境界，不新增境界名稱）：生活等級上限受玩家當前修行
  境界限制，例如開脈境上限Lv.10、靈府境上限Lv.20，依此類推逐步隨境界推進解封，
  避免生活系統完全獨立於主線成長節奏之外。
- **升級機制**：完成對應採集/製作獲得熟練度經驗；製作高於當前熟練度等級的目標物品，
  經驗獲取效率最高；持續生產已熟練的低階物品，經驗獲取遞減至趨近於0，鼓勵持續挑戰
  更高階配方而非重複刷取。

## 4. 生活製作與10裝備系統／04靈印系統的銜接規則

- **與10裝備系統銜接（曜印契片）**：鍛造可將生活產物加工為「曜印契片」（凡/精/曜三級），
  在裝備強化或洗鍊前使用，可鎖定該次操作的詞條屬性池方向，契片品質越高，鎖定精準度
  與強化成功率加成越高；鍛造同時產出強化所需的靈砥/曜金加工料。
- **與04靈印系統銜接（靈核精粹）**：採礦/採藥/採集/煉丹分別產出偏向不同效果傾向的
  「靈核精粹」（偏攻防/偏抗性/偏機制觸發/偏境界相容度），玩家融煉04已定案的8槽靈印時，
  需搭配「對應槽位屬性的精粹＋基礎靈核」；精粹類型不匹配時可用重鑄轉換，但會降低
  融煉成功率，藉此讓高階生活玩家的精粹產出成為市場搶手貨。

## 5. 生活玩法的社交/經濟價值（呼應14已定案雙幣制）

1. **高難副本藥材供應商**：煉丹產出的高階抗性藥與突破引藥，作為曜金導向的高價值商品，
   稀有度越高越依賴可交易高階幣流通。
2. **裝備成形效率販售**：鍛造契片與精粹是10/04系統的效率關鍵材料，形成穩定的曜金
   交易需求，同時搭配靈砥的日常穩定供給，形成雙軌資源流。
3. **宴會社交製作方**：烹飪高評分菜餚可製成「宴會Buff票」，在公會/組隊活動中提供團隊
   增益，定價可混合靈砥（材料成本）與曜金（稀有宴會Buff/專屬外觀）。
4. **獨佔外觀與熱門商品**：釣魚/烹飪/煉丹/鍛造達特定等級可解鎖專屬生活外觀
   （魚具、藥爐、廚具、鍛造工具與可展示裝飾），高等級生活玩家藉由稀有食材/藥材
   封裝品與獨佔外觀在拍賣場形成穩定商業模式，讓生活玩法成為與戰鬥並行的經濟支柱。
