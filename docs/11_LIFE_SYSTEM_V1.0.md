## 核心方向

7 種生活玩法（釣魚/採礦/採藥/採集/烹飪/煉丹/鍛造）須直接餵入戰鬥循環與經濟系統，避免變成
純打卡機制：

- **採礦/採集**：提供裝備鍛造與宿舍裝修材料。
- **採藥/釣魚**：提供煉丹/烹飪原料。
- **煉丹**：產出高難副本必備的抗性 Buff 藥與境界突破引藥。
- **烹飪**：產出階段型增益（如探索期移速、戰鬥期抗性）與社交宴會 Buff。
- **鍛造**：與裝備詞條綁定，讓生活玩家可製作稀有外觀與交易熱門商品。

生活產物是境界突破與戰鬥消耗的高需求品，高等級生活玩家可製作獨佔外觀與交易行熱門商品，
讓生活玩法成為獨立且有收益的成長途徑，而非附屬打卡活動。
