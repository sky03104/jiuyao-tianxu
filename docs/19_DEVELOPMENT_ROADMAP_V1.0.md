# 《九曜：天墟》開發路線圖 V1.0

> 狀態：**大綱級定案**，核心方向已鎖定，具體週期與人力排程待第二階段補完，標記為「可調整」。

## 核心方向

- **Phase 0（企劃/原型驗證）**：完成核心企劃、引擎框架搭建、戰鬥雙搖桿與6流派原型驗證，
  產出可玩的最小垂直切片（青嵐河谷小地圖 + 1小型BOSS）。
- **Phase 1（青嵐城 Vertical Slice）**：打通連線、任務主線到第一個世界事件體感、
  三流派代表角色與一個副本流程；商業化資料通路先跑（Battle Pass/月卡不依賴抽卡）。
- **Phase 2（第一章完整青嵐地區）**：補足主線分章、全部怪物類別與異化伏筆、
  雙脈切換、50人副本、至少2個世界事件/3秘境入口；生活系統全部可用但深度逐步開放。
- **Phase 3（MMO核心：公會/PVP/交易）**：加入公會系統、交易/資源池規則、PVP模式與結算，
  天墟終局地圖開放，全平台封測與公測上線。
- 時間軸以「每期至少1個可迭代的內容垂直切片」為節點，而非固定月數；
  每個 Phase 收尾前需回頭核對 01 決策文件的成本門檻與連線壓力測試結果是否仍然成立。
