# 一、第三章動畫定位

## 核心主題
**「天墟不是在入侵我們，它可能正在回到它原本的位置。」**

第三章是青嵐篇終章。
它不能直接給答案，而要讓觀眾第一次看到足以改變世界認知的影像證據：

> **裂谷另一側存在一個不應該存在於當代地圖上的古老世界景象。**

## 本章必須完成
- 青嵐山脈。
- 裂谷回聲。
- 山脈異常生態。
- 古代陣列節點。
- 江祈璟暫時合作。
- 斷陣裂王。
- 靈府避瘴印。
- 開脈境→靈府境。
- 九州其他節點證據。
- 裂谷彼端舊世界景象。
- 青嵐篇正式收束。

## 嚴格禁止
- 說明天墟就是舊界。
- 說明古代切離原因。
- 解釋回流完整機制。
- 解釋赤瞳妖將。
- 完整介紹妖族。
- 讓江祈璟永久加入主隊。
- 讓玩家成為預言中的救世主。

# 十五、第三章聲音與剪輯規格

## EP01～EP04
- 山風、石壁回音、低頻脈動。
- 回聲固定為三次循環，建立章節聲音識別。

## EP05～EP07
- 江祈璟出現時不使用反派音樂。
- Boss戰不使用傳統怪獸吼叫作唯一威脅；更多使用岩石裂動、陣紋震鳴、低頻崩解。

## EP08
突破音樂應從壓迫轉為穩定，不做「神力覺醒」。

## EP09
「舊界」出現時，音樂短暫抽空。

## EP10
彼端景象出現時不要使用勝利 BGM。
應使用極安靜、陌生、帶有遠距離風聲的音場。
九道曜光出現後，只留一個低頻長音，立即切黑。
