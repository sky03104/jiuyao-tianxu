# 《九曜：天墟》裝備系統 V1.0

> 狀態：**大綱級定案**，核心方向已鎖定，裝備數值表待第二階段補完，標記為「可調整」。

## 核心方向

- 裝備與靈印明確分工，不重疊：
  - **裝備**（武器/防具/飾品）：負責基礎數值與面板屬性（力量/身法/體魄等）、武器型態與招式
    變化（對應6大流派外觀與連段差異），以及流派/被動情境增幅（如對抗特定屬性的抗性）。
  - **靈印**：負責機制效果、技能變異與主動/被動特技（控場、位移後隱身、屬性爆發等），
    決定 Build 的戰鬥風格。
- 裝備強化不直接提升境界上限，只提升「當前境界可用效率」（如靈印槽效果上限、特定技能冷卻），
  避免裝備與境界成長曲線衝突。
- 掉落層級對應地圖深度：青嵐城先給低階詞條，高階詞條集中在後續秘境/荒境妖庭，維持養成曲線。
- 裝備詞條與靈印機制型技能嚴禁混淆——裝備絕不出售或產出帶有機制型技能的詞條。
