# 《九曜：天墟》裝備系統 V1.0

> 狀態：**細節定案（第二階段補完）**，具體數值為初版示意值，需 Phase 0 原型測試後調整，
> 標記為「可調整」。
> 產生方式：GPT/Gemini/DeepSeek 三方交叉草擬（槽位數量分歧8/10/10）→ Claude審查無跨題
> 規則衝突，採用Gemini的8槽版本（呼應04靈印8槽、手機UI精簡）與獨立於靈印的品質命名。

## 1. 裝備部位與槽位設計（共8槽，呼應靈印8槽）

1. **武器槽（1個）**：對應當前武器流派（刀/劍/槍/弓/重刃/靈杖擇一），決定基礎普攻/
   重擊模組、攻擊範圍與面板物魔攻。
2. **防具槽（4個）**：頭盔、胸甲、護手、腿甲。提供基礎防禦、生命值與韌性。
3. **飾品槽（3個）**：項鍊、戒指×2。提供6大屬性加成與情境增幅。

## 2. 裝備品質分級（5級，獨立於04靈印的黃玄地天聖命名）

| 品質 | 顏色 | 副詞條數 |
|---|---|---|
| 凡品 | 白 | 0 |
| 精品 | 綠 | 1 |
| 靈品 | 藍 | 2 |
| 曜品 | 紫 | 3 |
| 帝品 | 金 | 4（必含1條高階情境增幅） |

品質越高，可洗鍊次數、強化等級上限越高。

## 3. 裝備詞條設計邏輯

- **主詞條（固定1條，依部位決定）**：
  - 武器：基礎攻擊力 + 對應流派武技傷害加成。
  - 防具：基礎防禦力/生命值/元素抗性。
  - 飾品：直接分配至6大屬性（力量/身法/體魄/靈元/元神/悟性）任一項。
- **副詞條（隨品質0~4條，隨機池）**：基礎面板數值（攻擊/防禦/生命/速度/暴擊率/暴擊傷害）
  與情境增幅（對流血目標傷害+%、破防狀態下傷害+%、生命高於70%時減傷+% 等）。
- **流派情境增幅**（允許存在，但僅限數值倍率，嚴禁機制型技能詞條）：
  如「刀法傷害+%」「槍勢獲取+%」「靈杖耗靈-%」，只做數值增幅，不改變技能行為邏輯，
  技能變異與機制觸發一律專屬04靈印系統。

## 4. 強化系統

- 強化等級：+0 → +15。
- 消耗材料：靈砥（綁定日常幣）+ 對應境界礦石/靈晶；高階強化（+11以上）額外需要曜金
  （可交易高階幣）投入保底加速。
- 成功率：+1~+5必成；+6~+10逐步下降（示意80%→50%）；+11~+15顯著下降（示意40%→15%）。
- **保底機制**：連續失敗累積「幸運值」，每次失敗+10%，滿100%下次必成；
  同件裝備每5次失敗必成功一次，成功後歸零。
- **失敗懲罰**：不降品質、不掉等級、不損毀裝備，僅消耗材料（保護玩家養成體驗，
  懲罰只影響資源效率而非清空進度）。

## 5. 洗鍊與重鑄系統

- **洗鍊（重洗副詞條數值）**：消耗洗鍊石+靈砥，只重洗數值大小，不改變詞條種類；
  可選擇鎖定1~2條滿意詞條，僅重洗其餘未鎖定詞條（鎖定數量越多消耗越高，且需消耗曜金）。
- **重鑄（重抽副詞條種類）**：消耗更高階材料+曜金，隨機重抽全部副詞條的種類與數值；
  主詞條類型固定不可重鑄。
- 兩者皆有每日/每週次數上限或材料門檻，避免高頻率無限重刷破壞經濟平衡。

## 6. 裝備取得管道對應境界（呼應05境界壓制機制）

- **裝備配戴設有境界門檻**：若玩家境界低於裝備建議境界，裝備面板數值會被壓制到
  「當前境界可用效率上限」（例如效率封頂在80~120%區間，隨強化等級微調），
  **不會突破05已定案的境界壓制上限**，避免裝備等級差距繞過境界壓制機制。
- **穩定取得管道**（依地圖深度）：
  - 鍛骨境~靈府境（1~3階）：淺層野外與日常副本，主產凡品~靈品，穩定產出靈砥。
  - 天罡境~領域境（4~6階）：中層天墟遺跡/精英秘境，主產靈品~曜品，開始產出曜金。
  - 聖域境~曜神境（7~9階）：深層禁地、世界BOSS與高階團隊副本，主產曜品~帝品，
    帝品裝備僅在終局內容穩定產出。
- 每個境界段至少提供2種穩定取得管道（日常商店兌換/試煉禮盒/深層掉落擇一即可），
  避免完全依賴純機率刷取。
