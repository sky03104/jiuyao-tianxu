## 1. 好友系統具體機制

- **好友關係**：雙方互相邀請確認後建立，好友上限100人（可隨學宮聲望提升至120）。
- **友誼值**：0~300，分三階段「初識/常伴/摯友」（0/100/250），影響互動上限與助戰效果強度。
- **提升管道**：每日問候+2、贈送生活素材+5、同隊完成副本+3、被助戰成功+2；
  單日好友互動總量另設每日上限，避免無腦刷關係。
- **好友互動項目**（不觸及付費抽卡資源）：
  - 贈禮：僅限生活素材、低階（1~2階）靈印碎片，採「等價互換箱」機制，雙方各自放入
    指定品階素材確認後才發送，防止單方面詐騙或異常轉移。
  - 好友商店：以友誼值兌換社交外觀與素材，不涉及高階或付費資源。
  - 生產協助：可赴好友宿舍進行「靈氣灌注」，為其煉丹/鍛造縮短時間（每日上限次數）。
  - 拜訪宿舍：好友宿舍互訪，可能觸發連動NPC事件（見第4節）。

## 2. 組隊助戰・助力印記具體規則

- **取得方式**：好友設定「助戰角色」（帶入當前裝備與靈印快照），隊伍中含達到一定友誼值
  的好友，或直接借用助戰角色時自動生成「助力印記」，24小時更新一次快照。
- **降低失敗懲罰**：
  - 印記使用後，副本挑戰失敗或中途撤離時，資源/體力返還比例依友誼階段遞增：
    初識30%、常伴50%、摯友70%（不提供成功獎勵，僅降低失敗損耗）。
  - 裝備耐久損失同步減免，降低嘗試高難內容的心理門檻。
- **防濫用機制**：
  - 每日可借用助力印記次數上限（如3次），且需好友關係滿一定天數（如3天）才生效。
  - 終局高難內容（公會裂隙封印戰、領地演武、高階突破試煉）**禁止使用助戰角色/助力印記**，
    確保頂級內容仍需真人隊伍實力。
  - 同帳號/IP/模擬器多開重複借用不計入效果，防止小號互刷。

## 3. 院內名冊・Build配對系統具體設計

- **記錄內容**：系統自動擷取玩家當前主戰Build摘要——武器流派、核心屬性傾向、
  關鍵靈印連鎖組合、擅長機制（破防/控場/輸出/生存），以「標籤」呈現（最多8個標籤）。
- **展示方式**：分「公開摘要」與「詳細檔案」，公開摘要預設可見（供公會/配對快速判斷），
  詳細檔案可設定僅好友/公會/私密可見。
- **匹配應用**：
  - 公會任務/裂隙封印戰排隊時，系統依「隊伍現有流派缺口」優先推薦互補標籤的成員
    （呼應05已定案的隊伍配置多樣化加成）。
  - 玩家可自訂「招募條件」（如缺弓/需破防/需控場），系統依名冊標籤精準媒合。
  - 公會可對照裂隙封印戰所需的破招流派，精準向名冊中符合戰鬥風格的線上玩家推播邀請。

## 4. 與07已定案角色支線/好感度系統的整合

- **雙層獨立、聯動不互轉**：
  - **NPC好感度**（07已定案）：玩家與天玄院NPC（郁岑燁/厲若楓/齊衡烈/聞人澈/蕭曜霖/
    江祈璟）的單向關係，只影響支線解鎖、專屬外觀與人物劇情，不影響玩家友誼值。
  - **玩家好友友誼值**（本系統）：僅在玩家與玩家之間生效，影響好友商店、互贈與助戰效果。
- **不互相兌換**：NPC好感度不能提升好友商店額度，好友互贈也不能加速NPC支線解鎖，
  避免兩套資源互相稀釋設計初衷。
- **聯動彩蛋**：好友宿舍拜訪時，若好友對某NPC好感度已達上限，拜訪者可在該好友宿舍
  觸發專屬客座事件並獲得短期加成，作為社交系統與角色劇情的唯一聯動點，僅為體驗設計，
  不產生跨系統的數值套利。

## 5. 安全區與戰鬥區聊天分流具體規則

- **安全區**（青嵐城8子區域內的城鎮部分、宿舍、公會領地）：全頻道開放
  （世界/區域/公會/隊伍/私聊），支援文字、語音、貼圖與裝備/靈印展示連結。
- **戰鬥區**（副本、天墟裂谷野戰、領地演武）：世界頻道與區域頻道自動靜音收合，
  僅保留隊伍/小隊頻道、公會指揮頻道與私聊（私聊訊息預設延遲顯示或需手動展開，
  避免分心）；額外提供「戰術快捷輪盤」（8向常用指令），低延遲同步隊友，減少手動打字。
- **切換規則**：進入戰鬥區時自動記憶安全區頻道設定，離開戰鬥區/撤離返回安全區後自動
  還原先前頻道狀態；助戰/公會相關系統通知走獨立通知欄，不佔用戰鬥聊天頻道版面。
