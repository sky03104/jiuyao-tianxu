# 《九曜：天墟》社交系統 V1.0

> 狀態：**大綱級定案**，核心方向已鎖定，細節機制待第二階段補完，標記為「可調整」。

## 核心方向

除宿舍系統外，社交機制以「能直接提升戰鬥/養成效率」為主，避免淪為純裝飾社交：

- **組隊/助戰**：好友可為對方的世界BOSS或試煉提供「助力印記」，降低失敗懲罰或提升異化
  靈核掉落率（非強制返利）。
- **同道結伴**：雙人同行野外/搭檔戰鬥可獲得經驗與親密度加成，親密度解鎖專屬外觀與稱謂。
- **師徒傳承**：高境界玩家可帶領新契修通過突破試煉，獲得專屬外觀貨幣，促進老玩家與新玩家
  互動、加速新人成長曲線。
- **院內同修圈**：天玄院社交圈可記錄靈印 Build 偏好，協助匹配公會任務與副本隊友。
- 即時語音/貼圖等輕度社交功能兼顧休閒（宿舍派對、釣魚大賽）與重度團戰的不同需求場景。
