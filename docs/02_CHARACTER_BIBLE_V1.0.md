# 《九曜：天墟》角色設定聖經 V1.0

> 文件用途：定義玩家角色身份框架，以及第一批（青嵐城 Vertical Slice）登場的核心 NPC 角色。
> 狀態：**設計方向已定，人物細節與劇情弧線隨後續章節內容持續擴充，標記為「可調整」。**
> 產生方式：GPT 起草 → Claude 審查提出修正（六大武器流派覆蓋缺口）→ GPT／Gemini／DeepSeek
> 交叉討論收斂，採用「新增編外角色補流派缺口」而非「置換既有角色」的方案。

---

## 1. 玩家角色身份框架

- **統一稱謂：「青嵐新契修」**——天玄院對所有剛通過入門考核、尚未確立雙脈方向的新人修行者的統一稱呼。
  「契」指玩家首次覺醒武意／曜脈契點這件事。
- **院內定位**：非貴胄、非世家嫡系的入門考核通過者，起點公平，靠修行/戰鬥/任務/探索逐步成長。
- **外界看法**：青嵐城內人族稱新契修為「新芽」；資深修行者評價則是「能打、但還在長」——
  沒有天生救世主光環，成長全靠玩家自己一步步累積。
- **玩家自訂範圍**（性別/臉型/髮型/身高/體型）只影響外觀與部分動作表現，所有新契修仍受
  天玄院統一的同階修行規程約束，不影響核心數值成長路徑。
- 入院後分配至天玄院東廊「第七室」四人宿舍，與 3 位 NPC 舍友長期同住、一起執行任務與試煉。

---

## 2. 天玄院四人宿舍：第一批舍友（3位）

### 郁岑燁——劍修
- **流派定位**：劍修（高機動、快速連擊、持續輸出）
- **外觀關鍵特徵**：黑青短髮、額間細曜紋、右手常覆纏帶像護指
- **個性一句話**：嘴上認真挑剔、下手最先救人
- **與玩家的初步關係鉤子**：玩家初入宿舍時被他吐槽「步伐太散」，但會在首次擂台試煉後主動替玩家「補連段節奏」。
- **前三章人物弧線**：第1章以標準訓練壓人卻不自覺暴露驕氣；第2~3章在同伴受牽連時學會收劍、以團隊為先。

### 厲若楓——弓修
- **流派定位**：弓修（遠程、輸出、風箏）
- **外觀關鍵特徵**：琥珀色眼、背後斜掛三段式短弓、左肩有舊傷疤
- **個性一句話**：不愛吵架，但每次沉默都在計算下一箭
- **與玩家的初步關係鉤子**：常被他用「觀察角度」糾正錯誤站位；他會要求玩家一起外出偵巡，卻不說原因。
- **前三章人物弧線**：第1~2章冷眼旁觀、精準解圍；第2~3章舊箭傷／家族任務曝光，選擇掩護而非追擊，開始承認同伴。

### 齊衡烈——刀修
- **流派定位**：刀修（近戰、爆發、高傷害）
- **外觀關鍵特徵**：赤金刀紋般的臂環紋、身形偏壯、刀鞘常擦得發亮
- **個性一句話**：任何練習都能打出氣勢，但他最怕輸給自己
- **與玩家的初步關係鉤子**：玩家第一次用近戰爆發失控時，他不是嘲笑，而是帶玩家做「力歸節律」訓練。
- **前三章人物弧線**：第1章以衝動挑戰教官卻自尊受挫；第2~3章護短失敗自責，之後為宿舍擋鋒，學會收刀而非硬拚。

## 3. 編外第四友：靈杖流派補全

六大武器流派（刀/劍/槍/弓/重刃/靈杖）中，若只靠上述 3 位舍友 + 教官（重刃）+ 競爭者（槍修），
會漏掉「靈杖（法術範圍控制）」完全沒有角色代表，選靈杖流派的玩家會覺得被冷落。
**採用「新增編外角色」而非「置換既有舍友」的方案**——置換會把缺口搬位置而非真正補上
（例如把弓修舍友改成靈杖，會導致弓修反而沒人代表），新增才能讓六大流派一次補齊、原有
三位舍友的人物弧線也不受影響。

### 聞人澈——靈杖（編外/隔壁房常駐）
- **流派定位**：靈杖（法術、範圍、控制）
- **外觀關鍵特徵**：玄木短杖配腕繞符環、灰藍罩袍，施法時地面展開曜紋法陣
- **個性一句話**：不常主動開口，但總在關鍵時刻用範圍法術把隊友從死線拉回來
- **與玩家的初步關係鉤子**：常來第七室蹭飯，被齊衡烈半強迫拉進訓練；與郁岑燁爭「戰術主導」意見不合，
  但與厲若楓的遠程輸出/範圍控制配合度極高，戰鬥中自然形成掩護默契。
- **前三章人物弧線**：第1章布陣救場卻拒絕正式入隊；第2章舊陣法事故被揭露（曾因法陣失控牽連舊隊友受傷）；
  第3章強開天幕護住宿舍全員，正式承認新契修同伴身份。

## 4. 天玄院導師/教官

### 蕭曜霖——重刃（戰技堂教官）
- **流派/歸屬**：重刃（防禦、坦克、控場）｜天玄院「鋼樁武研導」
- **外觀關鍵特徵**：厚重護肩、眉骨有淡金曜痕、走路像壓著風聲
- **個性一句話**：少講道理，多讓你在挨揍中學會判斷
- **與玩家的初步關係鉤子**：玩家初期每次任務失誤，他都以「站位決定生死」為核心訓練；
  但會在玩家真正扛住失敗後，額外授予一段「青嵐禁區」的路線口訣。
- **前三章人物弧線**：第1~2章以嚴苛測試定調「天墟不是試膽」；第2~3章私下導正青嵐的策略錯誤，逐步透露其規訓背後的目的。

---

## 5. 初期「對照組」/競爭關係同期修行者（非純反派）

### 江祈璟——槍修
- **流派/歸屬**：槍修（中距離、控制、穿透）｜天玄院「穿衡槍班」，同屆考核前十
- **外觀關鍵特徵**：長馬尾束於背後、槍柄掛小鈴、指節有細密繭
- **個性一句話**：他不急著贏，只要你錯一步就會被他抓到底
- **與玩家的初步關係鉤子**：與玩家在青嵐城的「巡曜路」同任；他表面禮貌，卻總能用中距離控制穿透讓玩家暴露破綻。
  玩家越熟練，他越像在「逼玩家長大」。
- **前三章人物弧線**：第1~2章視玩家為拉低整體水準的變數，多次利用長槍壓制刷存在感；
  第3章聯合演習中被玩家小隊用奇襲打亂節奏、痛失第一名，將玩家視為平生宿敵，誓言在「天墟大比」徹底毀掉他——
  非純反派，動機是自尊與世家期望，而非惡意。

## 7. IP 原創性提醒

本文件所有人名（郁岑燁、厲若楓、齊衡烈、聞人澈、蕭曜霖、江祈璟）皆為原創命名，
設計時已避開直接沿用《滄元圖》《牧神記》等既有作品的專有名詞。但由於命名風格屬於
常見東方修行/武俠題材慣用字組合，**建議正式定案前另外人工查證一次**，避免與其他
知名作品角色名稱高度撞名。
