# 《九曜：天墟》任務設計 V1.0

> 狀態：**大綱級定案**，核心方向已鎖定，個別任務內容待第二階段補完，標記為「可調整」。

## 核心方向

- **主線**：負責推動境界突破條件、解鎖新地圖/副本入口，以及妖獸異化的劇情伏筆串聯，
  每章至少一次「試煉+特定敵人」節點。
- **支線**：提供「靈印搭配/生活食材/裝備配方」的垂直目標，並深入宿舍舍友的角色故事，
  解鎖專屬外觀與宿舍家具。
- **日常**：以短循環為核心（如每日三輪小試煉10-20分鐘、每日一個異化靈核來源、
  與生活系統掛勾的採集/煉丹委託），分散玩家遊玩時間、避免長時間綁定。
- 獎勵設計不與商業化衝突：不做付費抽卡門檻，成長差距主要由參與機制與組合深度決定。
