   境界硬性屏障通行機制）。
4. **【跨越屏障與編外援手】**：憑印記通過古林邊界屏障。林內異化瘴氣濃重，編外角色
   聞人澈登場，用靈杖暫壓異化毒素並提供藥劑支援，解鎖聞人澈加入輔助NPC行列。
5. **【古林深處的血色陣眼】**：舍友三人（郁岑燁/厲若楓/齊衡烈）協同作戰，深入古林

6. **【世界事件前導：赤瞳降臨】**：林底異化源頭爆發，第一個世界BOSS「赤瞳妖將」現身

## 2. 六位角色專屬支線任務（各1條，呼應02人物弧線鉤子）

1. **郁岑燁（劍/舍友）——「名劍折鋒」**：協助郁岑燁尋找家族斷劍的重鑄材料，面對他過度
   追求完美的執念。獎勵：劍系專屬裝備配方 + 靈印「極鋒」（提升連段命中判定與會心率）。
2. **厲若楓（弓/舍友）——「靜默之弦」**：陪同厲若楓前往古林高台獵殺特定異化飛鳥，
   解開她背負家族期望的沉重枷鎖。獎勵：弓系高階箭矢打造術 + 靈印「遠視」（增加射程與
   遠距離傷害）。
3. **齊衡烈（刀/舍友）——「烈火烹油」**：在演武場與齊衡烈對決，幫助他控制衝動刀意，
   達到剛柔並濟。獎勵：刀系專屬裝備配方「赤炎狂刀」+ 靈印「爆裂」（提升近戰破防與
   受擊反擊）。
4. **聞人澈（靈杖/編外）——「禁忌之解析」**：隨聞人澈搜集5種異化妖獸組織，暗中進行學宮
   禁用的靈核提純實驗。獎勵：生活技能「靈核純化術」配方 + 靈杖專屬靈印「導化」
   （減少技能冷卻與異常抗性）。
5. **蕭曜霖（重刃/教官）——「舊戰場的過往」**：陪教官重遊天墟裂谷外圍舊戰場，拾回
   當年戰友遺物，了解其嚴厲背後的溫柔。獎勵：重刃專屬裝備配方「鋼嶽重劍」+ 靈印「不動」
   （提供霸體護盾與減傷）。
6. **江祈璟（槍/競爭者）——「高傲的代價」**：江祈璟獨自挑戰高階異化妖陷入困境，玩家
   前往支援並完成「槍劍合璧」對決，贏得他認同。獎勵：槍系專屬靈印「貫日」（增加突進
   距離與連擊傷害）+ 專屬稱號「宿敵之證」。

## 3. 日常任務具體內容範例（5種，每日短循環）

1. **演武微縮試煉**（每日三輪小試煉之一，約5~10分鐘）：學宮演武場完成3波快速怪物清剿，
   隨機帶有限時/禁防具等微挑戰。
2. **異化靈核巡獵**（每日異化靈核來源，約6~8分鐘）：前往青嵐古林固定區域擊殺指定
   異化精英獸，100%掉落當日異化靈核（裝備進階/突破備材）。
3. **舍區生活委託**（生活食材/材料，約5分鐘）：採集古林特有食材或運送鍛造材料給舍友，
   獲得烹飪配方與耐力食物。
4. **舍友切磋交流**（角色互動，約3分鐘）：與郁/厲/齊三人選一進行快速切磋或小遊戲，
   提升好感度並獲得微量修為。
5. **青嵐靈脈護航**（地圖巡查，約3~5分鐘）：修復青嵐城內2處不穩定靈脈節點（簡易QTE
   互動），獲得城池聲望與基礎貨幣。

## 4. 任務系統與境界屏障的配合機制（防止任務卡關）

1. **強引導突破**：主線任務推進到需要進入新區域（如古林）時，任務目標會自動轉化為
   「境界突破任務」，直接指引玩家找到對應NPC（如蕭曜霖）進行突破試煉，不需自行摸索
   突破入口。
2. **屏障通行印記即為主線獎勵**：完成對應突破試煉（如「骨脈相應試煉」）獲勝後，
   系統直接獎勵該區域的通行印記，主線任務隨即自動刷新為「穿越屏障」，確保流程順暢。
3. **境界不足時的軟性引導**：若玩家境界尚未達標，主線任務會暫時鎖定並提示「需達到
   XX境圓滿」，同時自動解鎖並推播對應的修為支線與日常試煉，引導玩家快速獲取經驗，
   絕不讓玩家盲目卡在地圖屏障前不知所措。
4. **支線/日常不越界**：支線與日常任務只在玩家已抵達的區域內進行，或改用替代素材
   完成進度（例如聞人澈的支線可用半成品樣本推進，不強制要求玩家先達到更高境界），
   確保不會意外卡住或誘導玩家越級闖關。

## 5. 任務獎勵設計原則（不做付費抽卡）

- **主線獎勵**：修為經驗（直接推動境界突破）、境界突破必要材料、**區域通行印記**
  （100%獲得，非機率）、章節主題武器/防具套裝。
- **支線獎勵**：角色專屬**裝備配方**與**專屬靈印**（呼應該角色武器流派與人物弧線），
  不給通用垃圾道具，確保支線是玩家構築Build深度的核心來源。
- **日常獎勵**：穩定產出的**異化靈核**（裝備/靈印進階材料）、生活技能食材/藥材、
  基礎貨幣（靈砥）與少量修為，可每日累積但不能取代主線的屏障通行要求。
- 全系統不設任何機率型付費抽卡機制，資源獲取皆為任務完成即得或穩定產出，
  呼應01/14已定案的商業化原則（Battle Pass/外觀/月卡，不做抽卡）。
