# 0. 使用規則

## 0.1 核心鎖定

1. 世界暫稱「九曜界」。
2. 世界存在九條核心曜脈，統稱「九曜」。
3. 天墟不是單純的一個遺跡，而是與世界本身有關的異常區域／現象。
4. 天墟裂變是現代主線的核心世界危機。
5. 妖獸異化、古代遺跡甦醒、空間異常與曜脈失衡彼此相關。
6. 玩家不是天生救世主，也不是唯一特殊血脈。
7. 人族與妖族都不是單純善惡二分。
8. 天玄院是玩家前期成長與劇情主要基地。
9. 青嵐篇是理解世界的第一階段，之後擴大到九州、荒境與天墟深層。
10. 世界真相必須分層揭露，不能第一章一次說完。

# 1. 一句話世界觀

> **九曜界是一個依靠九條曜脈維持世界平衡的東方幻想世界；當一片早已被世界隔離的「舊界」開始重新回流，妖獸異化、遺跡甦醒與空間裂變接連發生，一群原本只是來到天玄院修行的年輕人，被迫一步步走進一場跨越人族、妖族與遠古時代的世界真相。**

玩家不是「天生救世主」，而是：

> **原本只想修行，卻親眼看見不該發生的事；既然沒有人願意告訴我真相，那我就自己查下去。**

# 2. 九曜界的底層規則

## 2.1 九曜不是九種單純元素

九曜是維持世界運行的九條曜脈，每一條都同時影響自然、生命、修行與空間。

初期玩家只把它們理解成修行力量來源；後期才知道九曜其實是世界的基本運行規律之一。

本版本只鎖定「九曜」總稱，不強行把九曜全部定義成火、水、雷等常見元素，保留後期原創空間。

九曜影響：

- 生物生命力
- 修行者曜脈契點
- 靈印運作
- 妖獸變異
- 秘境形成
- 空間穩定
- 古代遺跡
- 區域環境
- 高階修行境界
- 天墟現象

## 2.2 曜脈與修行者

普通人並非人人都能直接感知曜脈。修行者透過「契點」建立自身與曜脈的穩定連結，才能使用武技、靈印與更高階力量。

玩家被稱為「青嵐新契修」，不是因為擁有唯一契點，而是剛完成第一次契點覺醒並進入天玄院。

玩家沒有：

- 皇族血統
- 遠古神獸血脈
- 出生即滿級
- 世界唯一資格

玩家真正特殊的地方，是**自己的選擇、行動與關係累積**。

# 3. 「天墟」真正是什麼

## 3.1 表層認知

普通人認為天墟是古老災變留下的巨大空間裂口與危險遺跡，因此裂谷、古遺跡、異化妖獸與空間裂隙常被統稱為「天墟異象」。

## 3.2 中層真相

天玄院與星河殿的部分高層知道：天墟並非單純自然災害，而更像是世界曾經主動隔離出去的一部分異常區域。

古代遺跡也不是單純寶庫，而是維持隔離狀態的舊時代設施。

## 3.3 長期核心真相

> **天墟是九曜界曾經被強行切離的「舊界層」。**

遠古時代，九曜運行發生無法逆轉的失衡。當時的先民沒有能力直接修復世界，只能把已失控的一部分世界結構切離，形成天墟。

因此天墟不是外來世界，也不是單純邪惡力量，而是：

> **九曜界曾經失去、但從未真正消失的一部分。**

現在的天墟裂變，本質上是：

> **被隔離的舊界層正在重新回流。**

這解釋了空間裂口、遺跡甦醒、異化妖獸與古代裝置重新運作等現象。

# 4. 天墟裂變的真正原因

## 4.1 前期官方說法

> 「九曜脈動異常，導致天墟裂口重新出現。」

這個說法不算完全錯，但刻意省略了大量歷史。

## 4.2 中期真相

古代隔離天墟的系統正在失效，而且不是單一事件造成：

- 古代陣列損毀
- 曜脈環流改變
- 人族過度開採部分曜脈資源
- 妖族領地的古老封鎖遭破壞
- 有勢力試圖利用天墟力量

因此天墟裂變是逐步失控的系統性危機。

## 4.3 長期問題

世界真正面對的不是「要不要消滅天墟」，而是：

> **九曜界應該繼續把舊界層隔離出去，還是重新學會與它共存？**

這是後期世界級選擇，不在前期直接公布。

# 5. 妖獸異化

## 5.1 前期認知

妖獸突然變得暴躁、更強，並出現不符合原本生態的外形與能力，例如異化青牙狼。

## 5.2 中期認知

異化妖獸接觸了從舊界層回流的「墟息」。

墟息會干擾生物原本穩定的曜脈結構，使其：

- 產生新的器官或外形
- 改變攻擊方式
- 失去部分本能
- 出現異常能力
- 對某些曜脈過度敏感

## 5.3 長期真相

**異化不等於邪惡。**

部分異化生物會失控，部分則可能與墟息形成新的穩定狀態。

這讓後期人族與妖族對異化的態度產生合理分歧，也避免「怪物＝邪惡」的單薄世界觀。

# 6. 五大勢力的真正立場

## 6.1 九州聯盟

公開目標：保護人族城市、維持秩序、防禦妖獸、管理危險區域。

內部至少存在：

1. **封鎖派**：天墟必須永久封閉。
2. **研究派**：應理解天墟後再決定處置方式。
3. **利用派**：可以把天墟力量轉成武器或修行資源。

前期玩家主要接觸官方封鎖派立場。

## 6.2 天玄院

表面是修行學院，實際同時負責：

- 年輕修行者培養
- 妖獸觀測
- 秘境探索
- 曜脈研究
- 天墟異常監測

高層知道的比學生多，但沒有所有人都知道完整真相。

## 6.3 星河殿

掌握大量古代曜脈資料。

核心矛盾不是善惡，而是：

> **知道真相的人，是否有資格決定所有人都不能知道真相？**

部分成員主張封存資料以避免恐慌，另一部分認為隱瞞才是最大的危險。

## 6.4 萬兵閣

表面是武器與裝備勢力。

後期可揭露部分古代武器材料來自天墟舊界層，使鍛造系統自然與世界主線連結。

## 6.5 荒境妖庭

不是單一邪惡陣營。

內部至少存在：

- 戰爭激進派
- 領地保守派
- 異化研究派
- 希望與人族合作的少數派

後期玩家進入妖族文明後會發現：

> 人族歷史中的「妖族入侵」，與妖族記錄中的「人族擴張」，並不是同一件事。

青嵐篇不是世界救世冒險，而是一名年輕修行者第一次發現「世界表面與真相不一致」。

- 郁岑燁

# 8. 第一章：青嵐試煉

## 核心目的

- 教玩家戰鬥
- 建立舍友關係
- 認識天玄院與青嵐城
- 第一次看到異化妖獸
- 第一次接觸天墟線索

## 劇情流程

### 序幕：入院

玩家進入天玄院，蕭曜霖負責新生戰鬥訓練。

第一次學會移動、普攻、技能、閃避與資源管理。

### 任務1：第七室報到

玩家認識三名舍友。

郁岑燁嫌玩家步伐散；齊衡烈邀請切磋；厲若楓在旁觀察。

目的是讓玩家先記住「人」，而不是先背世界百科。

### 任務2：基礎演武

蕭曜霖進行戰鬥考核。

核心教學句：

> **「站位決定你能不能活下來。」**

這句話成為青嵐篇的反覆主題。

### 任務3：城郊異動

玩家與同期修行者巡查城郊，江祈璟正式登場。

他率先發現妖獸行為異常。

### 任務4：異化青牙狼

玩家擊敗異化青牙狼，取得異常靈核。

聞人澈檢查後指出：

> **「這不是普通妖獸的靈核。」**

第一個真正世界觀鉤子建立。

### 任務5：河谷調查（古林前置調查區）

玩家前往青嵐河谷，發現靈流出現異常逆向脈動。

玩家第一次接觸「曜脈異常」。

河谷的線索指向更深處的青嵐古林——但古林入口設有「靈壓障壁」（呼應06已定案的境界
硬性屏障），鍛骨境無法強行通過。

### 任務6：骨脈相應突破試煉

蕭曜霖引導玩家在天玄院完成「骨脈相應試煉」（呼應05已定案的突破試煉形式），
玩家由鍛骨境突破至開脈境，取得「青嵐古林通行印記」。

這是玩家第一次真正的「境界」概念，也是第一次感受到修行不只是打怪練級。

### 任務7：跨越屏障，正式進入青嵐古林

憑通行印記通過古林邊界屏障。編外角色聞人澈在林內登場，暫壓異化瘴氣並提供支援。

玩家在古林深處進行連續清剿（呼應08已定案的三波異化妖獸清剿設計），
發現靈脈結界遭暗紅能量侵蝕。

### 任務8：陣眼殘響

玩家找到正在失效的古代陣眼。

它不是寶箱，而是一座仍在運作的古代設施。

玩家只看見部分能量被導向裂谷方向，無法理解完整用途。

### 任務9：赤瞳妖將（先遣遭遇）

赤瞳妖將出現。蕭曜霖前來鎮場，江祈璟與舍友協同迎戰。

它不是單純守門，而是在搜尋某種從古代陣眼流出的東西。

**這是小規模的先遣遭遇戰，玩家一行只是「擊退」它，不是完整擊殺**——完整的20~60人
全服世界BOSS版本（呼應09已定案的赤瞳妖將機制）由本次遭遇觸發解鎖，作為後續世界事件
另外進行，兩者是同一隻BOSS的不同規模呈現，不是兩隻不同的怪物。

玩家取得線索，但得不到完整答案。

### 第一章結尾：裂口

天穹出現短暫裂痕。

天玄院立即封鎖部分區域。

官方說法：

> 「局部曜脈震盪。」

玩家卻知道：

> **那不是普通震盪。**

第一章結束。

# 9. 第二章：青嵐異變

## 核心主題

> **「問題不是妖獸變強了，而是有人知道它為什麼變強。」**

第二章把「怪物事件」提升成「人為調查事件」。

玩家開始接觸：

- 古代陣列
- 星河殿資料
- 異化研究
- 妖獸遷徙
- 地圖異常
- 不明勢力活動

### 角色線

**郁岑燁**：從追求個人完美轉向團隊信任。

**厲若楓**：家族舊傷與過去任務曝光，開始懷疑有人刻意隱瞞情報。

**齊衡烈**：因保護同伴而失敗，理解「力量不等於保護能力」。

**聞人澈**：揭露過去法陣事故，說明他害怕大型陣法的原因。

**江祈璟**：真正把玩家視為競爭者，而不是拖後腿的新生。

### 第二章結尾

玩家確認青嵐古林的異化不是獨立事件，不同區域都指向同一種「回流現象」。

玩家第一次聽見被天玄院高層刻意避開的詞：

> **「舊界。」**

但仍不知道舊界就是天墟真正來源。

# 10. 第三章：裂谷回聲

## 核心主題

> **「天墟不是在入侵我們，它可能正在回到它原本的位置。」**

第三章完成青嵐篇第一個故事閉環。

玩家確認：

1. 異化有共同來源。
2. 古代陣眼正在失效。
3. 裂谷不是單純地形。
4. 有勢力在利用異常。
5. 天玄院與星河殿知道的比學生多。
6. 妖族可能也在調查同一件事。

### 第三章結尾

玩家進入天墟裂谷邊緣。

不是打敗最終魔王，而是看到裂谷另一側出現一片與九曜界不同、卻又與九曜界相連的古老地貌。

玩家第一次看到「舊界層」的真實存在。

裂口隨後關閉。

玩家回到青嵐城，知道：

> **青嵐只是整個世界問題的第一個裂口。**

青嵐篇結束。

# 12. 角色長期弧線

## 玩家

**新生 → 同伴 → 修行者 → 探索者 → 決策者 → 世界選擇的參與者**

不是救世主，而是從普通人逐漸成為能影響世界選擇的人。

## 郁岑燁

個人完美 → 團隊信任。

## 厲若楓

只相信自己的判斷 → 願意相信同伴。

## 齊衡烈

力量就是保護 → 真正的保護需要判斷。

## 聞人澈

害怕再次害人 → 願意再次相信自己的力量。

## 蕭曜霖

嚴格教官 → 逐步揭露為真正知道天墟危險的人。

## 江祈璟

對手 → 競爭者 → 臨時合作 → 真正理解 → 關鍵戰役並肩。

不得簡單黑化。

# 14. 主線任務規則

每個主線任務至少滿足以下兩項：

1. 推進玩家成長。
2. 推進世界真相。
3. 推進 NPC 人物弧。
4. 改變玩家對勢力的看法。
5. 解鎖玩法或地區。
6. 建立下一個劇情問題。

禁止大量出現只有「接任務 → 跑地圖 → 打10隻怪 → 回報」而沒有劇情作用的主線。

這類內容放到日常、支線或懸賞。

# 15. 劇情與系統對接

## 戰鬥

- 異化妖獸：展示屬性／靈印機制
- 精英敵人：展示韌性／破防
- BOSS：展示機制型戰鬥
- 突破：主動試煉
- 競爭者：展示流派與操作

## 靈印

靈印不只是數值獎勵。

世界觀中，靈印是修行者將曜脈規律「固定成可使用形式」的方法之一。

## 裝備

裝備代表修行者能承受與使用多少力量；古代裝備可以成為劇情道具，但不能取代角色成長。

## 生活系統

採集、採礦、釣魚、烹飪、鍛造、煉丹都應與曜脈材料、地方文化或異化研究產生自然連結。

## 夥伴

夥伴承擔探索陪伴、戰鬥輔助、情緒價值與世界觀線索，但前期不搶走玩家與舍友的劇情中心。

# 17. Phase 0 必須驗證的三個故事 KPI

### A：玩家會不會產生疑問？

如果玩家打完異化青牙狼只覺得「就是一隻比較強的狼」，劇情鉤子失敗。

### B：玩家會不會記得舍友？

如果玩家只記得系統、技能與數值，完全記不得角色，演出不足。

### C：玩家會不會想知道天墟是什麼？

第一章結束時應自然產生：

> **「剛剛那個裂口到底是什麼？」**

# 22. 本版本的核心故事主軸

目前《九曜：天墟》的故事正式從：

> 「有一個東方幻想世界，發生了天墟災難。」

提升為：

> **「一個被迫切離舊界層的世界正在重新面對自己的失去；玩家從最普通的新契修開始，在學院、同伴、妖獸與一次次異常事件中，逐步發現世界真正的歷史，最後才有資格參與『世界是否應該重新完整』的選擇。」**
