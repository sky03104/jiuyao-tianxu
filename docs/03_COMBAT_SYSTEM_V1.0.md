# 《九曜：天墟》戰鬥系統 V1.0

> 狀態：**大綱級定案**，核心方向已鎖定，細節數值與招式規格待第二階段補完，標記為「可調整」。

## 核心方向

- 手動戰鬥採「機制型」設計：左搖桿移動/走位，右側普攻可編織連段；技能/閃避/絕技需面向或時機判斷，
  以「技能間隙可被打斷/反制」建立操作價值。
- 自動戰鬥只負責維持日常刷怪/低階素材採集循環（讀取距離/仇恨/生命線觸發），不做高風險操作
  （閃避、絕技釋放節點由 AI 保守保留，不搶手動玩家的操作空間）。
- 高難副本與 BOSS 戰強制或強烈引導手動操作，避免「掛自動就能過高難內容」削弱機制型戰鬥的設計初衷。
- 核心手法：屬性克制 + 靈印組合驅動，玩家用閃避路徑與切換戰鬥路徑（6流派/後期雙脈）完成最後
  傷害與控制落點，形成以小博大空間，呼應 01 決策中「戰力不能決定一切」的設計原則。
- 完美閃避（Perfect Dodge）可觸發短暫時停或反擊視窗，作為手動玩家的技術上限表現。
