# 《九曜：天墟》戰鬥系統 V1.0

> 狀態：**細節定案（第二階段補完）**，具體數值為初版示意值，需 Phase 0 原型測試後調整，
> 標記為「可調整」。
> 產生方式：GPT/Gemini/DeepSeek 三方交叉草擬 → Claude審查發現「完美閃避判定窗口」與
> `01_ARCHITECTURE_DECISIONS` 已定案的 10-15Hz 連線同步頻率衝突 → 三方一致提出技術解法後定案。

## 1. 戰鬥資源條

- **生命值（HP）**：歸零倒地。脫戰緩慢自然回復，戰鬥中主要靠藥品/技能/靈印回復。
- **靈力（MP，0~100~300，受靈元屬性影響上限）**：技能消耗來源。普攻命中小量回復，
  受擊小量回復，脫戰快速回復；受控制/硬直期間回復大幅降低。
- **絕技能量（0~100）**：造成傷害、受到傷害、完美閃避、成功反制均可累積；集滿可釋放
  「九曜絕技」，釋放後清空，死亡保留部分（約50%）避免懲罰過重。
- **氣力/架勢（Stamina）**：閃避與衝刺消耗，停止消耗後快速回復；歸零時不可閃避、
  格擋被破防，是資源管理與節奏控制的核心。

## 2. 六大武器流派操作節奏差異

- **刀（近戰爆發）**：3~4段重擊連段，前段可被技能打斷/反制，末段位移破韌；技能短前搖高傷，
  絕技站樁爆發。節奏：重擊硬直控制。
- **劍（高機動連擊）**：5~6段輕連段，後搖極短、支援移動攻擊與可取消銜接技能；絕技多段連斬。
  節奏：極速多段壓制、穿梭閃避。
- **槍（中距離控制穿透）**：4段中距突刺，特定段落有時機判定窗口精準擊中觸發「破甲穿刺」；
  絕技長距離貫穿。節奏：中距離卡位、視距節奏掌控。
- **弓（遠程風箏）**：3段蓄力射擊，按住普攻可移動蓄力，放開釋放；絕技引導多重狙擊。
  節奏：拉開距離、蓄力重擊、距離傷害加成。
- **重刃（防禦坦克控場）**：2~3段極重揮砍，自帶霸體與減傷，節奏慢且沉重；絕技招架蓄力
  大範圍嘲諷/擊飛。節奏：穩定輸出與嘲諷控場。
- **靈杖（法術範圍控制）**：3段遠程法術彈道，技能需0.5~1.5秒吟唱或指定地面區域；
  絕技持續引導AOE傷害。節奏：預判佈陣、保持安全距離。

## 3. 雙脈切換規則

- 後期解鎖，預設雙流派，戰鬥中可切換。
- **冷卻時間**：8秒（GCD，雙脈共用同一冷卻計時，不可無限切）。
- **切換代價**：消耗約20點靈力（或氣力），切換瞬間約0.4秒硬直（可被閃避取消），
  受控制/硬直/破防狀態下禁止切換，避免破壞戰鬥公平性。
- **切換連動**：切換瞬間觸發「切脈擊」，以副流派武器屬性造成範圍傷害，並獲得短暫
  （約3~4秒）流派專屬增益（如換至劍脈+移速、換至重刃脈+護盾），鼓勵主動切換而非單押一流派。

## 4. 閃避/格擋機制

- **閃避（Dodge）**：短暫無敵幀（約0.2秒，對應60fps約12幀），消耗氣力；
  **完美閃避**判定為敵方傷害判定落在閃避極短前段時間內觸發，成功後獲得短暫減速視窗/
  反擊視窗，並回復絕技能量、解鎖流派專屬反擊技。
- **格擋（Block，重刃/槍系專屬）**：需面向來源方向，成功減傷約70~90%，消耗氣力；
  在極短窗口內按壓觸發「完美格擋」，可免疫傷害並使攻擊者陷入硬直。
- **技術介面（解決與連線架構的衝突）**：完美閃避／格擋等短窗口判定，**不依賴對外
  10~15Hz 廣播頻率**——那是同步給其他玩家「看到」戰鬥表現的頻率，與伺服器內部戰鬥
  判定頻率解耦。伺服器內部戰鬥子系統以更高頻率（30~60Hz）做命中/閃避的權威判定：
  客戶端僅上傳「意圖」（操作時間戳+角色姿態，不送判定結果），伺服器保留短時間（約1秒）
  的歷史軌跡緩衝，用延遲補償/時間回溯（Lag Compensation / Rewind）重算命中判定，
  異常延遲、時間戳不合理或輸入頻率過高者一律丟棄或降判為普通閃避，
  確保短窗口手感與伺服器權威判定可以並存、不給作弊空間。

## 5. 自動戰鬥AI決策優先序

僅用於低風險日常刷怪循環，決策優先序：
1. **生存優先**：血量低於閾值（約35%）時優先使用防護/位移技能或撤退。
2. **不主動追求完美閃避**：僅在必定受到致命傷害時才觸發一般閃避，不嘗試精準判定。
3. **屬性克制優先**：優先選擇能觸發剋制加成的技能。
4. **不主動切換雙脈、不蓄力搶攻、不做預判控場**：避免自動戰鬥逾越高風險操作邊界。
5. **資源節奏管理**：靈力充足時維持技能循環，不足時降頻僅做必要普攻與資源恢復。
6. 高難副本/BOSS戰設有「機制硬檢定」（如限時內必須用特定流派技能打斷、或必須靠完美閃避
   躲過全屏必殺），自動AI無法應對，強制玩家介入手動。

## 6. 手動與自動的獎勵/懲罰設計

- **日常無痛**：低難度清怪/大世界採集允許100%自動戰鬥，掉落率與手動一致，保障輕度玩家體驗。
- **高難門檻**：BOSS/高階副本設有機制硬檢定，自動AI無法應對，強制手動介入。
- **數值與效率獎勵**：手動輸出上限可比自動高出約200%+（透過技能取消銜接、雙脈連招、
  完美閃避時停），且副本結算依「完美閃避次數/破招次數」評定 S/SS/SSS 評級，
  高評級提供額外稀有靈印掉落率加成，鼓勵手動但不強迫。
