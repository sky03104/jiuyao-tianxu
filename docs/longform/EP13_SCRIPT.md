**机遙：**（轉向隼和齊衡烈）「我們都想知道誰先動的手。」

**机遙：**「可是有人，連那一段都不想讓我們看見。」

△ （約 4 秒）沒有人回答。隼看著那片鑿痕（單人）。

△ （約 3 秒）齊衡烈也看著鑿痕，手慢慢從刀柄上滑下來（單人）。

**齊衡烈：**（鬆開刀柄）「……鑿的那個傢伙，最該挨罵。」

**隼：**（手離開鉤刃）「……這句，我同意。」

△ （約 3 秒）渺音看著那片鑿痕很久，指尖撥著辮尾的骨珠（單人）。
