## 第二季總覽

### 季主題
- **一句話**：離開學院，才發現每個地方都在講不同的真相——而且沒有人會再替你判斷。
- **篇章問題**（`21` 第 11 節）：「如果真相會摧毀現有秩序，那真相還應該被公開嗎？」
- **机遙這一季學的事**：蕭曜霖在 EP04 第一場說「從今天起，我不替你們判斷每一件事」。之後七集，机遙每集都得自己下一次判斷，而且每次都有代價：
  - EP05 繞路護崽、先救人，頭車翻落山溝，那批藥進不了城；
  - EP08 選了沒人去的村子，赭原就失守；
  - EP09 跨過封鎖線；
  - EP10 在討伐戰裡喊停封陣。
  季末他從「跟著隊伍查的新生」變成「會為自己的判斷負責的人」，對應 `21` 第 12 節的「同伴 → 修行者 → 探索者」。他仍然不是天選之人：每一次判斷都建立在同伴給的證據上。
- **觀眾的認知擴張**（`36` 第一節）：
  1. 青嵐不是孤例（EP04）；
  2. 同一件事，在不同人嘴裡是不同的事（EP04～06）；
  3. 人族自己的行動也會讓事情變糟（EP05、EP09）；
  4. 敵人不一定在攻擊世界，可能在保護什麼（EP10，只提出問題，不給答案）。

### 第二季製作通則（寫劇本、片段表時照做）
1. **文書類道具**，包括信、帳本、名單、公文、古卷、地圖、測定盤、旗幟、封條，一律只拍外觀和角色的臉；內容由角色唸出來。
2. **遠端通話**（符訊、資料符）：說話的人只在自己的地點出鏡，或只出聲（畫外）；兩地交叉剪接，不在同一支片段裡出現兩個地點。
3. **多人戰鬥**：每支片段一個地點、最多 3 人；大場面的人群一律是背景，模糊、不看鏡頭、不排隊。
4. **赤瞳妖將**：不吼叫、不說話、只有紅光；紅光「掃過整隊」，不單獨盯著机遙（P28）。
5. **灰斗篷人（EP04）、黑衣人（EP05）、霍棠（EP07）三種造型刻意不同**：劇情上不能證明他們是同一批人，畫面也不能讓觀眾以為是。

## EP04〈離院之路〉

- **對應章**：第 4 章（`36` 第二節、`40`）
- **一句話梗概**：第七室第一次離開青嵐，在西陲的赭原節點發現有人改過古陣的導流——改的人不想毀掉它；而厲若楓的家族箭簇顯示，十二年前就有人來這裡查過。
- **情緒弧**：
  - 机遙：等人下判斷（「那如果我們判斷錯了？」）→ 自己說出結論（「我們不是第一批來的人。」）。
  - 厲若楓：把家族的事藏著 → 把家族的箭接上一個地點和年份（「我那時候太小。家裡從沒說過是哪一年。」）；「誰射的」不在本集回答。

## EP05〈曜脈商路〉
