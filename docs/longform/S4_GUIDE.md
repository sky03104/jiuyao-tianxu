## 第四季總覽

### 季主題
- **一句話**（`24` 第五節）：「你以為自己正在探索遺跡，其實你正在走進世界失去的一部分。」
- **篇章問題**（`21` 第 11 節天墟篇）：「應該繼續封閉天墟，還是讓世界重新完整？」——第四季只把問題問完整，**不回答**（答案在第五季）。
- **這一季的答案（不是真相，是机遙的體會）**：被切出去的，不只是一塊地，還有站在那塊地上的人。
- **机遙這一季學的事**：第三季他學會「讓兩邊看見同一件事」。第四季他走進門後，發現連「看見」都有人替他決定過——紀錄被撕、名冊被改、地圖上的名字被刮掉。他從「探索者」變成「決策者」（`21` 第 12 節）：每一集他都做一個要付代價的選擇，但**每一次能做成，都靠別人交出手上的東西**（紀蘊之的缺頁、厲若楓讀得懂的箭號、桓瑾的倒戈、各勢力手上的殘環、江祈璟對父親的那一槍）。他仍然不是天選之人：他的靈印對殘環有反應，**所有人的都有**（EP20）。
- **觀眾的認知擴張**（`38` 第一節「碎片開始互相吻合」）：
  1. EP17～18：門後不是虛空，是一座有人住過、還在運轉的城（舊界的「確認存在」→「開始理解」）。
  2. EP19：遠古的人曾把世界的一部分切出去；切離只是把問題延後（**第一層**，不說切去哪裡）。
  3. EP20：天墟、天門、九曜、切離不是四件事（**第二層**，不公布等式）；十二年前的赭原，有人照著古人的方法又切了一次。
  4. EP21：赤瞳妖將一直在擋「錯誤的封鎖」（行為形成完整問題，目的不說破）。
  5. EP22：天墟＝九曜界曾經被強行切離的舊界層；回流＝舊界層重新與現世連結（**最終真相**，`21` 第 3.3 節）。
  但**不寫成「切離的人是壞人」**：斷代者是在沒有更好辦法時做事的人；十二年前下令的藺沅，救下了赭原三千人。

### 第四季製作通則（寫劇本、片段表時照做）
1. **天墟的樣子**（全季統一，寫進場景設定圖）：白天的天空是淡青綠色、沒有太陽，光從整片天均勻地來；夜裡是深紫色、沒有星星。建築的石材與暗色金屬和九州古城相似（屋簷弧度、門的比例），但更高、更細，到處是圓環紋；曜脈的光線**沿牆往上流**，呈琥珀色；渠道裡的水往高處流；說話聲會往上飄（音效：輕微上揚的殘響）。
2. **字**：遺跡的浮雕、城圖、記錄、名冊、密卷、家族紀錄，一律只用圖形、點、線、圓環紋，**沒有字**；內容由角色唸出或說出。
3. **記錄站的「記石」**（沿用 S3「記石投影」語言）：懸浮的石片，被碰到會在空中投出半透明的影像與聲音。古人的聲音是古語低吟（和記柱同一種），由渺音當場只譯**短句**；影像只用剪影與光，不拍古人的臉。
4. **厲疏桐**：四十歲上下，斥候打扮（灰斗篷、兜帽、臉蒙布、皮手套、背長木匣＝弓匣，與 S2 EP04 灰斗篷人同一套），**右半張臉到頸側是穩定異化的晶脈**（沿用 S3 製作通則 3，光是平穩的）。EP19 結尾前不露臉。
5. **赤瞳妖將**（延續 S1～S3）：不吼叫、不說話、只有紅光；紅光掃過整個場面、停一拍，不單獨盯著机遙。EP21 第一次近景，但仍不拍它攻擊人。
6. **符訊**：遠端的人只在自己的地點出鏡或只出聲，兩地交叉剪接；天墟內不通。
7. **肢體接觸**：重逢、拉人、扶人一律不拍接觸——兩人保持一步以上距離，用反應鏡頭、音效與剪接；「光鏈綁住赤瞳」只拍光鏈與它的剪影。
8. **多方場面**（EP17 議事廳、EP21 天門、EP22 深處資料庫）：每支片段一個地點、最多 3 人，正反打或交叉剪接；聯盟士兵、妖族戰士一律是背景，模糊、不看鏡頭、不排隊。
9. **九曜殘環**：八段弧形暗青銅與石的殘片，每段外緣刻九道細槽中的一部分；第一季的古代銅件（S1 EP03，巴掌大、方形榫口、九道平行細槽）是**扣件**，把殘段扣在一起。拼起來是一個少了一段的環（缺口＝第五季的「空位」）。

## EP17〈裂界之門〉

- **對應章**：第 17 章（`38` 第二節，17-1～17-8 全保留因果；T01～T07）
- **一句話梗概**：荒境天門塌了以後，九州的節點一座接一座熄滅。聯盟樞議藺沅要人進天墟，院方只問、不派，十個人報名。紀蘊之把聞人澈事故的缺頁還給他——上面畫的是天門；江祈璟的父親說出十二年前赭原的陣是他關的。萬兵閣用第一季帶回的古銅件撐開青嵐裂谷一炷香，門後不是虛空，是一整片大地。研究署的桓瑾抽了門的力，門提早崩；机遙回頭去帶她，門外的蕭曜霖下令「拔」——十個人被關在門後。
- **情緒弧**：
  - 机遙：「總要有人去看它從哪裡來」→ 踏進門的震撼 → 回頭救一個害了大家的人，門在背後關上。
  - 蕭曜霖（副線）：十二年前看著切線閉合的人，再一次親口說「拔」。
  - 聞人澈（副線）：一年來不敢說的事（看過門後）終於說出口。

  1. 大廳牆上的浮雕：細高、多關節的身影，提著燈、拄著長長的骨杖；地面石板上有化石般的巨大三趾足印。**只有圖形**。
  2. A：渺音說妖族的記誦裡也沒有它們。
  3. 齊衡烈盯著浮雕的骨杖：和青嵐秘境那個朽骨祭司拿的是同一種（S1 EP02）。他想起祭司那句話。
  4. B：桓瑾蹲下，用小刀把足印裡的灰刮進瓶子。沈昭寧帶刺地頂她（S3 EP14 籠子回扣）。

- 關鍵台詞：
  - **渺音：**「不是人，也不是我們。記誦裡沒有它們。」
  - **齊衡烈：**（盯著骨杖）「這根杖……青嵐秘境那個祭司，拿的就是這個。」
  - **齊衡烈：**「它那時候說，我們連自己站在哪裡都不知道。」
  - **沈昭寧：**（看桓瑾刮灰）「妳在籠子外面，也是這樣刮螢的？」
  - **桓瑾：**「研究就是刮。不刮，什麼都不知道。」
  - **陸鳴鸞：**「收好。出去了再吵。」

**第 8 場｜門後之城・城圖廣場｜入夜｜95 秒**
- 出場：厲若楓、聞人澈、江祈璟（同框 3）；机遙（反應鏡頭）
- 目的：18-6 古城地圖上一個被刮掉的名字，與「舊界」的記號一致（T32：只拍刮痕與記號）。
- 要點：
  1. 廣場地面是一整幅浮雕城圖：城、河、環形的街，延伸到廣場邊緣（**只有線與環**）。
  2. 城圖正中央有一塊被鑿平的地方，鑿痕很深。旁邊留著一個小記號：一個圓環，被一道短線切開。
  3. 厲若楓認出這個記號：第一季青嵐節點圖上，「舊界」兩個字旁邊就是它（S1 EP03 第 11 場）。
  4. 聞人澈說被鑿掉的是名字；江祈璟問誰會做這種事；厲若楓答。
  5. 机遙摸著鑿痕：它和城一樣老。
- 關鍵台詞：
  - **厲若楓：**「這個記號，我在青嵐的節點圖上見過。就在『舊界』兩個字旁邊。」
  - **聞人澈：**「中間被鑿掉的，是名字。」
  - **江祈璟：**「誰會去鑿一座城的名字？」
  - **厲若楓：**「不想讓人找回來的人。」
  - **机遙：**（摸鑿痕）「鑿痕，跟城一樣老。」

**第 9 場｜門後之城・光渠邊｜夜｜75 秒**
- 出場：聞人澈、郁岑燁、机遙（同框 3）
- 目的：18-7 天墟內的靈流不是向外噴發，而是在某些區域朝九州流動；「像有人替它挖好的」（為 EP21 赤瞳維持的路徑、EP22 斷代者的設計埋線）。
- 要點：
  1. 城邊一條寬渠，渠裡流著光。聞人澈把測定盤放在渠邊：三圈光環整齊地指向同一邊。
  2. 那一邊，是他們進來的門的方向。
  3. 郁岑燁把九州的回流和這裡接起來。
  4. 聞人澈修正：不是全部，只有這幾條渠；而且渠很直。
  5. 机遙看著幾條光渠一起往地平線收過去。
- 關鍵台詞：
  - **聞人澈：**「靈流不是往外噴。是沿著這幾條渠，往同一個方向走。」
  - **郁岑燁：**「哪個方向？」／**聞人澈：**（指向門的方向）「我們來的那邊。」
  - **郁岑燁：**「九州那些回流，是從這裡過去的。」
  - **聞人澈：**「不是全部。只有這幾條。直成這樣……像有人替它挖好的。」

**第 10 場｜門後之城・回營的長街｜夜｜85 秒**
- 出場：厲若楓、机遙、陸鳴鸞（同框 3）
- 目的：【動畫補完】有九州的人進來過；厲家的箭——接回 S1 EP02、S2 EP04 的箭簇線（`38` F09）。
- 要點：
  1. 回營途中，厲若楓突然停步：牆縫裡斜插著一支箭，箭桿發黑、羽毛爛光，箭簇生滿鏽。
  2. 她拔出來，對著光渠的光看箭簇：側面三道刻痕（S1 EP02 同款，特寫）。
  3. 她說出這是斥候的路標，以及角度代表什麼；順著看過去，長街盡頭的牆上還有一支。
  4. 陸鳴鸞問；厲若楓的回答很短。
  5. 机遙問多久以前；她看鏽色回答。
- 關鍵台詞：
  - **厲若楓：**（看箭簇）「……三道刻痕。」
  - **机遙：**「跟妳腰囊裡那枚一樣？」／**厲若楓：**「一樣。家裡打的。」
  - **厲若楓：**「插成這個角度，是斥候的路標。意思是：往這邊走。」
  - **陸鳴鸞：**「有人進來過？」／**厲若楓：**「我們家的人。」
  - **机遙：**「多久以前？」／**厲若楓：**（看鏽）「……好幾年。」

**第 11 場｜水輪廣場・營地｜深夜｜80 秒**
- 出場：A 桓瑾、机遙、郁岑燁（光渠旁圍坐，同框 3）；B 厲若楓、机遙（同框 2）
- 目的：18-8 第一次懷疑（T09：保留為问句、沒人回答）；結尾鉤子落在厲若楓。

  4. B：厲若楓一個人坐在廣場邊，手裡是那支鏽箭。机遙走過去，在一步外坐下。

- 關鍵台詞：

  - **郁岑燁：**「……睡吧。明天跟著箭走。」
  - **厲若楓：**（看著鏽箭）「我們家，只有一個人沒回來。」
