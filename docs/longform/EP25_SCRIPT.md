△ （約 3 秒）他把木匣推到桌心，和銀印並排（特寫）。

**江肅：**（把木匣推到桌心）「江家的封陣器，不做了。」

△ （約 3 秒）廳口，江祈璟靠著門柱站著（單人，從石桌往廳口拍）。

**江祈璟：**（在廳口）「爹，那九州每一道新的縫，我去看。」

△ （約 3 秒）江肅隔著整個廳看著兒子，點了一下頭（單人）。

△ （約 3 秒）石桌中央，素銀印和木匣並排放著（特寫）。
