## 核心方向：雙幣制（承接原方案，本輪補完細節）

- **靈砥（綁定，日常養成幣）**：不可交易，防代練/防賣帳號，用於角色基礎等級、技能、
  裝備基本強化消耗。
- **曜金（可交易，高階/公會幣）**：透過高難副本、公會爭霸戰、玩家間拍賣場流通，
  可購買稀有裝備、頂級打造材料、公會物資。

## 1. 靈砥產出來源（6項）

1. 每日/週常任務指南與週卡里程碑固定獎勵。
2. 生活系統採礦/採集基礎產出（呼應11已定案）。
3. 低中階副本通關與材料副本獎勵。
4. 分解低階（凡/精/靈）裝備回收。
5. 一次性主線/支線劇情與探索度獎勵（呼應07）。
6. Battle Pass免費線達到特定等級的階段性靈砥包。

## 2. 靈砥消耗管道（6項，呼應10/11/13）

1. 裝備基礎強化（10已定案+1~+10區間主要材料）。
2. 洗鍊/重鑄前置消耗（10已定案）。
3. 角色基礎等級與技能天賦點亮。
4. 生活技能維護（工具修復、基礎配方解鎖）。
5. 傳送陣費用、基礎補血藥等NPC服務。
6. 高頻煉丹配方的基礎材料投入（呼應11）。

## 3. 曜金產出來源（6項）

1. 高難團隊副本/世界BOSS未綁定掉落（呼應09Build缺口機制）。
2. 公會爭霸戰/裂隙封印戰結算（呼應13）。
3. 生活系統高階原礦精煉產出（呼應11）。
4. 拍賣場出售未綁定稀有裝備/頂級材料。
5. 野外首殺/精英怪機率掉落未綁定曜金袋。
6. 月卡/Battle Pass付費線的定額定量產出（不破壞市場供給）。

## 4. 曜金消耗管道（6項，呼應10/11/13）

1. 裝備高階強化（10已定案+11~+15區間）與洗鍊/重鑄的高階材料。
2. 公會建立門檻（13已定案3,000曜金）與建築升級投入。
3. 拍賣場採購其他玩家出售的稀有裝備/頂級打造材料。
4. 公會物資與每週戰力Buff兌換。
5. 生活系統高階工坊租用/特殊設施使用費。
6. 拍賣場交易稅（系統抽成，直接銷毀，見第6節）。

## 5. 拍賣場/交易系統具體規則

- **交易形式**：僅限曜金資源與標記「可交易」的裝備/材料；禁止玩家間點對點直接交易，
  全數走拍賣場，避免線下交易與詐騙。
- **手續費**：成交額8%（月卡用戶降至5%），稅金直接銷毀（不進任何玩家或系統帳戶），
  作為通膨防治的基礎回收池。
- **上架限制**：一般帳號同時上架上限10個欄位，月卡用戶15個；上架時效可選24/48小時，
  上架需預先支付少量靈砥作為保管費（防止洗版式掛單）。
- **防詐騙機制**：
  - 動態均價區間：依前7天市場成交均價設定漲跌幅限制（±30%），防止極端哄抬/惡意砸盤。
  - 稀有物品公示期：橙色品質以上裝備/稀有材料上架後進入15分鐘公示期（全服可見不可購買），
    公示結束後隨機延遲1~60秒開放搶購，防止外掛腳本秒搶。
  - 購買後物品發放延遲5秒並提供完整帳務明細，降低誤操作與腳本攻擊風險。

## 6. 通膨防治的監控指標與自動應對機制

- **監控指標**：
  1. 人均曜金存量（7日移動平均）。
  2. 核心物價指數CPI（選定10項核心商品如高階藥劑/頂級原礦/通用強化石的加權平均價）。
  3. 拍賣場成交量/上架量比（去泡沫化的真實流動性）。
  4. 公會爭霸戰活躍度與曜金獲取效率比（單場平均曜金/平均參戰時長）。
- **自動應對（分級）**：
  - **輕微通膨**（CPI三日內上漲超過15%）：拍賣場交易稅自動調升（每日+0.5%，最高12%），
    加速曜金回收。
  - **嚴重通膨**（人均曜金存量14日內翻倍）：高階重鑄與公會物資的曜金消耗量自動上調
    10~20%；高難副本未綁定掉落轉為部分「綁定曜金」（僅能自用強化，不可上架，
    比例最高上調至30%）。
  - **通縮**（CPI下跌超過15%）：交易稅自動下調至最低5%，並調降高階重鑄的曜金消耗，
    刺激市場流動性。
- **原則**：所有調整只作用於曜金交易流與高難產出端，不影響靈砥的日常養成節奏，
  避免破壞玩家基礎體驗。

## 7. 月卡具體內容與定價方向（不做抽卡，不破壞數值平衡）

- **定價方向**：約NTD 300/月，定價低於等值抽卡期望值，確保理性消費不助長通膨。
- **內容**：
  1. 購買後立即獲得少量曜金，每日再額外登入領取（單月總量固定上限，屬於定額定量
     產出，非無限增值）。
  2. 拍賣場手續費優惠（8%→5%）與上架欄位增加（10→15）。
  3. 便利功能：專屬倉庫、隨身修裝、區域內免費傳送次數增加。
  4. 生活系統體力恢復速度小幅提升（不影響單次產出品質，只提升遊玩效率）。
  5. 專屬外觀（頭像框/稱號），不含任何屬性加成。
- 全部內容嚴格遵守01已定案原則：不影響裝備/靈印數值上限，不提供機率型抽卡道具。

## 8. RMT（真實貨幣交易）防範具體偵測規則

1. **異常轉移偵測**：同一帳號短時間內以偏離市場均價（如+30%上限）大量購入低價值物品，
   且賣方為固定IP/裝置指紋的關聯帳號，判定為洗金行為，觸發交易權限凍結與異常所得回收。
2. **工作室帳號識別**：主線進度長期停滯（<20%）、從不參與副本/生活/公會活動、
   僅重複執行單一採集路徑，且產出曜金於24小時內90%以上透過拍賣場轉移至單一目標帳號，
   系統判定為代練礦號，直接停權並清算異常資產。
3. **新公會保護期**：新建或未滿7天的公會，每週可提取的公會曜金資源上限大幅調降
   （呼應13已定案的每週提取上限機制，疊加額外90%調降），防止用公會金庫當洗錢通道。
4. **風險分數機制**：綜合交易集中度、對手活躍度、來源異常度三項加權計算風險分數，
   超過閾值自動凍結交易並轉人工審核，避免單一規則誤判正常玩家。
