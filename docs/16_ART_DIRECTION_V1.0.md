# 《九曜：天墟》美術方向 V1.0

> 狀態：**大綱級定案**，核心方向已鎖定，具體美術規格書待第二階段補完，標記為「可調整」。

## 核心方向

- 整體基調：低飽和水墨底色 + 局部高亮靈光（如青藍靈氣、赤紅濁氣），營造沉浸蒼涼感，
  避免高飽和卡通化，呼應「東方古風 + 高品質3D」定位。
- 材質語彙：粗糙織物/古樸青銅/光潤玉石，對比「天墟濁氣結晶」的異質科幻感，形成
  正常世界與異化威脅的視覺分界。
- 角色服裝：新式道袍 + 輕甲，保留流線型剪裁與學院徽飾，嚴禁模仿既有作品的韓系誇張羽毛
  或純西式鐵甲，維持東方幻想學院少年冒險調性。
- 怪物設計：以本土妖怪意象（獸骨/裂隙變異）為基礎原創發想，異化部位呈現暗紅結晶質感與
  幽光紋理，突顯神祕與危險；嚴禁直接模仿既有作品的角色/服裝/建築/怪物設計（見IP原則）。
- 場景需具備「天空裂隙」宏觀視覺錨點，在青嵐城/天玄院/裂谷等重要地標皆可望見，
  強化「世界很大、危機在逼近」的第一印象。
