> 天墟裂谷/青嵐秘境），其餘內容整合兩版優點採用。

## 0. 全局視覺總綱

- **基調**：低飽和水墨/宣紙質感底色（墨黑、墨灰、泥灰、米白），大量留白與暈染過渡。
- **局部高亮**：靈光僅做「功能性提示」——**青藍靈氣**（修行/正向/UI正向反饋）、
  **赤紅濁氣**（天墟裂隙/異化/UI警示）。兩色只允許出現在符印、裂面、核心、邊緣導光
  等機能位置，不做環境大面積染色。
- **材質語彙**：粗糙織物/紙纖維、古樸青銅（高對比反射但不金亮）、光潤玉石（圓潤冷硬
  反射）、天墟濁氣結晶（粗裂面+內層微發光）。
- **天空裂隙錨點**：每個主要場景至少具備「形狀/光帶方向/碎片分布」三要素之一，
  作為遠距離可辨識的宏觀視覺地標。

## 1. 角色美術規範（六大流派具體化，呼應02/03已定案角色）

共通原則：新式道袍+流線輕甲+學院徽飾（統一為「青銅章+玉石刻紋」，尺寸固定避免各角色
徽章比例造成視覺混亂）；嚴禁大面積光環、羽翼、傳統純武俠大氅等既有作品既視感元素。

1. **劍流（郁岑燁）**：對襟窄袖輕夾克式道袍，肩部綴以青銅與白玉交錯流線小鎧板，
   下擺不對稱短斜裁；劍身鑲嵌微光青玉，發招時劍身流淌青藍靈光紋路。
2. **弓流（厲若楓）**：緊身皮質胸甲搭配單側（開弓側）護臂，無袖道袍外罩防風披肩，
   腰間掛學院徽飾扣環；複合角弓，拉弓時由靈氣凝聚成青藍光弦與光箭。
3. **刀流（齊衡烈）**：粗麻寬肩無領上衣，胸腹部覆蓋重疊式古樸青銅護甲，單邊皮革長護手，
   強調肌肉線條與爆發力；厚背斬馬刀，刀身粗糙鍛造黑鐵質感，刀刃處赤紅濁氣與青藍靈氣
   交織交界線。
4. **靈杖流（聞人澈）**：多層次長款高領學院道袍，內搭垂墜感織物，腰帶綴大量光潤玉佩與
   幾何符文流蘇；枯木與青銅盤繞長杖，杖頂懸浮不規則切面青藍靈石。
5. **重刃教官（蕭曜霖）**：雙肩巨型青銅鎧甲，搭配沉穩暗灰厚重道袍，胸前為學院高階教官
   之鎏金青銅徽章；巨型門板重劍，材質為粗糙隕鐵與青銅，劍面有天墟裂痕般的暗紅與青藍
   交錯縫隙。
6. **槍流競爭者（江祈璟）**：立領修身輕甲，雙臂雙腿皆有流線型青銅鍛金保護，腰際掛輕量化
   流蘇學院徽章；長槍，槍頭為三稜青玉複合結構，槍纓處綴有靈氣絲線編織的槍巾，
   刺擊時產生流線型光束軌跡。

## 2. 怪物美術規範（四分類設計語言差異，呼應08已定案具體怪物）

1. **一般野獸**（青牙狼/赤尾狐/黑羽鴉等）：寫實本土野生動物結構，毛皮為低飽和大地色系
   （灰赭、泥棕），無結晶與異變，光影呈自然散射光，無靈光發散。
2. **古林妖獸**（岩甲獸/河谷巨蟒）：體型放大並具備自然元素融合（背生玄武岩甲、皮肉鑲嵌
   溫潤青玉），眼睛發出微弱青藍靈光，無暗紅結晶。
3. **異化妖獸**（呼應08已定案異化機制）：受天墟濁氣侵蝕，瞳孔轉為高飽和暗紅，關節/受傷處
   突出不規則暗紅濁氣結晶，皮膚表面浮現赤紅血管狀紋路，肌肉呈現非自然腫脹或乾涸感。
   例：赤尾狐異化後尾部結晶化、毛尾斷裂呈晶刺狀；黑羽鴉異化後羽片呈墨黑青銅片化，
   邊緣赤紅晶光流動。
4. **天墟巨魔**（BOSS層級）：巨型異質科幻古風體，由巨大古質青銅構件、崩解的古代建築
   殘骸與巨大暗紅結晶體凝聚而成，核心為脈動的赤紅濁氣源，局部殘存被拉扯侵蝕的青藍靈氣，
   具備極高視覺對比度與壓迫感。

## 3. 場景美術規範（青嵐城8子區域+4長期擴充區域，呼應06已定案世界觀命名）

共通視覺錨點：天空必須有巨大脈動的「天墟裂隙」作為宏觀光源與視覺中心。

**青嵐城8子區域**（06已定案正確名稱）：
1. **城門區**：灰黑玄武岩基座、老舊青磚、暗色木構建築，搭配水墨微霧；濁潤石板光澤，
   點綴暖黃燈籠光與學院青藍旗幟微光。
2. **青嵐主街**：商業氛圍稍暖，木構店鋪與青銅牌匾，水墨暈染的招牌旗幟，局部暖光燈籠
   與青藍靈氣招牌交錯。
3. **天玄院**：灰青水墨+玉石白為主，古樸青銅門框建築，光影如宣紙背光，柔邊，
   莊重清幽氛圍。
4. **青嵐河谷**：霧白/墨藍水色反射（弱化避免寫實鏡面），青藍靈光帶沿岸流動。
5. **青嵐古林**：墨黑樹幹密林，暗紅結晶點綴於巢穴/傷口周邊，光影呈水墨暈染過渡，
   夜間更顯壓迫（呼應06已定案迷霧脈息與異化妖獸增多設定）。
6. **青嵐山脈**：地表碎石粗糙、暗紅結晶點陣，光影偏硬但仍保持水墨暈染過渡感。
7. **天墟裂谷**：全區最強視覺錨點，主視覺導向天空裂隙本體，大量赤紅濁氣結晶與青藍
   殘存靈氣交界，混沌震盪的空間扭曲感。
8. **青嵐秘境**：依副本主題浮動，但統一保留水墨留白基底與局部結晶/靈光節點。

**4個長期擴充區域**（呼應06已定案的星辰/浮空/焚天/雷劫世界觀命名）：
- **北境·寒霜星辰原**：深藍墨黑交織的夜空與懸浮星核碎片，冷冽青藍靈光點狀分布如星辰，
  地表玄冰晶柱泛冷光。
- **東海·歸墟浮空島**：明亮高空青藍基調，白雲環繞破碎島嶼，古仙舟遺骸帶風化白石質感，
  日光與青藍天色雙重反光。
- **南荒·赤燄焚天谷**：焦黑與熾熱暗紅為主基調，硅化琉璃岩層與熔岩結晶，高對比赤紅
  逆光與濁氣地煙。
- **西境·雷劫天脊**：紫黑烏雲密布，帶電黑鐵岩層與青紫雷光交織，高頻閃動的雷光與
  金屬邊緣高光。

## 4. 色彩系統具體規範（呼應15已定案UI配色，遊戲內外統一）

- **基底色系（約70%畫面佔比）**：低飽和水墨色（焦黑、墨灰、泥灰、米白），用於場景
  地景、建築與角色大面積布料。
- **輔助色系（約20%）**：沉穩古風色（青銅綠、古玉青、暗黃銅），用於裝備金飾、道具細節
  與UI邊框裝飾。
- **高亮發光色系（約10%，嚴格限制面積）**：青藍靈氣（正向：靈力/技能/UI成功提示）與
  赤紅濁氣（負向：裂隙/異化/UI警示危險），與15已定案的UI配色完全對應同一套色碼，
  確保遊戲內美術與UI感知一致。
- **統一機制**：3D渲染的Bloom泛光閾值須與2D UI的Glow效果數值一致；發光元件嚴禁使用
  無飽和度的純白遮罩，必須保留青藍/赤紅的核心色相；單一模型的Emissive發光貼圖面積
  建議不超過模型UV總面積的8%，避免視覺過曝喪失水墨質感。

## 5. 原創性查核建議（具體可執行的檢查方式）

1. **剪影測試**：將完稿角色/怪物轉為純黑剪影，與已知作品（如市面東方仙俠/幻想題材
   知名角色）進行剪影比對，若輪廓相似度過高或僅靠頭飾/披風/武器輪廓才能辨識，
   一律退回重繪。
2. **材質三角審計**：檢查裝備材質是否落在「粗糙織物/古樸青銅/光潤玉石」三角語彙內，
   若出現「大面積高光皮革+LED燈條」（偏科幻）或「大面積純金+飄逸純絲綢」
   （偏傳統武俠仙俠既視感）等組合，即判定違規需修改。
3. **圖像反向搜尋**：2D設定圖定稿前，將服裝徽飾、武器幾何紋樣、異化怪物頭部設計
   截圖進行反向圖搜，確保與現有動漫/遊戲設計無雷同。
4. **發光面積稽核**：檢查3D模型Emissive貼圖，高亮發光區域（青藍/赤紅）不得超過整體
   UV面積的8%上限，防止光污染破壞水墨質感。
5. **世界觀對照表**：建立內部參照板，將「風格相近但容易撞衫」的外部作品各列1~2張，
   標註「撞點類型」（如披風比例、肩甲形狀、眼睛結晶呈現方式、巨魔骨架比對），
   每次新設計定稿前逐項打勾比對，避免空泛提醒。
