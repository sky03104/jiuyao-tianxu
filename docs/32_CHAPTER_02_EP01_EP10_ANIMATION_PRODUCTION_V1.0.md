# 一、第二章動畫總規格

## 核心主題
**「問題不是妖獸變強了，而是有人知道它為什麼變強。」**

第一章已建立：裂痕、異化、古陣、赤瞳妖將。
第二章必須把觀眾從「看到異常」推進到「開始查證異常」。

## 章節功能
1. 玩家第一次主動調查。
2. 六名核心 NPC 關係深化。
3. 青嵐秘境正式登場。
4. 「回流」成為可觀察現象。
5. 確認有人曾經調整古代陣列。
6. 朽骨祭司說出「舊界」。
7. 星河殿正式進入主線。
8. 青嵐異變暫時穩定，但證明九州其他地區也有節點。

## 硬性世界觀限制
- 不揭露「天墟＝舊界」。
- 不解釋古代切離事件。
- 不解釋九曜完整歷史。
- 不解釋赤瞳妖將真正目的。
- 不把妖族拍成單純邪惡。
- 玩家仍只是普通新契修。
- 第二章不安排境界突破，成長重點放在調查、裝備、靈印與團隊協作。

# 三、第二章角色固定表

### 玩家
普通年輕新契修，可自訂外貌；前章開脈境；服裝延續第一章；不使用英雄披風或特殊神紋。

### 郁岑燁
黑藍短髮、額前曜紋、右手包紮、劍修、黑藍戰裝。表情克制，動作俐落。

### 厲若楓
琥珀眼、三節短弓、左肩舊傷、冷靜觀察者。第二章開始增加「記錄證據」的動作。

### 齊衡烈
魁梧刀修、紅金臂環、動作大但仍有少年感。第二章後半逐漸學會停手與等待。

### 聞人澈
灰藍長袍、深色木杖、手腕符環。面對大型陣法時會有短暫緊張，但不誇張。

### 江祈璟
長馬尾、槍修、槍身鈴鐺、修長結實。語氣自信，第二章由競爭者轉為共同調查者。

### 蕭曜霖
重刃教官、厚重肩甲、金色眉間脈印。站姿穩定，幾乎不做多餘動作。

### 朽骨祭司
殘破祭衣、枯骨與人形輪廓融合、灰白殘魂、暗紅陣紋。不是普通妖獸，應呈現「古老殘留物」的感覺。

### 星河殿資料使
深色星紋長袍、銀灰資料匣、克制理性；不要設計成反派。
