# 《九曜：天墟》養成系統 V1.0

> 狀態：**大綱級定案**，核心方向已鎖定，數值曲線待第二階段補完，標記為「可調整」。

## 核心方向

- 採「多維互鎖」的縱向 + 橫向成長曲線，避免單一數值碾壓：
  - **縱向骨架**：9大修行境界，提供基礎屬性上限與核心技能槽解鎖。
  - **橫向配置**：6大核心屬性為自由分配點數，決定戰鬥風格特化（如力量偏重刃爆發、
    悟性影響靈印效果上限與觸發判定）；靈印與裝備為橫向 Build 搭配，負責戰鬥機制與屬性克制。
- 裝備提供「情境型」短期優勢（對應流派武技/特定屬性抗性），靈印決定 Build 風格（控制鏈/
  位移起手/爆發窗口），兩者不重疊、不互相取代。
- 突破境界需同時具備「修為累積 + 突破材料 + 試煉 BOSS + 劇情條件」四項，不做單純按鈕升級，
  確保各階段玩家皆有明確且階段性的成就感與操作考驗。
- 低境界玩家可靠屬性克制/技能搭配/靈印組合/操作/隊伍配置創造以小博大空間，防止純戰力碾壓。
