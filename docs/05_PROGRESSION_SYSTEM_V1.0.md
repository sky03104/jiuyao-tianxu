# 《九曜：天墟》養成系統 V1.0

## 1. 九大境界修為曲線與能力提升幅度

- 曲線形狀：**前緩後陡的台階式成長**，每境界內部再分初期/中期/後期/圓滿4小階段，
  小階段修為需求依序遞增（示意比例約 初期20% / 中期30% / 後期40% / 圓滿10%+瓶頸）。
- 各境界成長重點：
  - **鍛骨境**：基礎動作與生存能力起步，成長最平緩。
  - **開脈境**：MP/氣力與技能循環強化，後期開始提升絕技取得速度。
  - **靈府境**：靈印裝配效率前緩後陡，後期靈印被動觸發頻率與穩定性提升。
  - **天罡境**：攻防面板同步提升，後期身法效益（生存）成倍放大。
  - **神藏境**：資源回復前緩，後期絕技能量上限與獲取節奏顯著提升。
  - **領域境**：戰鬥帶入空間/節奏控制，後期領域類效果覆蓋率與容錯提升。
  - **聖域境**：面板成長趨緩，後期專注抗性突破與關鍵判定成功率。
  - **天門境**：取得「跨判定」能力（如條件式觸發），後期使克制鏈更難被逆轉。
  - **曜神境**：全曲線最陡，前期銜接、後期集中爆發於絕技與領域結合的巔峰輸出。

## 2. 六大屬性點數分配機制

- **升級（同小階段內）**：每小階段推進取得固定小量自由分配點（示意值：每次2點），
  可自由分配至任意屬性，不綁定靈印。
- **突破（跨大境界）**：每次突破額外取得「突破專精點」（示意值：每境界6~10點，
  隨境界提升遞增），此點數只能分配到本次突破試煉對應的主題屬性（2~3個屬性擇一）。
- **洗點重分配**：
  - **一般洗點**（不涉及已鎖定的突破專精配置）：消耗「洗髓丹」，有冷卻/次數限制。
  - **大幅重塑**（影響已綁定的突破專精配置）：僅限在「圓滿」小階段開放，成本更高，
    避免戰鬥中隨意切換Build，保有長期Build取捨的嚴肅性。

## 3. 屬性對戰鬥數值轉換邏輯

（呼應03戰鬥系統與04靈印系統，具體係數留待數值案設計，此處定邏輯方向）

- **力量**：主要影響物理傷害倍率、破防（韌性削減）效率、重型武器氣力消耗降低。
- **身法**：主要影響攻速/出招速度、閃避無敵幀長度、氣力恢復速度、移動速度。
- **體魄**：主要影響HP上限、物理防禦、抗打斷（霸體閾值）。
- **靈元**：主要影響MP上限、法術/靈印技能傷害與治療量。
- **元神**：主要影響絕技能量獲取效率與觸發判定穩定性、抗控制能力。
- **悟性**：主要影響靈印運作效能——冷卻縮短使觸發條件更容易滿足、連鎖組合判定範圍更寬容、
  技能學習與升級所需經驗降低。
- 典型配置方向：坦度續航（體魄+靈元/元神）、瞬擊爆發（身法+力量+悟性）、
  控場穩定絕招（元神+悟性+靈元）。

## 4. 突破試煉形式與難度曲線（依境界不同，不重複套用同一形式）

1. **鍛骨→開脈**：骨脈相應試煉——打靶/定型動作考核＋抗擊倒，容錯高但需時間，難度低。
2. **開脈→靈府**：通脈引流試煉——限時能量導入管理，失誤導致資源損耗，難度中上。
3. **靈府→天罡**：靈府共鳴試煉——多選機制，同一關卡可用不同靈印組合解題，
   通關評分決定突破獎池，難度依技術深度浮動。
4. **天罡→神藏**：天劫躲避試煉——雷劫躲避與反制，需精準閃避或招架吸收劫力反擊BOSS，難度陡升。
5. **神藏→領域**：心魔試煉——鏡像BOSS戰，複製玩家當前裝備與屬性但心魔擁有靈印全滿狀態，
   考驗玩家對自身Build的理解與操作，難度高。
6. **領域→聖域**：領域壓制戰——BOSS具備完整領域機制，需利用地圖機制與氣力控場打破領域，難度高。
7. **聖域→天門**：守界誓約——劇情封印線+陣眼守成，需隊伍分工，難度中後期高。
8. **天門→曜神**：天門對照——多分支判定，玩家選擇的「悟意象」決定後續資源曲線，
   成功率受元神/悟性影響，難度極後陡。
9. **曜神境（最終境界內部圓滿突破）**：曜輪臨照——高風險高回報，每次失敗損耗材料但保留部分
   試煉進度，以極限操作與靈印聯動評分，難度最高。

## 5. 低境界以小博大的具體機制

為避免數值碾壓、同時防止低境界玩家無限制擊敗遠高境界內容，採**硬性規則**：

- **境界壓制上限**：
  - 境界差1階：高境界一方獲得15%最終傷害減免。
  - 境界差2階：高境界一方獲得30%最終傷害減免（此為上限，不再隨差距擴大）。
  - 境界差3階以上：觸發「天威壓制」，低境界一方對高境界一方無法造成有效傷害
    （防止跨太多級的無腦碾壓或外掛式體驗）。
- **姿態打破（Poise Break）例外**：當高境界目標氣力/霸體值歸零進入破防狀態時，
  上述傷害減免**完全失效**，且此時低境界一方的處決傷害獲得200%暴擊加成——
  這是低境界玩家「以小博大」的核心突破口：靠精準閃避/招架/靈印控場打出破防窗口，
  而非單純數值堆疊。
- **屬性克制與靈印連鎖不受境界壓制影響**：04已定案的連鎖組合（如風助火勢/刺客瞬殺）
  造成的「真實傷害」部分不受境界減免影響，維持戰術組合的價值。
- **隊伍配置加成**：多人隊伍若涵蓋不同屬性/流派主戰角色，克制鏈更完整，
  可疊加額外命中判定寬容度，鼓勵陣容多樣化而非單一輸出集中。

## 6. 從第一境界推進到第六境界（領域境）預估時間

對應06地圖設計的青嵐地區境界分布，預估中位數玩家總體驗時程約 **45~55小時**（含支線與突破材料收集）：

- 鍛骨境：1~2小時（新手引導）
- 開脈境：4~6小時（解鎖2靈印槽，熟悉探索）
- 靈府境：8~10小時（解鎖4槽，Build初具雛形）
- 天罡境：12~15小時（解鎖5槽，面臨第一次陡升曲線）
- 神藏境：15~18小時（解鎖6槽，核心劇情大事件與區域主線BOSS）
- 領域境：突破後即達青嵐地區天花板（解鎖8槽全開），作為進入下一大區域的門檻，
  另需3~5小時進行最後鞏固。
- 重度養成/反覆刷取試煉追求Build品質的玩家，總時程可能拉長至60~90小時。
