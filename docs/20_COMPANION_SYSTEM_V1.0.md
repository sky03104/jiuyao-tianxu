## 0. 系統總覽

夥伴系統採「雙軌並行」機制，兩者互相獨立：

- **星曜獸型夥伴**：九曜世界觀中地脈曜氣凝聚而成的原生異獸，可捕捉/孵化/培養，
  獨立成長線，戰鬥中提供環境/節奏型輔助（控場、破防、資源回收），**不碰六流派招式
  本體，不佔用04已定案的8槽靈印，另開專屬掛槽**。
- **宿命契友型夥伴**：直接使用02已定案的6位角色（郁岑燁/厲若楓/齊衡烈/聞人澈/
  蕭曜霖/江祈璟）作為搭檔池，靠好感度解鎖「羈絆連攜技」，利用03已定案雙脈切換的
  8秒冷卻視窗作為連攜觸發時機點。

## 1. 星曜獸：捕捉/孵化機制（呼應06地圖生態）

- **野外捕捉**：06已定案的青嵐城各生態子區域（河谷/古林/山脈等）設有「曜脈節點」，
  玩家可用消耗品「凝曜網」（靈砥購買）進行追擊，將目標壓制至瀕危或控制狀態後完成
  捕捉QTE判定。
- **孵化取得**：野外探索/解謎/特定採集可獲得「星曜卵」，帶回城內「曜化育生陣」
  （天玄院附屬設施）進行孵化，孵化需等待時間，可用靈砥加速，或透過12已定案社交系統
  請好友協助「注曜」縮短時間（縮短比例設上限，防濫用）。
- **孵化不掉落於08怪物系統的掉落表中**：星曜卵/曜脈節點捕捉為獨立產出管道，
  與08已定案的一般怪物掉落機制完全分離，避免刷怪同質化套利。

## 2. 星曜獸獨立成長曲線（不牽動05已定案9大境界）

- **等級**：Lv.1~上限（隨玩家進度開放），僅影響出場強度係數，不影響玩家本體境界。
- **資質分級（T1~T6）**：孵化/捕捉時依種源決定初始資質區間，資質分級名稱與04靈印
  的「黃玄地天聖」、10裝備的「凡精靈曜帝」完全區隔，避免玩家混淆三套品質系統。
- **培育資源**：以環境材料（06各地區採集/任務產出）與少量靈砥為主，曜金僅用於
  加速/外觀，非戰力堆疊的主要來源。
- **星曜獸成長不影響05已定案的境界突破判定**，兩者僅在戰鬥表現上產生疊加效果
  （例如境界越高，星曜獸輔助效率係數微幅提升），不互相取代。

## 3. 星曜獸戰鬥參與具體規則

- **專屬掛槽**：玩家可裝配1~3個星曜獸掛槽（隨進度開放），與04已定案的8槽靈印
  完全獨立。
- **參與形式（混合制）**：
  - **被動常駐光環**：裝配後持續生效的環境型加成（如減速抗性、受擊效率微調）。
  - **主動召喚出場**：手動觸發，固定時長內在場提供技能效果，結束後進入獨立冷卻
    （與03已定案雙脈切換冷卻互不干擾，可錯位使用形成節奏）。
- **效果分類（三選一或組合，依孵化資質決定開放上限）**：
  1. **控場**：節律干擾（暈眩/定身/延遲行動），以「回合節拍」呈現，不改寫戰鬥核心。
  2. **破防**：對特定弱勢狀態疊加「裂隙標記」，觸發破防窗口。
  3. **回收**：戰鬥中/戰後回復資源或降低消耗類進度損耗。

**星曜獸範例（4隻）**：
1. **霜魄冰狐**（控場型）：召喚釋放寒霜氣場，範圍內敵人減速並小幅疊加裂隙易傷。
2. **岩脊巨甲**（防禦/破防型）：被動降低受擊硬直消耗；召喚時提供護盾並嘲諷周圍敵人。
3. **風穴擎鶴**（資源/節奏型）：被動提升移速與雙脈切換冷卻恢復速度；召喚時牽引雜兵
   聚集並回復少量資源。
4. **回響刃犬**（破防型）：對處於破綻/失衡狀態的敵人提供傷害加成；召喚造成一次
   定點突進標記，降低目標防禦架勢。

## 4. 宿命契友：羈絆連攜技具體設計（6位角色各1個，呼應02已定案人物與流派）

- **好感度解鎖**（呼應07已定案好感度系統）：達到一定好感階段，解鎖「羈絆連攜技」
  被動資格；再達到更高階段，連攜效果強度與觸發成功率提升。
- **觸發時機**：玩家執行03已定案的雙脈切換時，進入8秒視窗，若當前配置的「出戰契友」
  在此視窗內完成指定動作或條件，即觸發連攜技（連攜技冷卻獨立計算，不與雙脈冷卻疊加，
  同場戰鬥設觸發次數上限防止無限連打）。
- **六位角色連攜技**（呼應各自流派定位）：
  1. **郁岑燁（劍）——「霜劍破陣」**：連攜瞬間附加冰系標記直線貫穿打擊，
     為後續劍系連段建立減速優勢。
  2. **厲若楓（弓）——「穿雲影矢」**：連攜時射出多重追蹤箭矢，標記並牽制遠距離目標。
  3. **齊衡烈（刀）——「怒刃裂地」**：連攜造成範圍震擊與短暫控制，替隊伍創造輸出空檔。
  4. **聞人澈（靈杖）——「澄息導流」**：連攜前置淨化負面狀態並回復生命，兼顧生存與續航。
  5. **蕭曜霖（重刃）——「山門壓影」**：連攜提供隊伍短暫抗打斷與穩定輸出視窗。
  6. **江祈璟（槍）——「貫曜同鳴」**：連攜強化破防轉換效率，加速破綻窗口形成。

## 5. 夥伴系統資源與14已定案雙幣制經濟掛鉤（防通膨、防與08重複）

- **靈砥（綁定，日常消耗為主）**：捕捉道具、日常餵養/孵化基礎加速、低階資質洗鍊、
  宿命契友好感度日常禮物。
- **曜金（可交易，高階/外觀為主）**：稀有外觀、育化設施擴建、高階資質鎖定型洗鍊、
  拍賣場交易稀有星曜卵/資質材料。
- **防通膨/防重複機制**：
  - 星曜獸成品與星曜卵**絕不進入08已定案的怪物掉落池**，產出管道完全獨立（地圖生態
    探索/孵化/週期活動），避免刷怪雙重套利。
  - 與夥伴養成直接掛鉤的曜金消耗設定**階段性上限與每日/每週次數上限**，防止課金
    直接堆疊戰力形成通膨破口。
  - 星曜獸維持親密度需持續消耗少量靈砥（親密度過低時被動光環效率打折），
    形成穩定的靈砥回收管道而非放置型無成本掛機。
