# 一、整體故事結構

《九曜：天墟》主線採五大篇章、二十五章結構：

```text
第一篇 青嵐篇      第1～3章   發現異常
第二篇 九州篇      第4～10章  認識世界與人族內部矛盾
第三篇 荒境篇      第11～16章 接觸妖族文明與異化真相
第四篇 天墟篇      第17～22章 進入舊界層，理解遠古歷史
第五篇 九曜終局    第23～25章 決定世界未來
```

整體情緒曲線：

> **校園成長 → 區域冒險 → 九州遠行 → 陣營衝突 → 妖族文明 → 世界危機 → 遠古真相 → 世界選擇 → 新時代**

玩家的身份也同步變化：

> 新契修 → 天玄院弟子 → 青嵐事件調查者 → 九州事件參與者 → 跨陣營同行者 → 天墟探索者 → 九曜危機的關鍵行動者。

玩家不是預言中的唯一救世主。真正讓玩家走到終局的，是一路累積的能力、同伴、關係、情報與選擇。

# 二、第一篇：青嵐篇

## 篇章主題

> **「我只是來修行，為什麼這座城開始不對勁？」**

青嵐篇負責讓玩家從「日常修行」第一次踏入世界異常。

### 第1章《青嵐試煉》

**既有任務級規格完整保留，以 `07_QUEST_DESIGN_V2.0.md` 為準。**

核心路線：

> 第七室報到 → 基礎演武 → 青嵐河谷調查 → 異化青牙狼 → 骨脈突破試煉 → 開脈境 → 古林通行印記 → 青嵐古林 → 三波清剿 → 陣眼殘響 → 赤瞳妖將先遣遭遇 → 裂口。

章末：玩家第一次看見天空裂痕，官方稱為「局部曜脈震盪」，但玩家與同伴知道事情沒有那麼簡單。

**赤瞳妖將此時不可擊殺。** 這是先遣遭遇，不是世界討伐戰。

### 第2章《青嵐異變》

青嵐城開始出現連續異常：河谷靈流逆行、野外妖獸異化、城內部分陣紋失效。

主線：

> 調查裂口殘留 → 天玄院封鎖區 → 朽骨祭司線索 → 青嵐秘境 → 秘境核心異常 → 發現古代陣列並非單純遺跡 → 朽骨祭司撤退。

玩家第一次意識到：有人可能正在主動利用天墟異常。

章末：青嵐秘境封印暫時穩定，但一枚古代陣紋指向青嵐之外。

### 第3章《裂谷回聲》

青嵐裂谷出現持續回聲，調查隊伍前往青嵐山脈。

主線：

> 裂谷調查 → 山脈異常生態 → 古代陣列節點 → 斷陣裂王 → 回收陣列核心 → 靈府境突破 → 發現九州各地存在相似節點。

章末：玩家第一次看到「青嵐只是整個系統的一個節點」的證據。

青嵐篇結束時，玩家不再只是學生，而開始主動追查事件。

# 三、第二篇：九州篇

## 篇章主題

> **「當你離開一座城，才發現每個地方都在講不同的真相。」**

九州篇擴大世界尺度，讓玩家接觸五大勢力與人族內部矛盾。

### 第4章《離院之路》

天玄院組成跨區調查隊，玩家獲准隨隊離開青嵐。

重點：
- 建立九州地理概念
- 第一次接觸州際運輸與大型城鎮
- 萬兵閣正式登場
- 玩家發現不同城市對「天墟」有不同稱呼

章末：調查隊收到第一份來自其他州的異常報告。

### 第5章《曜脈商路》

調查一條被異化妖獸襲擊的商路。

核心：人族為了資源開採曜脈，可能無意中改變了局部環流。

玩家首次面對「受害者與責任者可能同時存在」的事件。

### 第6章《星河舊卷》

玩家進入星河殿資料區，追查青嵐陣列與古代節點的關聯。

核心衝突：
- 封存資料派
- 真相公開派
- 利用天墟研究派

玩家第一次看到「天墟並非突然出現」的古代記錄。

### 第7章《萬兵殘器》

萬兵閣發現一件古代兵器材料正在產生異常共鳴。

主線連結裝備與鍛造系統：部分古代材料確實來自天墟舊界層。

章末：有人試圖奪走殘器，玩家開始確認存在主動利用天墟力量的勢力。

### 第8章《九州裂線》

多州同時出現空間裂口。

玩家必須分頭協助不同地區，但無法拯救所有地方。

本章建立 MMO 世界事件感：城市、野外、多人活動與大型防衛事件開始出現。

章末：九州聯盟宣布全面提高天墟封鎖等級。

### 第9章《封鎖令》

九州聯盟開始限制天墟相關情報與民間探索。

玩家的調查行動與官方政策產生衝突。

核心問題：

> 為了避免恐慌而隱瞞真相，是否會讓真正的危機更難處理？

玩家不被要求立刻選邊，而是透過任務與人物逐步理解各方理由。

### 第10章《赤瞳妖將・世界討伐戰》

青嵐篇曾經遭遇的赤瞳妖將再次出現，但這次已進入世界級事件。

規模：20～60人多人世界討伐戰。

核心：
- 多階段戰鬥
- 區域機制
- 陣眼防守
- 赤瞳妖將異化力量
- 玩家需要分工

戰鬥結束後，玩家發現赤瞳妖將並非單純被墟息侵蝕，而像是在保護某個更深層的東西。

這一章將「敵人」概念第一次翻轉。

# 四、第三篇：荒境篇

## 篇章主題

> **「如果敵人也有自己的歷史，那麼我們真正正在戰鬥的是誰？」**

玩家進入荒境妖庭勢力範圍，正式接觸妖族文明。

### 第11章《荒境邊界》

人族與妖族邊境衝突升高。

玩家任務從單純討伐妖獸轉為調查邊境事件。

發現部分妖獸異化後並未失控，甚至能保持理智。

### 第12章《妖庭來使》

一名妖庭使者秘密與玩家接觸，指出人族記錄中的部分歷史存在缺漏。

玩家第一次得知：妖族也保存著一套關於「第一次天墟災變」的歷史。

### 第13章《雙界舊史》

玩家進入妖族遺跡，看到遠古時代的人族與妖族曾共同研究九曜。

這推翻「妖族一直都是人族敵人」的簡單歷史觀。

### 第14章《墟息之民》

玩家遇見能穩定承受墟息的妖族／異化生命。

核心真相：

> 異化不一定等於墮落。

不同勢力因此產生三種主張：封鎖、研究、共存。

### 第15章《妖庭裂痕》

妖庭內部衝突爆發。

戰爭激進派希望利用天墟力量反攻人族；研究派試圖理解異化；合作派希望停止無止境戰爭。

玩家被迫在多方行動之間建立信任，而不是單純加入一個陣營。

### 第16章《荒境天門》

荒境深處的古代設施啟動。

玩家與人族、妖族部分角色共同阻止設施失控。

最終得到重要情報：

> 「天墟不是門外的東西。」

> 「門，本來就是九曜界自己造出來的。」

荒境篇結束，玩家開始理解真正的敵人不是某一個種族，而是失衡的世界系統與各方對它的不同利用方式。

# 五、第四篇：天墟篇

## 篇章主題

> **「你以為自己正在探索遺跡，其實你正在走進世界失去的一部分。」**

這一篇正式進入天墟深層。

### 第17章《裂界之門》

九州多個陣列節點同時失效，天墟開始大規模回流。

玩家取得進入天墟的資格，但這不是榮耀，而是一項高風險任務。

### 第18章《舊界層》

玩家第一次真正進入天墟。

發現其中並非單純荒蕪之地，而存在：
- 破碎城市
- 古代生命痕跡
- 仍在運作的曜脈結構
- 與現代九州相似卻不同的地貌

玩家開始理解「舊界層」的含義。

### 第19章《斷代者》

玩家找到遠古時代留下的記錄。

揭露第一層核心真相：

> 遠古時代九曜失衡，先民無法修復，只能切離部分世界結構。

但記錄同時顯示：

> 切離並沒有真正解決問題，只是把問題延後。

### 第20章《九曜殘環》

玩家調查九個核心節點，理解九曜並不是九種單純元素，而是世界運行規律。

玩家的靈印、修行、妖獸異化、秘境與空間穩定開始被串成同一套世界規則。

### 第21章《歸墟之潮》

天墟大規模回流。

人族與妖族必須暫時合作。

各地同時發生世界事件，玩家與其他玩家共同維持節點。

本章是全遊戲第一個真正意義上的大型跨區世界危機。

### 第22章《天墟真相》

玩家取得完整遠古記錄。

正式揭露：

> **天墟是九曜界曾經被強行切離的舊界層。**

> **現在的天墟裂變，本質上是被隔離的舊界層正在重新回流。**

但真相揭露並不等於答案揭露。

玩家此時才真正面對終局問題：

> 要重新封死天墟，還是尋找與舊界層共存的方法？

# 六、第五篇：九曜終局

## 篇章主題

> **「世界沒有正確答案，只有你願意承擔的答案。」**

### 第23章《九曜失衡》

九條曜脈開始出現全面性失衡。

各勢力提出不同方案：

1. 永久封鎖天墟。
2. 強行吸收天墟力量。
3. 重新切割舊界層。
4. 建立新的九曜循環。

玩家需要收集前二十二章累積的資料、盟友與節點成果。

### 第24章《最後陣眼》

玩家與主要同伴進入世界核心區域。

過去遇到的角色與勢力依照玩家一路建立的關係參與最終行動。

這裡不以「玩家一個人打最終 Boss」作為唯一高潮，而是讓整個旅程的人與選擇回到終局。

最終敵對力量不是單純人格化的魔王，而是失控的九曜／天墟回流機制，以及試圖利用它的人。

### 第25章《新曜紀》

最終行動完成後，世界不直接恢復成原狀。

天墟與九曜界的關係被重新定義。

結局依玩家前期累積的世界狀態、勢力關係與關鍵任務完成度產生不同表現，但不把玩家做成「選一個按鈕就改世界」的簡單分歧。

核心結局方向：

**A．封界方案**

天墟再次被隔離，短期世界恢復穩定，但仍留下未解問題。這是「延續舊方法」的結果。

**B．共鳴方案**

建立新的九曜循環，使部分舊界層與現世開始穩定共存。世界進入未知的新時代。

**C．重構方案**

玩家與各方共同完成九曜結構重組，代價最大、世界變化也最大。部分舊有規則被永久改寫。

三種方向不是單純善惡結局，而代表三種不同的世界治理哲學。

最終畫面：

> 九曜重新運轉。
>
> 天空中的裂痕沒有完全消失。
>
> 但它不再只是「災難的裂口」。
>
> 遠方，一道新的曜光穿過天際。
>
> 新時代開始。

# 七、主要角色長期弧線

## 江祈璟

定位：競爭者 → 同行者 → 關鍵戰友。

弧線：

> 初見時嚴格要求玩家 → 青嵐事件中建立實力上的尊重 → 九州篇共同調查 → 赤瞳妖將事件後開始信任玩家判斷 → 荒境篇面對人族歷史矛盾 → 天墟篇承認過去的答案未必正確 → 終局與玩家並肩。

他不是傳統反派，也不是無條件好友，而是玩家一路成長的鏡像角色。

## 郁岑燁

定位：第七室核心同伴、理性型支援。

弧線：

> 觀察玩家 → 建立合作 → 對天玄院制度產生疑問 → 追查資料 → 最終成為理解九曜規則的重要人物。

## 厲若楓

定位：冷靜觀察者。

弧線：

> 少言觀察 → 開始主動提供判斷 → 在勢力衝突中學會表態 → 終局選擇相信同伴而不是只相信制度。

## 齊衡烈

定位：熱血型同伴。

弧線：

> 喜歡切磋 → 追求變強 → 第一次遭遇真正世界級危機 → 理解力量不是只有勝負 → 最終成為保護同伴與普通人的戰士。

## 聞人澈

定位：內斂、可靠的編外友人 → 核心同行者。

弧線：

> 古林支援 → 逐漸加入第七室圈子 → 對異化生命抱持不同於主流的理解 → 荒境篇成為連接人族與妖族的重要人物之一。

## 蕭曜霖

定位：教官／前期導師。

弧線：

> 只教玩家怎麼活 → 開始透露天玄院真正責任 → 面對學生捲入世界危機 → 最終選擇讓年輕一代知道真相，而不是繼續替他們決定答案。

# 十、故事設計硬規則

1. 第一章不能揭露天墟最終真相。
2. 赤瞳妖將第一章只能先遣遭遇；第10章才進入世界討伐戰。
3. 玩家不是天選之子。
4. 妖族不是純粹反派。
5. 異化不是單純邪惡。
6. 五大勢力都必須存在合理動機與內部分歧。
7. 九曜不能被簡化成九種普通元素。
8. 天墟不是普通副本或單一遺跡，而是被切離的舊界層。
9. 遠古真相必須分層揭露。
10. 終局不是單純擊殺魔王後世界恢復原狀。
11. 玩家選擇必須透過長期行動累積產生影響，而不是只靠最後一個選項。
12. 遊戲主線是正史；動畫補完，不得反過來覆蓋遊戲核心因果。
13. 後續任務、NPC、地圖與動畫設定若與本文件衝突，先檢查本文件與 V1.0 的核心真相，再修改下游內容。
