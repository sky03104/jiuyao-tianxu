# 《九曜：天墟》UI/UX 設計原則 V1.0

> 狀態：**細節定案（第二階段補完）**，具體數值為初版示意值，需 Phase 0 原型測試後調整，
> 標記為「可調整」。
> 產生方式：GPT/Gemini/DeepSeek 三方交叉草擬，Claude審查未發現與已定案內容
> （03戰鬥/04靈印/05屬性/09BOSS/12社交/16美術）衝突，整合三版優點定案。

## 1. 戰鬥介面完整佈局規格

- **左下角・移動控制區**：常駐虛擬搖桿，半透明水墨暈染風格，固定於左下12~15%區域，
  支援大小/位置/透明度自訂，不遮擋下方資訊。
- **左上角・角色資源區**（呼應03已定案資源條）：頭像＋HP（紅）／MP（藍）／氣力（黃）
  橫向疊加條；絕技能量以0~100環形光圈呈現於頭像外圈，集滿時觸發水墨金焰擴散提示；
  頭像下方最多顯示5個當前異化/增益狀態圖示。
- **右下角・弧形扇面技能區**（呼應03已定案六流派操作節奏）：中央為普攻（依流派顯示連段
  進度點），內弧為流派技能鍵，外弧為絕技鍵，下緣為閃避鍵，扇面頂端獨立配置雙脈切換鍵
  （切換瞬間0.3秒特效與圖示變化）；技能冷卻以扇形遮罩+倒數數字呈現，資源不足時呈灰階
  半透明。
- **頂部・目標與BOSS狀態區**（呼應09已定案韌性條/破綻窗口）：一般怪物僅顯示名稱/HP/
  距離；BOSS額外顯示韌性條（附加條紋材質，不僅靠顏色）與破綻倒數，破綻觸發瞬間於目標
  周圍出現高對比朱紅水墨光圈脈衝，明確提示輸出窗口。
- **右上角・系統與自動戰鬥區**（呼應12已定案安全區/戰鬥區分流）：小地圖（含安全區/
  戰鬥區標示）、Auto三態切換鍵（關閉/保守模式/全自動），遇到高機制技能前，畫面中央
  彈出「高威脅機制，請手動接管」提示並倒數2秒自動移交操作權。

## 2. 非戰鬥介面設計

- **主選單導航**：底部固定「角色／背包／靈印／修行／社交」五分頁，戰鬥中鎖定，
  進入安全區自動解鎖。
- **角色/修行頁面**（呼應05已定案六大屬性養成）：左側3D角色模型可360度檢視，
  右側六大屬性雷達圖＋詳細數值面板，點擊單一屬性可彈出突破/分配微調視窗，
  資源不足時導引至背包對應材料。
- **背包系統**：5x4網格式，分「全部/裝備/靈印/消耗品/材料」五大頁籤，支援搜尋/篩選/
  批次分解/鎖定，選中物品於右側顯示詳細資訊卡（品質色框＋詞條）。
- **靈印頁面**（呼應04已定案8槽位系統）：中央呈現8槽位陣盤（可用八卦方位裝飾呈現，
  僅作視覺排列樣式，不影響機制），點擊槽位右側滑出對應屬性靈印背包，支援「一鍵推薦
  裝配」與連鎖組合預覽，並提供3組自訂配裝方案供快速切換。
- **社交分流頁面**（呼應12已定案）：常駐左下角迷你聊天列，展開後分「大世界／安全區／
  隊伍／公會」頻道頁籤，戰鬥區時自動收合世界/區域雜項廣播。

## 3. 新手引導UI設計原則（漸進式，不塞爆）

- **階段式解鎖**：
  1. 初期僅顯示移動搖桿與普攻鍵。
  2. 首勝後解鎖閃避與第一個流派技能。
  3. 約Lv.5解鎖第二/第三技能與絕技能量條。
  4. 完成首個突破試煉後解鎖雙脈切換與靈印頁面（僅開放裝備1槽教學）。
  5. Lv.10前後才完整開放修行頁面全屬性配置。
- **情境式提示**：不使用強制全螢幕遮罩教學，採「實體動作觸發」——例如BOSS首次釋放
  重擊時，畫面局部減速並高亮閃避鍵，引導玩家當下完成操作而非預先看教學文字。
- **資訊節流**：每個引導步驟最多同時出現2個新資訊點，且教學提示可跳過/重播，
  訓練場模式提供無限重練環境。
- **首次高機制/BOSS教學**：自動戰鬥首次啟用時彈出三段式簡短說明；首次遭遇BOSS韌性條/
  破綻機制時，提示視窗僅出現一次並可在設定中重新開啟。

## 4. 無障礙/易用性考量

- **色弱適配**：所有靠顏色區分的資訊（HP/MP/氣力條、增益減益、韌性/破綻狀態）皆搭配
  「圖形/紋理/形狀」雙重編碼（如HP用實心紋理、MP用波紋紋理、氣力用階梯紋理），並提供
  紅綠色盲、藍黃色盲濾鏡模式，高亮色可切換為高對比純黃/純青替代色。
- **操作簡化選項**：
  - 扇面技能鍵位大小可調（80%~120%）與位置微調。
  - 提供「防誤觸保護」：滑動需超過閾值才觸發確認類技能。
  - 自動戰鬥高機制技能介入時機可自訂「永遠自動／永遠詢問／依機制等級詢問」三檔。
  - 提供輔助瞄準（自動朝最近敵人修正方向）滑桿選項。
- **視覺對比**：BOSS破綻/機制提示的高對比模式預設開啟，可於設定關閉降低視覺刺激。

## 5. UI視覺風格呼應16已定案（東方幻想美術方向）

- **色彩計畫**：低飽和水墨底盤（玄青、墨灰半透明宣紙質感），僅在關鍵提示（絕技滿蓄／
  靈印觸發／破綻窗口／機制警示）局部啟用高亮靈光配色，遵循「同一類提示固定同一配色與
  形狀」原則，降低學習成本，且與16美術方向的「低飽和主體+局部高亮靈光」完全一致。
- **線條與材質**：UI邊框採古風細線描邊（圓角+符文短刻度），彈出視窗使用半透明暗玉
  質感搭配邊緣微弱靈光泛影，避免現代粗直框。
- **動態反饋**：按鍵按下反饋採水墨擴散+微弱靈光閃爍，響應時間控制在80ms以內，
  確保視覺氛圍與操作流暢手感兼顧。
- **字體與圖示**：以可讀性優先的古風字體呈現，資源數值使用固定高對比字重確保戰鬥中
  快速辨識。
