# 《九曜：天墟》UI/UX 設計原則 V1.0

> 狀態：**大綱級定案**，核心方向已鎖定，個別畫面規格待第二階段補完，標記為「可調整」。

## 核心方向

- 手機雙搖桿核心佈局：左側常駐虛擬搖桿控制移動，右側以弧形扇面配置普攻、技能、閃避、
  絕技與切換戰鬥路徑（雙脈一鍵切換鍵）。
- 高資訊密度控管：戰鬥中僅保留血條/靈力條/目標距離/靈印觸發狀態/異化狀態與剩餘冷卻，
  其餘深度資訊（靈印組合、境界突破進度）收納到背包/修行頁面，避免戰鬥時畫面干擾操作。
- 自動戰鬥需有明確狀態欄：Auto循環/保守模式/手動接管切換，並在高機制技能（絕技、控制鏈
  起手）前提示「是否需要手動確認」。
- 重要BOSS機制（如硬直條、招式預警圈）使用高對比古風光圈提示，確保手機端操作精準且
  無視覺雜亂感。
