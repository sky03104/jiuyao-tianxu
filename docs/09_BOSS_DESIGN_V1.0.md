## 1. 世界BOSS赤瞳妖將：完整雙階段機制設計

**隊伍前提**（呼應08已定案方向）：需槍系可打斷核心鎖定、重刃可承接爆發、靈杖可淨化濁氣，
鼓勵刀/劍/弓等其餘流派多樣化配置。

### Phase 1：血色陣眼・鎖定期（HP 100%→45%）
- **陣眼招式（血瞳鎖域）**：地面生成血色陣眼核心圈，赤瞳妖將短暫站樁，形成「陣眼鎖定
  讀條」（3秒）。讀條完成後生成鎖線向未處理區域造成高傷與減治。
- **破局需求（槍系打斷）**：槍系流派需於讀條內命中核心命中框，達成「打斷」：成功則
  妖將停滯0.8秒並進入「破綻狀態」。
- **濁氣機制（靈杖淨化）**：鎖線生成後每5秒噴出「濁氣吐息」形成濁氣池（持續12秒），
  靈杖可用連續施法2段的淨化法陣使濁氣池失效，並在失效瞬間為隊伍提供短暫增傷
  （僅在破綻窗口內生效）。
- **破綻窗口**：打斷成功後0.8秒「核心破綻」+0.8秒「擴散破綻」，共約1.6秒，此時期核心
  受傷倍率提升，並獲得「韌性削減上限提升」（見第3節）。

### Phase 2：血色陣眼・爆發期（雙階段硬切換，HP降至45%或Phase1完整循環2次觸發）
- **爆發招式（陣眼反噬・瞳爆）**：陣眼重新生成核心，周圍升起三層環形護盾（每層1次承傷
  倍率），並召出「瞳刃殘影」干擾站位。
- **破局需求（重刃扛傷承接）**：重刃需使用承接/扛傷技能在護盾生成後的第一段瞳爆
  （0.5秒判定窗）承受，成功後將爆發能量導入重刃體內形成「蓄爆」；蓄爆滿格時釋放可造成
  「核心瞬破」，使護盾直接剝離一層。
- **輪替配合**：護盾每剝離一層，槍系下一次打斷更容易命中核心；靈杖在濁氣吐息期間維持
  場地乾淨以避免隊伍被迫分散。
- **破綻窗口（最終）**：「瞳爆第一段」承接成功後，立即進入2.0秒「核心破綻」（全隊可
  集中輸出）；若重刃未承接且靈杖未淨化，破綻窗口會被「回潮」縮短至1.0秒，造成極限爆發
  機會損失。

## 2. 天墟巨魔：朽骨祭司 / 斷陣裂王 完整BOSS戰機制

### 朽骨祭司（召喚型・殘魂封域）
- **Stage 1（HP 100%→70%，殘魂封域啟動）**：於場地四象位生成封域柱（每柱可承受2次
  攻防判定），封域完成後召喚「亡靈殘影」在場內循環巡邏。
  - 破局手法：亡靈殘影每次生成後有0.9秒「靈體空窗」（受硬直/群控命中時延長至1.3秒），
    刀/弓負責清理殘影追打施法者站樁，阻止封域循環完成。
- **Stage 2（HP 70%→35%，封域回收）**：封域柱間連線形成吸附線（持續9秒）。
  - 破局手法：槍系需在吸附線生成後2秒內刺穿其中一節（擊破節點=解除整條吸附線）；
    若未擊破，殘影會吸收連線能量獲得高韌性，導致該段輸出停滯。
- **Stage 3（HP 35%→0，殘魂崩解）**：全場濁灰彌漫，召出「殘影殘影」疊影。
  - 破局手法：靈杖淨化「濁灰核心區」，完成後殘影落入地面形成2.5秒站樁破綻，
    重刃在破綻期負責收割並承接殘影最後爆炸。

### 斷陣裂王（地形毀滅型・裂地脈爆）
- **Stage 1（HP 100%→60%，殘陣地脈）**：地面生成裂紋網，每6秒擴張，擴張末端形成
  「脈爆點」。
  - 破局手法：弓/刀負責拆脈爆點——目標脈爆點被命中3次後停止擴張並短暫碎裂（0.8秒），
    碎裂期間可對巨軀弱點輸出。
- **Stage 2（HP 60%→30%，巨軀化）**：裂王進入「巨軀化」，減少被控但提高移動慣性，
  弱點從頭部轉為胸前「陣核」。
  - 破局手法：槍系瞄準陣核反覆打出「點破」，累計3層點破才會觸發短暫破綻。
- **Stage 3（HP 30%→0，裂地脈爆）**：隨人數擴散的地脈爆炸圈隨機刷新。
  - 破局手法：重刃負責「前置承接爆炸圈外緣」，承接成功可把爆傷轉化為蓄爆
    （同時為隊友創造2.0秒輸出通道）；靈杖在蓄爆釋放瞬間做「淨心抑制」，避免隊伍被
    濁傷灼燒波及。

## 3. 副本BOSS（20~50人）韌性條機制具體規則

- **韌性條數值範圍**：初始1000~1800（依BOSS難度分檔），每副本BOSS獨立設定。
- **削減方式**：
  - 一般攻擊：每次命中削減韌性1~3。
  - **正確破局打點**（對應武器流派破招）：每次削減80~140。
  - 錯誤流派強行輸出：僅削減10~25（降低「無效輸出」的手感但不完全歸零，保留參與感）。
- **破綻窗口持續時間**：韌性歸零觸發「破綻狀態」，持續6~10秒（依難度），
  結束後韌性重置為初始值的30%（而非直接歸零重來，避免無限刷新破綻）。
  破綻期間BOSS受到傷害倍率提升1.6~2.2倍，並額外暴露弱點（提升命中判定寬容度）。
- **雙脈流派極限爆發加成**（呼應03已定案8秒切換冷卻）：破綻觸發後8秒內完成一次雙脈切換，
  即可獲得「極限爆發」：破綻期輸出增幅+25%~+40%，且使韌性後續回復速度下降20%
  （讓破綻更穩定、更容易被連續打滿）。

## 4. 世界BOSS全區玩家分工機制

- **狂暴倒數運作**：全服狂暴倒數初值180秒（依難度檔調整），每秒遞減；任何分線未完成
  對應階段破局（未打斷核心鎖定/未淨化濁氣/未擊破護盾）都會使倒數加速1.2~1.8倍，
  逼迫各分線玩家維持節奏而非拖時間硬耗。
- **動態血量隨人數調整**：
  `當前總血量 = 基準血量 × (0.85 + 0.15 × (1 − 在場人數/期望人數))`，
  期望人數依難度檔預設（如20/40/60人檔），確保人少血量降低、人多血量提高，
  避免「越多人越輕鬆碾壓」或「人少打不動」的兩極體驗。
- **武器流派分工角色**（以赤瞳妖將為範本）：
  - **槍系（最關鍵）**：每輪負責打斷核心鎖定讀條，並在破綻期首段提供連續點破。
  - **重刃**：負責指定區塊站樁承接爆發，降低全場死亡率，並在破綻期集中輸出。
  - **靈杖**：淨化濁氣池/濁灰核心，維持場地乾淨可輸出狀態；若淨化失效，後續狂暴倒數
    會被加速。
  - **刀/弓（輔助破局）**：清理殘影/脈爆點等地形機制構件，確保「破局窗口」能被正常命中。

## 5. BOSS掉落對應Build缺口的具體規則

**判定核心：缺什麼就給什麼，但給的是「可補齊的Build零件」而非直接成品。**

伺服器統計每位玩家擊殺時的3類缺口：
1. **武器流派缺口**：當前主裝（武器槽）是否具備本BOSS指定的破局流派（如赤瞳妖將
   指定槍/重刃/靈杖）。
2. **靈印組合缺口**：8槽靈印中，是否缺少與本BOSS破招關聯的核心連鎖組合
   （例如缺少完成「破局連鎖」所需的2~3件靈印）。
3. **境界/裝備門檻缺口**：玩家經驗已足以突破但受05已定案的境界壓制限制
   （缺少突破試煉材料或對應境界的裝備門檻）。

- **發放規則**：依三類缺口各自的「缺口權重分數」，掉落最高分項目對應的Build零件：
  - 缺武器流派：優先掉落該流派的武器模組/專精材料。
  - 缺靈印連鎖：優先掉落靈印零件/升階素材，直接指向其所缺的連鎖組件。
  - 缺境界門檻：優先掉落突破試煉材料或境界對應的裝備配方。
- 若三類缺口皆已補齊，掉落轉為通用強化資源（材料/靈砥），避免持續重複發放同類材料。
