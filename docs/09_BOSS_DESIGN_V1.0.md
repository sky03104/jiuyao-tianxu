# 《九曜：天墟》BOSS設計原則 V1.0

> 狀態：**大綱級定案**，核心方向已鎖定，個別BOSS機制規格待第二階段補完，標記為「可調整」。

## 核心方向

- 摒棄純血條怪，強調多階段機制型戰鬥：
  - **副本BOSS**（20~50人 instance）：具備明確破局機制（破甲階段/地形毀滅/元素盾解密等），
    需要特定武器流派（如槍/重刃打破韌性、靈杖解控）與靈印搭配破招，並具「韌性條」機制——
    削減至零觸發破綻狀態，此時切換雙脈流派可打出極限爆發。
  - **世界BOSS**（如赤瞳妖將）：世界事件觸發制、非常駐，全服多分線同步刷新，具備狂暴倒數與
    動態血量，強調全區玩家分工（拉怪、輸出破核、輔助淨化），以操作與默契取代數值輾壓。
- BOSS 戰需提供「操作獎勵」：閃避路徑成功能縮短充能/降低下一段傷害，鼓勵手動玩法；
  自動戰鬥則以保守模式確保不被一擊打穿。
- BOSS 掉落需對應 Build 缺口：靈印材料、裝備配方、或境界突破材料，避免與其他資源重疊過量。
