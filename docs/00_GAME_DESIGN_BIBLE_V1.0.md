## 0. 專案核心方向

本遊戲是一款以手機玩家為主的「東方幻想 MMORPG」。

核心創作方向：

- 喜歡大型東方妖魔世界的劇情張力與少年成長感。
- 喜歡學院成長、開放世界、多人副本、PVP、生活玩法與社交系統。
- 不直接使用任何既有作品的人物、地名、勢力、專有名詞、劇情或力量體系。
- 本專案必須發展成獨立原創 IP，而不是單純替換名稱的衍生作品。
- 可以吸收「東方修行、妖魔、人族、學院、少年成長、世界危機」等廣泛題材元素，但世界觀、角色關係、劇情、名詞、系統與視覺識別必須自行建立。

商業化前仍應由專業 IP/法律人士進行最終檢視，本文件不構成法律意見或侵權保證。

# 2. 世界觀總體概念

暫定世界名稱：

## 九曜界

九曜界是一個存在特殊「曜脈」力量的東方幻想世界。

人族、妖族、異獸與古老勢力共同存在。

很久以前，世界曾發生過一次未知的大災變。

這場災變造成：

## 「天墟裂變」

天空與空間出現異常裂口。

部分區域受到未知力量污染。

妖獸開始發生異化。

古代遺跡重新出現。

人族與妖族之間的平衡逐漸崩壞。

玩家就在這個時代開始自己的修行之路。

# 11. 突破系統

不要單純：

# 35. 地圖解鎖方式

不採用單純：

「等級達到 → 自動開地圖」

採用：

## 劇情 + 境界 + 探索條件

例如北境雪原：

- 靈府境
- 完成「雪原調查」
- 擊敗「冰魄妖王」

才正式開放。

目的：

讓玩家有「我終於有資格踏入這個地方」的成長感。
