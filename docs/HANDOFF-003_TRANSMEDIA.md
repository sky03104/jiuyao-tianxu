# 《九曜：天墟》HANDOFF-003：赤瞳妖將尺度收斂＋跨媒體動畫規格

> 日期：2026-09-15
> 發起者：ChatGPT
> 狀態：待 Claude Code 執行
> 目的：在進入 Phase 0-A Unity 技術 Spike 前，正式解決赤瞳妖將的劇情遭遇／世界 Boss 尺度衝突，並把「遊戲＋動畫＋短影音」納入正式 IP 開發規格。

## 一、任務背景

使用者已正式同意《九曜：天墟》採「遊戲 × 動畫 × 短影音」的跨媒體 IP 方向。

核心原則：

1. 遊戲是主要互動正史。
2. 動畫不是把遊戲劇情逐集重播，而是補充世界觀、角色視角、幕後事件與玩家看不到的真相。
3. 動畫不得與遊戲正式核心規格互相矛盾。
4. 遊戲、動畫、PV、Shorts／抖音應盡量共用角色、場景、武器、怪物、特效等 3D 資產。
5. 不因製作動畫而建立第二套完全獨立的角色／場景資產。
6. 「遊戲正史 > 動畫補完」；若動畫與遊戲發生衝突，先修動畫，除非使用者重新鎖定正式世界觀。

## 三、赤瞳妖將正式收斂決策

目前規格衝突：`09_BOSS_DESIGN_V1.0.md` 將赤瞳妖將定義為 20～60 人規模的世界 Boss，而 `07_QUEST_DESIGN_V2.0.md` 第一章包含「赤瞳妖將先遣遭遇」。

正式決策：

### 1. 第一章不是完整世界 Boss 戰

第一章的赤瞳妖將只能是「先遣遭遇／劇情戰」。

玩家不在第一章真正擊殺赤瞳妖將。

戰鬥目的：
- 展示其遠超現階段玩家的威脅。
- 教玩家理解陣眼、墟息與異化的關聯。
- 讓江祈璟與其他角色參與撤離／掩護／限制，而非完成世界 Boss 機制。
- 最終由赤瞳妖將主動撤退、陣眼異變或天墟裂口干擾，使戰鬥中止。

### 2. 後續正式世界 Boss 保留 09 的完整設計

後續赤瞳妖將世界事件才使用：
- 20～60 人動態規模。
- 雙階段 Boss 機制。
- 槍系打斷。
- 靈杖淨化。
- 重刃承接爆發。
- 動態生命值／狂暴計時。
- 多流派協作。

不得為了第一章方便而刪除或縮小 09 的世界 Boss 正式設計。

### 3. 名稱區分

建議在正式任務與 Boss 文件中明確使用：
- 「赤瞳妖將・先遣遭遇」＝第一章劇情戰。
- 「赤瞳妖將・世界討伐戰」＝後續正式世界 Boss。

兩者是同一世界角色／Boss，不是兩隻不同 Boss。

## 四、建立正式跨媒體文件

請新增：

`docs/22_TRANSMEDIA_ANIMATION_PLAN_V1.0.md`

內容至少包含：

### 4.1 跨媒體定位

定義《九曜：天墟》為可同時承載：
- MMORPG／RPG 遊戲
- 長篇動畫／遊戲 Cinematic 式動畫
- YouTube 長片
- YouTube Shorts
- 抖音短影音
- 遊戲 PV／角色 PV
- 開發紀錄

### 4.2 三種敘事層

**遊戲：玩家視角**
- 玩家是主要行動者。
- 玩家透過探索、戰鬥、任務逐步認識世界。

**動畫：世界／角色視角**
- 展示玩家看不到的事件。
- 深化角色動機。
- 補充勢力與歷史。
- 可以提前埋伏筆，但不得直接破壞遊戲主線的謎團節奏。

**短影音：內容入口**
- 角色片段。
- 世界觀解說。
- Boss 介紹。
- 開發幕後。
- 動畫精彩片段。

### 4.3 第一季方向

第一季以「青嵐篇」為主軸，先不要一次鎖死全部集數細節，但至少建立 8～12 集的高層骨架。

第一季應與遊戲第一～三章互相呼應，但不逐字逐任務重播。

建議敘事方式：
- 遊戲第一章：玩家進入天玄院、河谷調查、突破、古林、先遣遭遇。
- 動畫：可以從江祈璟、天玄院教師、古林監測者、其他角色視角切入，讓觀眾看到同一事件背後的另一面。
- 第一季不能提前揭露天墟最終真相。

### 4.4 遊戲／動畫時間線

建立一份時間線規則，至少區分：
- 天墟裂變前
- 第一章青嵐試煉
- 第二章青嵐異變
- 第三章裂谷回聲
- 後續青嵐篇
- 九州篇
- 荒境篇
- 天墟篇

動畫可以插入過去事件，但必須標明相對時間與正史狀態。

### 4.5 共用資產規範

未來 Unity 資產必須考慮 Cinematic／動畫用途：
- 角色模型
- 骨架
- Facial／表情
- 動畫 Clip
- 武器
- 場景
- 怪物
- Boss
- VFX
- 材質

禁止為動畫建立與遊戲完全不同且無法共用的主要角色資產，除非有明確藝術或技術理由並經確認。

### 4.6 Cinematic 技術需求

請提出對 `17_TECH_ARCHITECTURE_V1.0.md` 的影響建議，至少考慮：
- Timeline／Sequencer 類系統。
- 角色表情控制。
- 鏡頭資料。
- 場景燈光／後處理。
- NPC／Boss Cinematic 行為。
- 遊戲內過場與獨立動畫輸出的資產共用。

不要在本階段實作完整動畫系統；先形成技術規格與最小可行方向。

## 五、動畫第一季高層故事骨架

請以正式世界觀為準，提出 8～12 集高層骨架。每集至少寫：
- 集數
- 暫定標題
- 主視角角色
- 時間位置
- 核心事件
- 新增世界資訊
- 與遊戲哪個章節互相呼應
- 集尾鉤子

不得直接抄寫其他作品的劇情、人物或專有設定。

## 六、短影音內容策略

1. 角色短篇
2. 世界觀短篇
3. Boss／戰鬥短篇

目標是讓沒有玩遊戲的人也能看懂，並自然導向《九曜：天墟》世界觀與遊戲。
