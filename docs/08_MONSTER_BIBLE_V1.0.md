## 1. 四分類具體怪物設計（已定案5隻不可改名）

### 一般野獸（低威脅，多為群居）
- **青牙狼**（已定案）：群居獵殺，1隻領頭吸引仇恨，側翼包夾，撕咬附加流血。
- **赤尾狐**（已定案）：高敏捷，採「襲擊-撤退」戰術，噴灑尾霧干擾視線與移速。
- **黑羽鴉**（已定案）：飛行偵查型，遠程俯衝襲擊，受擊會發出警戒尖叫召來同伴。

### 古林妖獸（威脅中等，具基礎靈氣與智能）
- **岩甲獸**（已定案）：重裝防禦型，背生岩晶，常態物理減傷，招式為「縮殼滾撞」與
  「裂地震波」。
- **河谷巨蟒**（已定案）：伏擊控場型，潛伏水域/草叢，技能「巨蟒纏繞」（需QTE掙脫）與
  「腐蝕毒液」。
- **碧玉毒蟆**（新增）：空戰範圍型，施放廣域麻痺粉塵，配合蹲踞跳躍製造中距離輸出。

### 異化妖獸（源於天墟裂隙洩出的濁氣侵蝕，核心設計主軸）
- **血眼裂狼**（異化青牙狼）：狂暴撕咬+濁息標記。
- **赤絲狐影**（異化赤尾狐）：尾焰血化+鏡影反擊。
- **濁鱗妖蟒**（異化河谷巨蟒）：鱗刺化+濁液吞咽。
- **黑羽噬影**（異化黑羽鴉）：群體追襲+暗紅羽噬。

### 天墟巨魔（高威脅，異化源頭或陣眼具象化）
- **赤瞳妖將**（已定案世界BOSS）：血色陣眼核心具象，雙階段機制型戰鬥。
- **朽骨祭司**：召喚亡靈殘影，技能「殘魂封域」。
- **斷陣裂王**：殘陣巨軀化（偏地形型），技能「裂地脈爆」。

## 2. 異化機制的具體視覺/數值/行為變化規則

- **視覺**：眼睛由自然瞳色轉為暗紅血瞳並伴隨瞳孔脈紋跳動；體表出現濁氣紋路（像裂隙灌入的
  血絲）；命中後留下短暫可見的「濁氣印痕」。
- **數值**：威脅層級+1；新增「濁氣標記」機制——被命中/命中角色時疊加標記（最多3層），
  疊滿觸發短暫狂暴（攻速/傷害提升，同時防禦下降，呈現高輸出高破綻的狂暴型態）；
  對非剋制屬性/流派的控制效率降低。
- **行為模式改變（非換色換皮）**：
  - 原本單體直線攻擊 → 異化後追加連續突進或範圍濁氣爆裂，攻擊前搖縮短。
  - 原本受擊會後退的怪物 → 異化後受擊短暫免疫硬直，甚至觸發反擊。
  - 血量低於30%時，異化個體強制進入10秒霸體狂暴狀態，招式全面強化並解鎖範圍終結技。
- **掉落**：首次擊殺必定掉落「異化靈核」（裝備/靈印進階關鍵材料）。

## 3. 怪物與六大武器流派剋制設計（直接使用03已定案的流派名稱）

依怪物的防禦特性/行動模式決定剋制關係，而非硬套元素表：

- **重裝甲殼型**（如岩甲獸、血眼裂狼的濁氣硬殼變體）：**槽/重刃**破防效率高
  （重刃霸體對撞、槍系穿刺破甲），**弓**系穿透力不足打擊效率較低。
- **高機動群居型**（如青牙狼、赤絲狐影）：**靈杖**範圍控制與**劍**系高頻連段能有效
  壓制群體節奏，**重刃**大硬直招式容易被群體包夾打斷。
- **潛伏/伏擊型**（如河谷巨蟒、濁鱗妖蟒）：**弓**系遠程風箏可提前拉開安全距離，
  **刀**系需承擔近身纏繞的高風險。
- **飛行/空戰型**（如黑羽鴉、黑羽噬影）：**弓**系與**靈杖**遠程壓制效果最佳，
  **刀/重刃**近戰流派難以觸及。
- **天墟巨魔（陣眼/BOSS級）**：多階段需要流派輪替，如赤瞳妖將需槍系打斷陣眼鎖定、
  重刃扛傷承接爆發、靈杖淨化濁氣，單一流派難以獨立應對，鼓勵隊伍配置多樣化
  （呼應05已定案的隊伍配置加成機制）。

## 4. 圖鑑解鎖與加成規則

- **解鎖節點**（依累計擊殺數，每隻怪物獨立計算）：
  - 1級（擊殺1隻）：解鎖生態背景與基礎數值，加成 +1% 對應屬性抗性/傷害。
  - 2級（累計5隻）：解鎖弱點部位與行為模式解析，加成 +3%。
  - 3級（累計15隻）：解鎖異化原因與完整掉落表，加成 +5%，異化個體對玩家的濁氣標記
    疊加速度降低10%。
- **區域圖鑑總完成加成**：青嵐地區圖鑑全數解鎖3級後，額外提供全隊「異化抗性+10%」，
  作為長期收集動力。

  考驗玩家範圍控制與走位。

  需要靈活切換閃避節奏與流派應對纏繞機制。
- **第三波：陣眼核心・精英前哨**：朽骨祭司×1（作為陣眼守護精英）+ 血眼裂狼殘部×2，
