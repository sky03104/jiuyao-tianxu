# 《九曜：天墟》怪物圖鑑設計原則 V1.0

> 狀態：**大綱級定案**，核心方向已鎖定，完整圖鑑資料表待第二階段補完，標記為「可調整」。

## 核心方向

- 怪物分類建議採「行為/威脅層級」四分法：一般野獸、古林妖獸、異化妖獸、天墟巨魔（後期終局），
  對應世界五層探索架構由淺至深的威脅遞增。
- 異化機制為核心設計主軸：異化源於天墟裂隙洩出的「濁氣」侵蝕，外觀出現暗紅眼睛/異化紋理，
  招式變得更具威脅且獲狂暴狀態，掉落「異化靈核」（高階靈印/鍛造關鍵材料），呼應主線伏筆
  「妖獸為何異化」。
- 圖鑑系統記錄生態、弱點與異化原因，解鎖圖鑑條目提供對應屬性加成/異化抗性，驅動玩家研究
  討伐策略而非盲目刷取。
- 同一生物的不同異化階級提供分層掉落，確保刷取有目的性。
