# 一、整合原則

本文件不重新規劃25章主線，而是在既有主線總綱、第一～第三章完整腳本與六人長線弧線之上，建立伏筆的「埋設 → 加深 → 保留 → 回收」關係。

任何後續劇情修改，都必須先確認：
1. 是否破壞已埋設伏筆。
2. 是否提前揭露限制級真相。
3. 是否讓某個角色知道了不應知道的資訊。
4. 是否讓支線變成主線必要條件。
5. 是否造成單一勢力掌握全部真相。

# 三、三層真相控制

## 第一層：表面真相（Ch1-10）
玩家可以合理得到：
> 青嵐只是多地異常之一；古代陣列仍在運作；有人曾經改動陣列；回流正在造成異化；星河殿掌握更多資料。

## 第二層：歷史真相（Ch11-22）
玩家逐步知道：
> 舊界不是單純地名；古代世界曾經發生重大界層／空間處理；九曜與這件事直接相關；天墟與舊界的關係開始成立。

## 第三層：終局真相（Ch23-25）
才完整回答：
- 為什麼舊界被切離。
- 天墟究竟是什麼。
- 九曜系統在其中扮演什麼角色。
- 回流為何發生。
- 世界未來要選擇隔離、共存或其他方案。

# 四、主線／支線互補規則

## 規則 A：支線不能單獨解謎
例如 S10 只能證明資料存在管理限制，不能直接解釋舊界。

## 規則 B：主線也不能完全靠支線才能理解
每個核心主線節點至少有一條主線證據。

## 規則 C：同一伏筆至少兩個來源
例如「人為改陣」：
- 主線：厲若楓／江祈璟找到後加刻痕。
- 支線：S13 三個不同年代陣紋。
玩家因此不是因為一個NPC說了就相信。

## 規則 D：不同勢力看到同一件事，解釋可以不同
例如回流：
- 天玄院：危險現象。
- 星河殿：歷史資料。
- 萬兵閣：設備異常。
- 荒境：生態變化。
- 妖族：可能是另一種世界記憶。
直到後期才拼成完整答案。

核心不是「妖族其實是好人」，而是妖族擁有自己的歷史、利益、恐懼與對天墟／回流的理解。

回收：
- S08 星曜獸生態
- S14 夜行者
- F13 妖獸非純邪惡
- F17 裂谷三音節
- F12 星曜獸生態
- F04 回流生態效應

玩家第一次真正接觸妖庭後，不應得到善惡翻轉的簡單答案，而應發現：
> 人族與妖族都只掌握真相的一部分。

# 八、第17～22章天墟篇核心回收

這裡才開始大量回收青嵐篇留下的零散資訊：
- S04 聞人澈事故缺頁

- F18 界限

回收方式不是 NPC 一次講完，而是：
> 古代設備 + 不同勢力資料 + 妖族傳承 + 舊陣列 + 玩家在青嵐看到的景象

互相驗證。

直到玩家自己能推導：
> 天墟並不是「從外面來的敵人」。

# 九、第23～25章終局回收

前期伏筆最後不應變成單一答案，而要服務終局選擇。

玩家最後面對的不是「誰是大反派」，而是：
> 「當一個曾被切離的世界層開始回到原位，現在的人是否有權再次把它切出去？」

青嵐篇支線在此時的意義：
- 郁岑燁：保護不等於控制。
- 厲若楓：證據比立場重要。
- 齊衡烈：力量需要節制。
- 聞人澈：修復不一定代表恢復原狀。
- 蕭曜霖：把選擇權交給下一代。
- 江祈璟：競爭與合作可以並存。
- 星曜獸：提供共存的生態證據。
- 妖族：提供另一種歷史視角。
- 星河殿：提供記錄與制度視角。
- 萬兵閣：提供古代技術視角。

因此終局不是突然提出「共存」，而是前面二十多章逐步累積。

# 十一、支線與主線依賴關係

### 主線必須可獨立完成
玩家不做任何支線，也能理解主線核心因果。

### 支線提供三種價值
1. 更完整的人物理解。
2. 更多證據與不同視角。
3. 後期回收時產生「原來早就看過」的記憶感。

### 禁止
- 不做支線就無法打最終 Boss。
- 不做支線就不知道核心真相。
- 支線完成直接給主線答案。
- 支線角色取代主線角色功能。

# 十二、Unity 實作資料要求

每條支線日後轉成 Quest Data 時至少包含：
- QuestId
- ChapterAvailability
- RequiredQuestIds
- NPC
- Map
- TriggerType
- Objective
- DialogueSet
- RewardSet
- UnlockFlags
- ForeshadowIds
- RevealLevel
- CompletionState
- FutureCallbackIds

ForeshadowIds 與 FutureCallbackIds 是本文件新增的重要資料欄位概念。
例如 S04 可標記：
- ForeshadowIds：F08
- FutureCallbackIds：F08-CH17

如此 Unity 任務系統可以記錄玩家曾接觸的伏筆，未來對話可因完成支線而產生額外視角，但不改變主線基本可玩性。
