## 2. 長期擴充區域：4個長期擴充區域（世界觀定位與地形主題）

不使用刻板雪山/沙漠印象，每區呼應九曜世界觀的星辰/裂變/異變邏輯：

1. **北境·寒霜星辰原**：古代九曜星辰碎片墜落之地，非單純雪山，而是星鐵磁場與萬年玄冰
   交織的隕星古戰場。地貌：巨型星鐵坑、發光玄冰晶柱群、失重飄浮的星核碎片。
2. **東海·歸墟浮空島**：地脈逆向噴湧形成的浮空巨石群與古仙舟遺骸，呼應九曜中「水/空」
   曜靈。地貌：垂直分布的跨海瀑布、浮空島鏈、流光海溝與失落的古代港口遺跡。
3. **南荒·赤燄焚天谷**：九曜火曜之力持續侵蝕的硅化琉璃化石林，地熱與毒火交織的莽荒禁地。
   地貌：結晶化的琉璃樹木、地表噴發的赤燄地火、巨大的妖族骨骸山谷。
4. **西境·雷劫天脊**：九曜雷曜匯聚之處，古修強者渡劫留下的天雷痕跡與重力異常區。
   地貌：被雷霆削平的千仞石林、常年交織的曜靈電場、懸空石梯與金屬礦脈。

## 3. Zone與Instance的地圖切分與切換設計

- **切分原則**：城鎮與野外（城門區～天墟裂谷）**全部為Zone**，採動態分線與Interest
  Management，確保大世界探索的可見性與社交密度；**只有秘境副本與突破試煉戰場為Instance**，
  確保高強度機制戰鬥的零延遲與同步率。
- **Zone到Zone**：以地形遮蔽（山洞、峽谷彎道）作為視訊與數據加載緩衝帶，無黑屏轉場。
- **Zone到Instance**：地圖設置「靈脈裂隙」或「結界橢紐」節點，玩家組隊進入互動範圍後
  觸發「凝靈防護罩」讀取提示（約3秒），背景完成房間分配與全量同步加載，之後無縫轉場至
  副本內部。

## 4. 地圖解鎖節奏與境界壓制、突破試煉搭配

- **境界門檻採硬性屏障**（不同於05已定案的PvE戰鬥傷害壓制，這是「移動層面」的獨立機制）：
  地圖邊界（如河谷→古林、古林→山脈）設有「靈壓障壁」。若玩家境界低於該區最低門檻，
  強行進入會持續受到「靈脈反噬」（每秒扣減生命值+大幅減速），**無法用蠻力或載具跑圖繞過**，
  必須完成對應突破試煉取得通行資格才能真正進入，杜絕玩家提前跑深圖。
- **突破試煉與地圖權限解鎖對應**：
  - 鍛骨境：僅限城門區、主街、天玄院、河谷。
  - 開脈境：於天玄院完成「開脈突破試煉」後取得通行印記，解鎖古林（抵禦迷霧脈息）與山脈。
  - 靈府境：擊敗山脈獨佔秘境BOSS後取得「靈府避瘴印」，方可進入天墟裂谷抗衡混沌震盪。
- 突破試煉本身（05已定案）安排在對應區域的「主導場景機制區」內完成，
  讓地圖機制與突破試煉共用同一套規則，減少重複開發與學習成本。

## 5. 第一批探索型互動設計（呼應09地圖事件系統）

1. **靈脈脈衝**：野外隨機刷新，需用雙搖桿操作解開靈氣走向陣眼，觸發區域靈氣爆發，
   短時間大幅提升周邊玩家靈氣獲取，同時吸引妖獸圍攻，形成风险與獎勵並存的臨時世界事件。
2. **曜靈陣法殘卷**：地圖上的五行石碑，需依序使用對應屬性技能擊打解謎，
   解開後開啟隱藏地脈通道或取得高階寶箱。
3. **濁氣裂隙淨化**：天墟裂谷隨機出現撕裂點，持續湧出異化妖獸，玩家需吸收怪物掉落的
   「狂暴靈核」填入陣法完成淨化，成功後獲得區域性增益，並直接餵給09未來的動態區域
   事件系統作為進度來源。
4. **懸崖御風地形**：山脈與高空區域設置「風穴」，可利用位移技能配合雙搖桿微操觸發
   「御風彈跳」，抵達常規路徑無法到達的絕壁採集點與古代修仙者遺跡。
