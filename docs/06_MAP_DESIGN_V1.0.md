# 《九曜：天墟》地圖設計原則 V1.0

> 狀態：**大綱級定案**，核心方向已鎖定，個別地圖細節待第二階段補完，標記為「可調整」。

## 核心方向

- 後續地圖沿世界五層探索架構（城市/野外/秘境副本/荒境妖族/天墟終局）延伸，每張大地圖
  至少包含1個核心城鎮/棲身地、3~4個特色野外分區、與獨佔的秘境/天墟裂谷型內容。
- 每張地圖至少包含一個「主導場景機制區」（視野遮蔽、地形高低差、可破壞障壁等），
  讓戰鬥與探索互相影響，而非純視覺美術差異。
- 區域之間用「修行成本曲線」串聯：越深處敵人越具異化壓力，但提供更高品質靈核/靈印材料。
- 野外路線設計需支援雙搖桿操作：視距清晰、可讀技能預兆、地形避免無限追擊。
- 秘境副本延續青嵐城「取靈核→強化Build→面對機制型BOSS」的節奏，確保新地圖內容可被
  竟速或刷取理解，而非純迷宮。
