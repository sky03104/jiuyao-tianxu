# 《九曜：天墟》契友隊伍與轉職系統 V1.0

> 狀態：**設計定案候選**（2026-09-27）。數值全部為初版示意值，標記為「可調整」，需原型測試後校準。
> 產生緣由：咖哩裁定遊戲戰鬥結構**完全比照《斗羅大陸：史萊克學院》**：主角一個職業（流派）、戰鬥中不換人；
> 換職業要在大地圖找 NPC、用轉職卡、符合條件，副本內不能換；夥伴帶一整隊，只有第一位上場，其餘提供增益；
> 夥伴各自養成。
> **取代範圍**：`03` 第 3 節雙脈切換、`20` 第 4 節羈絆連攜技觸發方式、`00` 第 7 節雙脈系統
> （`00` 為原始總綱不改字，以本文件為準）。其他文件中的「雙脈」「切脈」機制**全部取消**，改讀本文件。
> IP 原則：參考的是玩法結構，名詞、角色、系統細節全部原創，不使用斗羅系列專有名詞（武魂、魂環、魂卡等）。
> 修訂紀錄：同日稍早曾定為「戰鬥中換手操控契友」，咖哩確認史萊克學院實際玩法後改為本版。

# 1. 系統總覽

| 位置 | 人數 | 作用 |
|---|---|---|
| **主力：机遙** | 1 | 玩家操控。一個流派，穿全套裝備（`10`）、掛 8 槽靈印（`04`） |
| **出戰契友** | 1 | 隊伍第一位。**由 AI 控制跟著机遙上場戰鬥**，有自己的流派招式與招牌技 |
| **增益契友** | 最多 3 | 隊伍第二～四位。不上場，依好感階段提供屬性增益與一項被動效果 |

- 星曜獸（`20` 第 1～3 節）不受影響，照原規則另開掛槽。
- 隊伍在大地圖可隨時調整；**進入副本後隊伍鎖定**，出副本才能換。

# 2. 主力流派與轉職

## 2.1 初始流派

- 第一章任務 02「基礎演武」時選定机遙的初始流派（對應遊戲開局選主力；`25` 任務 02「解鎖六種初始武器路徑」）。
- 六流派招式沿用 `03` 第 2 節，戰鬥中不能切換。

## 2.2 轉職（換流派）

| 條件 | 內容（示意值，可調整） |
|---|---|
| 地點 | 天玄院**戰技堂**的轉職執事（大地圖 NPC）；九州篇後各大城可增設 |
| 道具 | **轉職卡** ×1 |
| 境界 | 開脈境以上（完成第一章突破試煉） |
| 狀態 | 不在副本內、不在副本排隊或組隊確認中、不在戰鬥狀態 |
| 冷卻 | 每次轉職後 7 天內不能再轉 |
| 首次 | 第一次轉職免轉職卡（讓新手敢試） |
| 保留 | 裝備、靈印、境界、屬性點全部保留；舊流派的技能等級保留，轉回來不用重練 |

- **轉職卡取得**：主線與支線獎勵、週常活動、Battle Pass 獎勵。
- **是否在商城販售**：待咖哩裁定。轉職不直接增加戰力，但 `01` 禁止「戰力直購」，
  若要上架，建議只放在曜金商城並設每月購買上限。
- 靈印子效果依**机遙當前流派**計算（`04` 第 6 節原本「依當前脈」的規則，改讀為「依當前流派」）。

# 3. 出戰契友（上場的那一位）

- **AI 控制**，跟隨机遙戰鬥，使用自己的流派招式（Phase 0-B 已做好的六流派招式直接沿用）。
- **招牌技**（沿用 `20` 第 4 節原連攜技名稱與效果）：

| 契友 | 流派 | 招牌技 |
|---|---|---|
| 郁岑燁 | 劍 | 霜劍破陣 |
| 厲若楓 | 弓 | 穿雲影矢 |
| 齊衡烈 | 刀 | 怒刃裂地 |
| 聞人澈 | 靈杖 | 澄息導流 |
| 蕭曜霖 | 重刃 | 山門壓影 |
| 江祈璟 | 槍 | 貫曜同鳴 |

- **招牌技發動**：自動模式下 AI 冷卻好就放；**半自動與手動模式下由玩家按鍵發動**（技能扇面上的契友頭像鍵）。
  這是本作在史萊克學院結構上的唯一調整，用來保留 `01`「操作深度」與 `09` 破綻爆發的設計（見第 6 節）。
- **倒下**：出戰契友血量歸零時退場，30 秒後可再上場（示意值）；机遙倒下即戰敗。
- **多人場景**：每位玩家各自帶一位出戰契友，伺服器要同步 AI 跟隨單位。20～50 人副本的效能預算需在 Phase 2 驗證，
  必要時大型副本改成「出戰契友只放招牌技、不常駐」。

---

# 4. 增益契友（不上場的三位）

- 依好感階段，把自身基礎屬性的 **5%～15%** 轉為机遙的加成（示意值）。
- 每位契友另有一項**隊伍被動**（例：齊衡烈＝近戰傷害微幅提升；聞人澈＝受到控制時間縮短），隨好感階段強化。
- 總加成設封頂（示意：不超過机遙基礎屬性的 25%），避免囤角色堆戰力。

---

# 5. 多角色養成

原則：**每位契友都值得養，但不要變成養七套完整角色**。机遙完整養成，契友精簡養成。

| 項目 | 机遙 | 契友（每人各自一條） |
|---|---|---|
| 境界 | 九大境界（`05`） | 自己的境界，**上限不超過机遙目前境界** |
| 修為來源 | 戰鬥、任務、修行 | 「契友心得」（主線、支線、日常、羈絆事件）；出戰也會累積少量 |
| 屬性點 | 手動分配（`05` 第 2 節） | **自動分配**，依角色個性模板 |
| 技能 | 當前流派技能 | 固定流派技能＋招牌技，用契友心得升級 |
| 裝備 | 8 槽（`10`） | **2 格「信物」**：專屬裝備，來自個人支線與好感事件（例：郁岑燁的家族斷劍碎片） |
| 武器 | 一般裝備 | 本命武器，隨好感階段突破外觀與基礎攻擊 |
| 靈印 | 8 槽 | 不掛 |

**經濟**（沿用 `20` 第 5 節與 `14` 雙幣制）：契友心得、信物強化以靈砥為主；曜金只用於外觀與部分加速，
設每日／每週上限，**不能直購契友或契友境界**。收入端以**契友外觀收藏**為主（時裝、武器外型、招牌技特效）。

## 5.1 解鎖進度（依正史劇情）

| 契友 | 解鎖時點 | 劇情理由 |
|---|---|---|
| 郁岑燁、厲若楓、齊衡烈 | 第一章任務 05 開脈境突破後 | 第七室舍友，開始並肩訓練 |
| 聞人澈 | 第一章任務 14 夜談後 | 正式進入第七室朋友圈 |
| 江祈璟 | 第三章章末 | 由競爭者轉為臨時合作 |
| 蕭曜霖 | 九州篇（第四章後，時點可調整） | 教官身分特殊，出戰時境界壓到机遙同階（「壓境相助」，可調整） |

- **劇情立場不變**：入隊是羈絆與訓練同行，不代表服從机遙；六人主線立場仍然獨立（修訂 `34` 第七節）。
- **多人讀法**：每位玩家都是自己故事裡的机遙，別的玩家也可以帶齊衡烈，屬於 MMO 的常見抽象；劇情副本內只出現一位。

# 7. 技術與美術影響（誠實揭露）

- **程式**：戰鬥中不換人，比稍早的「換手」版本簡單。新增的是**AI 跟隨單位**（出戰契友）與多人同步，
  這是主要技術風險，要在 Phase 2 驗證 20～50 人副本的效能。Phase 0 範圍不變。
- **美術**：六位契友要做**完整戰鬥動作組**（AI 上場打），成本與稍早版本相同，排程要算進去。
- **平衡**：机遙只有一個流派，出戰契友最好補机遙缺的定位（例：机遙弓修＋齊衡烈刀修）。

# 8. 待驗證／待裁定

1. 轉職卡要不要在商城販售（第 2.2 節）。
2. 史萊克學院 35 級後的「第二武魂」（戰鬥中可切換第二職業）本作**暫不做**；要不要在後期開放類似機制，待咖哩決定。
3. 出戰契友在 20～50 人副本的伺服器效能（Phase 2 實測）。
4. 增益比例 5%～15%、封頂 25%、轉職冷卻 7 天等數值。
5. 蕭曜霖「壓境相助」是否讓玩家覺得教官太弱。
