# 《九曜：天墟》公會系統 V1.0

> 狀態：**大綱級定案**，核心方向已鎖定，細節機制待第二階段補完，標記為「可調整」。

## 核心方向

- 公會（暫定名「仙盟」，可調整）核心玩法圍繞「裂隙封印戰」（多人PvE大型副本，需要多小隊
  協同）與「領地演武」（Phase 3 才開放的PVP玩法），呼應連線架構已定的 instance 20~50人規模。
- 公會可建造專屬駐地，產出獨佔靈丹與裝備圖紙，需要生活系統玩家貢獻資源升級建築，
  讓不同類型玩家（戰鬥/生活）在公會內互利共榮。
- 每週固定挑戰內容（公會Boss/異化事件）依隊伍配置解鎖公會技能樹加成（影響屬性/靈印觸發概率，
  但不超越個人核心 Build），並提供高階副本入場券與戰力 Buff。
- 公會系統與經濟系統（14）、社交系統（12）深度掛鉤：公會資源池使用可交易的高階貨幣，
  避免與日常養成貨幣混用。
