# 《九曜：天墟》公會系統 V1.0

> 狀態：**細節定案（第二階段補完）**，具體數值為初版示意值，需 Phase 0 原型測試後調整，
> 標記為「可調整」。
> 產生方式：GPT/Gemini/DeepSeek 三方交叉草擬，Claude審查發現Gemini與DeepSeek在「公會
> 建立門檻」再次使用不存在的境界名稱（金丹初期/元嬰一重），已修正為已定案的9大境界名稱；
> 其餘內容整合三版優點採用。

## 1. 公會（暫定名「仙盟」）建立與階級制度

- **建立門檻**：發起人境界需達**神藏境**（呼應05已定案的9大境界，第5階），支付
  3,000曜金（可交易高階幣），並於24小時內透過12已定案的院內名冊招募滿10名玩家共同簽署，
  逾時失敗全額退還。
- **職位與權限**：
  - **盟主**（1人）：解散/轉讓公會、建築升級動用資源池、技能樹點選、開啟裂隙封印戰、
    分配可交易高階幣資源池。
  - **副盟主**（2人）：人事處置（審核/剔除）、每日營運預算動支、發起公會常規活動。
  - **長老**（若干）：審核招募申請、配置裂隙封印戰小隊編組模板、分配貢獻兌換。
  - **精銳弟子**：優先進入20~50人instance副本、使用高階駐地設施。
  - **盟眾**（一般成員）：使用駐地基礎設施、貢獻生活材料、領取每週技能樹加成。
  - **試煉弟子**（新人）：僅能參與封印戰候選隊列，無資源池提取權，需在期限內達成
    貢獻門檻才能轉正。

## 2. 裂隙封印戰具體玩法設計（呼應09已定案BOSS機制邏輯）

- **規模與分組**：instance 20~50人，依06已定案地圖/連線規則，劃分2~5支小隊
  （每隊5~10人），出發前由公會依隊伍配置指定各小隊「功能位」：
  - **破陣位**：負責打斷封印機關/降低封印進度抗性。
  - **護航位**：承接爆發傷害，確保刻印期不被打斷。
  - **刻印位**：達成靈砥觸發條件時鎖定靈印/封印節點。
  - **擴核位**：在弱化窗口內集中輸出。
- **BOSS機制呼應**：戰鬥開始時系統掃描全隊Build組合，依09已定案的「Build缺口」邏輯，
  若全隊缺乏對應破局流派/機制，BOSS會提升「封印抗性」（進度變慢）；反之補齊缺口會
  觸發09已定案的弱化窗口（如短暫破綻/暴擊倍率窗口），讓小隊分工與09的破局邏輯直接掛鉤。
- **進度與結算**：封印進度採全隊共享（不因小隊各自為政而分裂），依「封印進度貢獻」與
  「弱化窗口命中率」計分，結算轉化為個人掉落券（依09已定案掉落規則）與公會技能樹升級
  所需資源。

## 3. 公會駐地建築系統具體規則

- **議事殿**（核心建築）：決定公會等級上限、可容納人數與技能樹解鎖階段。
- **靈丹工坊**（呼應11生活系統）：由生活玩家貢獻採藥/煉丹產出材料，產出公會獨佔靈丹
  與強化胚料。
- **鍛造閣**：由採礦/鍛造材料驅動，產出獨佔裝備圖紙。
- **靈脈陣**：升級後解鎖對應的公會技能樹節點。
- **資源倉**：公會資源池所在地，可交易高階幣（曜金）與貢獻生活材料的儲存中心。
- **演武場**（Phase 3開放）：領地演武訓練與獎勵加成設施。
- **升級規則**：每項建築升級需要「生活系統材料（11已定案7種玩法產出，必填）+ 靈砥
  （綁定日常幣，用於核心工序消耗，防止單靠交易貨幣堆疊）+ 曜金（可交易高階幣，用於
  加速工期或補齊缺口，但設有每週上限，避免單靠課金/氪金玩家速通）」。

## 4. 公會技能樹具體設計（呼應05境界壓制精神，不超越個人核心Build）

- **技能樹分三支**：裂隙支（封印傷害/減傷）、生產支（生活效率/產量）、社交支
  （助力次數/名冊曝光）。每支5層，每層加成1~3%（相對值）。
- **解鎖節奏**：每週固定挑戰依「隊伍配置多樣化程度」（呼應05已定案的隊伍配置加成邏輯）
  解鎖對應節點，非單純刷等級。
- **硬性上限（防止超越個人核心Build）**：
  - 公會加成一律為「機率型輔助/環境型輔助」（如靈印觸發機率微調、封印抗性削減、
    非戰鬥移動速度），**不直接提供爆發傷害數值**。
  - 全公會加成加總後，單一靈印觸發機率提升總量設硬上限（如總提升不超過個人基礎值的
    某一相對比例），且**完全不影響05已定案的境界壓制判定**——境界差距造成的傷害減免/
    天威壓制依然按05規則執行，公會加成只作用於「壓制後的可用效率」，不能抵銷或突破
    境界壓制本身。

## 5. 與12社交系統的招募/管理機制串接（具體規則）

- **招募面板**：盟主/副盟主可設定招募條件（缺乏的Build標籤、可接受境界區間、
  裂隙封印戰角色偏好），系統依12已定案的院內名冊標籤自動媒合並推播邀請給符合條件的
  線上玩家。
- **助力印記轉化**：成員之間使用12已定案的好友助力印記完成公會任務時，額外記錄一筆
  「公會聲望」，每週結算聲望最高的互助組合會登上公會榜單，強化公會內部社交黏著度。
- **轉正與淘汰機制（具體門檻）**：試煉弟子需在2週內完成至少1次裂隙封印戰且達成
  「對應功能位貢獻門檻」，並完成公會建築材料貢獻，方可轉正為盟眾；連續2週貢獻不足且
  未請假者，由長老或副盟主發起審核，盟主一鍵執行除名，除名者需經過短期冷卻才能重新申請
  加入同一公會，避免頻繁進出洗版。
