# 角色設定圖的版面規格

`image.sheet` 是**給出圖模型的完整版面指令**，本 skill 只負責把它寫對，**不負責出圖**。
出圖在下游（要選模型、畫風、畫幅，這三件事在這一層一個都答不了）。

下面這些約束必須逐條寫進 `image.sheet` 的英文正文。它們都是被真實輸出打出來的——
不寫死，模型就會各自發揮，而且總往同一個方向崩。

## 每個角色一張圖

一張橫構圖，內部左右分欄：

```
┌──────────┬────────────────────────────┐
│          │   正視    側視    背視       │
│  半身像   │                            │
│ （證件照） ├────────────────────────────┤
│  面部基準  │  細節 · 細節 · 細節 · 細節   │
│   ~34%   │                            │
└──────────┴────────────────────────────┘
                    16:9
```

左欄的半身像是**面部設計的基準**，右欄三檢視的臉照著它畫。

## 主體資訊不能在排版時縮水

`image.sheet` 的主體段必須承接 `image.prompt` 中的年齡、身份對應的服飾、面料品質、髮飾、隨身物件與儀態，不能只保留衣服顏色和髮髻。三個區是同一身份、同一場合、同一套裝束；原文明確的便裝、喬裝或落難狀態同樣保留，不擅自換成禮服。細節條優先展示能辨認這個人的特徵，不能為了填滿細節格憑空新增補丁、磨損或飾物。

## 背景：白底

一律**純白背景**。理由有三個：摳圖乾淨、印出來是設定表該有的樣子、在深色報告裡也能讀。
`image.sheet` 裡寫死 `plain pure white background`，不要改成灰底或場景背景。

## 分割槽光照

設定表要平光（摳圖、量比例），體積感要方向光。兩者矛盾，所以**分割槽解決**：左欄半身像給柔和
方向主光 + 環境遮蔽，右側三檢視和細節條保持平光正交。提示詞裡是兩句獨立的
`LIGHTING IN THE LEFT ZONE ONLY` / `LIGHTING IN THE RIGHT ZONES`，**不要合併成一句全域性光照**。

## 比例 ⚠️

這個版面最容易崩的就是比例——模型為了把細節條塞進去，會把三個全身像壓扁或拉長。必須寫死
`PROPORTIONS ARE CRITICAL`、`no stretching, squashing or foreshortening`、
`the detail studies give way, not the figures`。

## 左欄的收口 ⚠️

模型預設會把半身像的兩側肩膀裁掉、底邊做成圓角或漸隱暈影，看著很彆扭。必須顯式禁掉：
肩膀完整、兩側留空、底邊齊平直切。**這條不寫就一定會出問題。**

## 面部一致性 ⚠️

一張圖裡出現兩個長相是這個版面最容易出的問題——左欄畫一個人、右欄畫另一個人。必須寫死
`must match the bust portrait exactly — same features, same hairstyle, same expression`。

## 畫風不在這裡

**`image.sheet` 裡不寫畫風。** 畫風是出圖那一刻由呼叫方整批附加在提示詞前面的一層，
寫進這裡只會跟當時選的那一檔打架，而且換風格要逐條改。細節見 `profile-pass.md`。

同一批角色的畫風一致性因此也是下游的事：整批共用同一段風格指令，必要時再拿第一張成圖
當參考圖壓一壓。這一層管的是「這個人長什麼樣、這張表怎麼排」。

## 檔名

`render` 預設去 cast.json 同級的 `images/<slug>-sheet.png` 找圖，找到就嵌進 report.html；
圖在別處就用 `--images <目錄>` 指過去。本 skill 不產生這些檔案，下游出完圖重跑 `render` 就能撿起來。
`node scripts/novel-characters.mjs slug "<角色名>"` 生成安全檔名（中文會保留）。
