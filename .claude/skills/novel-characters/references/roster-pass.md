# 第一趟 · 掃描角色

給一段原文，抽出這段裡出現的所有角色。**只輸出 JSON，不要任何解釋、不要 markdown 圍欄。**

## 規則

- 列出這段裡每一個有名有姓、或雖無名但明確是獨立個體的角色。沒名字的用描述性標籤，比如「擺渡的老頭」。
- 同一個人的稱謂、綽號、正式名合併成一條，`name` 取原文裡用得最多的那個形式。
- **不要編造角色。** 地名、組織、動物除非像角色一樣行動，否則不算。
- `note` 要密集：長什麼樣、怎麼說話、做了什麼。**後一趟看不到原文，只看得到你寫的 note**，所以細節必須落在 note 裡。
- 記錄身份、職業、經濟條件，以及原文明說的服裝、面料、髮飾、隨身物件、儀態和穿戴場合；把日常造型與喬裝、落難、禮服等特殊狀態分開。區分本人的外觀與身邊侍從/親屬的外觀，不把合併角色的敘事功能當成主人物的衣著或身份。沒有外觀描寫就明確記為缺失，不在掃描階段編造；優先保留能佐證這些資訊的原文片段。
- `quotes` 和 `note` 不是一回事：從原文裡**逐字複製**片段，**保持原文語言，不許翻譯成英文**。**不許把被敘述打斷的對白拼起來**——如果一句話被「他說」隔開，只取其中一側，不要合併兩側。
- 敘述者除非本身是故事裡的角色，否則忽略。

## 輸出格式

```json
{
  "characters": [
    {
      "name": "老周",
      "aliases": ["老伯", "擺渡人"],
      "note": "七十上下的老船伕，在這條河上擺渡四十年。背駝得厲害，左眼有白翳。說話嗓子沉、含混。被問路時不答話，只用篙子點對岸。",
      "quotes": ["背駝得像一張拉滿的弓", "霧一厚，連自己的手都看不清。"]
    }
  ]
}
```

欄位都是必填。`aliases` 和 `quotes` 沒有就給空陣列。
