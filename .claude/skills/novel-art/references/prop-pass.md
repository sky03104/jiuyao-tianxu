# 道具設定 · 怎麼填

給你原文/大綱裡與道具相關的全部資訊，先**選**再**填**。**只輸出 JSON，不要解釋、不要圍欄。**結構見 `schema.md` 的 props 段。

## 先選：什麼配當敘事道具

三個條件**同時滿足**才入選：**有特寫、跨集出現、承載劇情**。一部劇通常 3–8 件，跟主角數量一個量級。

| 型別 | 歸屬 | 例子 |
| --- | --- | --- |
| **敘事道具** | 入選，單獨建資產 | 皮箱（全劇懸念）、舊硯（爆點實體） |
| 場景陳設 | 場景錨點已覆蓋，不入選 | 銅鈴、紙燈籠、繫纜石樁 |
| 一次性手部道具 | 鏡頭級提示詞解決，不入選 | 一碗茶、一份報紙 |

拿不準就問一句：這件東西被鏡頭懟著拍過嗎？觀眾記得住它嗎？劇情少了它轉不動嗎？三個都不是就不入選。

## 硬規則

1. **道具的形制按本劇朝代寫。**`art.json` 頂層的 `dynasty` 已經定好了，直接沿用——器型、材質、工藝、紋樣、裝裱方式都有朝代差別，一件道具漂一個世紀，跟它同框的場景就穿幫了。**不許寫「古代」這類含糊詞**（理由見 `scene-pass.md` 第 1 條）。還沒有 `dynasty` 時，從現有場景裡推斷一個具體的。

2. **`summary` 寫戲劇功能，不寫商品描述。**「誰碰翻誰的臉的懸念核心」是戲劇功能；「棕色牛皮材質」只是材質。先說它在劇裡幹什麼。

3. **錨點要經得起特寫。**道具的錨點比場景的更小更細：綠鏽銅釦上的一道新劃痕、墨池邊的月牙磨痕。特寫鏡頭會把這些放大到全屏，**缺了立刻穿幫，多了核對不過來**——照舊 3–5 個。

4. **狀態變體從劇情反推。**皮箱有合上/開啟，狀紙有藏著/攤開——道具的狀態弧跟著劇情走，每個狀態一條英文提示詞，會各生成一張參考。沒有狀態變化的道具寫一個主狀態即可。

5. **尺度必須寫死。**`scale` 三檔（手持級/桌面級/傢俱級），`image.prompt` 和 `image.sheet` 裡**必須出現對應英文短語**（handheld scale / tabletop scale / furniture scale）——AI 把手持道具畫成傢俱尺寸是高頻事故，validate 會對著查。

6. **白底、無人、無手。**道具參考圖要被貼進各種鏡頭，必須純白背景可摳；**拿著道具的手是最常見的汙染**，反向提示詞必須禁 hands/fingers。validate 三樣都查。

7. **關聯要掛上。**`relatedScenes` 掛它主要出現的場景（id 必須存在），`carriedBy` 寫誰帶著它（自由文本）。這兩樣進報告，是排生成任務時查「這場戲桌上該有什麼」的索引。

8. **提示詞永遠英文，絕不出現角色名**——影像模型會把它認識的名字畫進去。表面處理句跟場景是同一套兩檔，照抄 `scene-pass.md` 裡「要整段帶上的是表面處理」那兩段之一——按這件東西的保養水平選，御賜的印信和船家的竹篙不是同一檔；畫風同樣不寫進提示詞。

## 輸入格式

```
候選道具線索（從原文/大綱摘出）：
- 沈知微始終抱著一隻舊皮箱，指節發白（第 1–6 集，開箱是收束爆點）
- 陸行遠口袋裡的硬東西，第 3 集掏出是一方舊硯，硯底刻著縣衙的印
- 胡二爺的兩箱貨（挑著走，無特寫）
已有場景：S01 渡船船艙、S02 渡口棧橋、S03 對岸蘆葦灘
```

上面第三條就該落選——有出場無特寫，不承載劇情轉折。
