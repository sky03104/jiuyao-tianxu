# 美術報告的設計約定

報告由 `scripts/novel-art.mjs render --html` 生成，樣式全部內聯在 `renderHtml()` 裡。**改樣式只改那一處。**

與另外兩份報告同一套視覺語言：冷灰印張 + 鐵鏽紅印記，1600 寬，全部平鋪可 Cmd+F，零外部依賴，離線雙擊能開。

## 結構

```
頁首      劇名 · 場景設定集 · 畫風 · 品質門徽章 · 匯出 JSON
KPI 帶    場景數（主場景 + 變體）/ 一致性錨點 / 光照狀態 / 複用變體
（病灶橫幅）品質門有未過項才出現
01 場景清單    一張總表：ID/型別/出現集/錨點數/光照/變體改動
03 道具清單 04 道具設定卡    有 props 才渲染；道具卡與場景卡同構（狀態變體替代光照，徽章顯示尺度）
02 場景設定卡  每場景一張大卡（報告的主體）
03 品質門     完整 ✓/✗ 清單
```

## 場景設定卡

**一排兩張**（1100px 以下降一列），卡內縱排——這個排法是給截圖宣傳定的：設定圖佔滿卡寬、位置靠上，兩張卡並排截出來就是一張能發的圖。

卡內從上到下：卡頭（ID + 名稱 + 徽章 + 出現集）→ 設計意圖（宋體，它是敘事不是引數）→ **環境設定圖**（可點，彈層看大圖，Esc 或點背景關閉；沒出圖就佔位）→ 變體來源標註（鐵鏽紅底）→ **一致性錨點**（編號列表，`01 02 03` 等寬序號——它是核對表，編號是給 QC 唸的）→ **光照與時段**（狀態名 + 提示詞，每行帶複製按鈕） → 提示詞包（摺疊 + 複製，主視角/設定圖/反向 + 整卡 JSON）。

## 品質門

11 道（場景與共用 7 + 道具 4），`gateReport()` 渲染時算好烘進頁面。無道具的檔案四道道具門直接放行並照常顯示。特殊處理一條：「提示詞不含角色名」在沒給 cast.json 時**明說跳過**（面板上寫「未提供 cast.json，本門跳過」），不裝作查過——靜默通過和撒謊只差一步。

## 匯出 JSON

與另外兩個 skill 同一套：`<script type="application/json" id="scenes-data">` 內嵌原樣資料 + 頁首按鈕下載。兩個坑照舊：`<` 轉 `<` 防 `</script` 截斷；`revokeObjectURL` 延後調防 Safari 存出空檔案。

## 品質底線

- 模型生成的資料一律 `esc()` 轉義
- `@media print`：隱藏按鈕、提示詞全展開、卡片不跨頁斷
- `prefers-reduced-motion` 關動效
- 中文文案不用單字詞（複製/展開/主場景，不寫單字）
