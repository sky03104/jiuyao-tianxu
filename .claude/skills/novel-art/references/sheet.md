# 設定圖的版面規格（場景 + 道具）

`image.sheet` 是**給出圖模型的完整版面指令**，本 skill 只負責把它寫對，**不負責出圖**。
出圖在下游（要選模型、畫風、畫幅，這三件事在這一層一個都答不了）。

下面這些約束必須逐條寫進 `image.sheet` 的英文正文。

## 每個場景、每件道具各一張圖

### 場景

一張 16:9 橫構圖，主視角大圖 + **底部和右側的 L 形細節邊框**，細線分隔：

```
┌─────────────────────────────┬───────┐
│                             │ 細節 1 │
│      主視角（標準取景）        ├───────┤
│      場景的標準長相            │ 細節 2 │
│      ~72% 寬 × 70% 高        │       │
├─────────┬─────────┬─────────┼───────┤
│  細節 3  │  細節 4  │  細節 5  │       │
└─────────┴─────────┴─────────┴───────┘
```

- **主區（左上，約 72% 寬 × 70% 高）**：主視角 = 這個場景的標準取景 + 第一個光照狀態，這就是「這個場景長什麼樣」的唯一標準答案
- **右列 + 底行**：全部是**細節特寫**——一致性錨點和關鍵材質的近景，右列 2 格、底行 3 格左右
- 每個細節格都必須是主視角那個空間的裁切放大，**不許出現主視角裡沒有的東西**——提示詞裡寫死 `nothing invented that is not present in the master view`

### 道具

同一套 L 形版面，差別三處：**純白背景**（每個面板都是，要摳圖）、主視角是主狀態的四分之三角度、底行放**其他狀態 + 側面正交檢視**。全圖**無人且無手**——拿著道具的手是最常見汙染，出現就重生成。尺度短語（handheld scale 等）必須在提示詞裡，否則皮箱會被畫成衣櫃。

提示詞欄位 `image.sheet`。`render` 預設去 art.json 同級的 `images/<slug>-sheet.png` 找圖（`slug` 命令生成安全檔名），
圖在別處就用 `--images <目錄>` 指過去。本 skill 不產生這些檔案，下游出完圖重跑 `render` 就能撿起來。

## 三條硬要求

1. **全圖空景無人。**提示詞裡 `Absolutely no people anywhere` 必須在，反向提示詞禁人必須在。生成圖裡出現一個人影就重生成——環境資產裡的人洗不掉。
2. **一張圖裡只能有一個空間。**角色設定圖最容易出「一張圖兩個長相」，環境圖的對應崩法是**面板之間空間對不上**（左邊六排坐板、右上變成四排）。提示詞裡寫死 `THE SPACE MUST BE IDENTICAL ACROSS ALL PANELS`。拿到圖先核對錨點：每個錨點在主視角裡找得到嗎？
3. **透視要穩。**環境圖最常見的廢圖是幾何融化、透視歪斜。反向提示詞裡 `warped perspective, melted geometry` 必須在（預設自帶）。

## 變體場景：提示詞裡要掛住母場景

`variantOf` 的場景，`image.sheet` 寫的是**母場景主視角 + `changes` 的改動描述**，外加一句
`keep the structure, materials and wear identical to the reference image`——那句是寫給下游的：
出這張圖時要把母場景的成圖當參考圖掛上去。**變體機制的意義就在這**，從零生成一致不了。

## 畫風不在這裡

同一部劇的所有場景應該像同一個美術組畫的。這靠兩件事，**兩件都不寫進單條提示詞**：
表面處理句是寫死的一套（見 `scene-pass.md` 裡「要整段帶上的是表面處理」那一條），
畫風則由下游在出圖時整批附加同一段指令。寫進這裡只會跟當時選的那一檔打架，
而且換風格要逐條改。
