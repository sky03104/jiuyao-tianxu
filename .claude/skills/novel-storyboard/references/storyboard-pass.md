# 切鏡：一集怎麼分段、怎麼切

一次任務切一集。你拿到 seedScenes 工作底稿（每場的節拍清單：編號、動作/臺詞、每拍秒數、說話人）、場景卡、角色卡。產出：把這一集的 `segments` 從空切滿，然後刪掉 `seedScenes`。

## 先分段，再切鏡

1. **段 = 一次生成呼叫**，≤ 15 秒，不跨場次。先把每場的節拍按劇情單元分組（一次交鋒、一次進場、一次收尾），每組 9–15 秒就是一段。
2. **段內切分鏡**，每切 2–5 秒（硬門），圍著 3 秒打。一段通常 3–5 切。
3. **每切一張分鏡圖**：第 1 切的是主分鏡圖（釘 0.00 秒），其餘子分鏡圖釘在各自切點。生成時全套餵給 H3，段內每一格的構圖都由圖控制，不靠文字賭。

## 硬規則

1. **認領是地基。** 每個分鏡宣告 `beats:[起,止]`，全場連續區間、不重不漏。切完在心裡過一遍：每場第 1 拍到最後一拍都有主嗎？
2. **秒數是下單不是估算。** 分鏡秒數直接決定切點時刻和對齊指令——改秒數必須同步改 `h3Prompt`，validate 逐字對帳，改一邊必被攔。
3. **臺詞裝得下。** 認領節拍的臺詞秒數 ≤ 分鏡秒數。4.4 秒的臺詞就給 5 秒的切。
4. **景別短語進分鏡圖提示詞，運鏡詞進這一切自己的鏡頭正文裡。** 一切一個運鏡，寫成自然的動作句。**用哪種語言的運鏡詞，跟著這份分鏡的 `promptLang` 走**：英文模式用官方英文詞（Push In / Pan Left / Tracking Shot…，`a slow push in toward…`），中文模式用 `schema.md` 詞表的中文詞（推 / 搖 / 跟拍…，「鏡頭小幅緩推向掐白的指節」）。門按 `promptLang` 逐切對帳，寫錯語言當場攔——別把一種協議的語言當成所有分鏡的預設。
5. **分鏡圖提示詞直呼角色名；影片正文一律用通用身份。** 兩半的規矩相反，因為定規矩的不是同一個人：
   - **分鏡圖提示詞（frame）寫名字**（張三、王五）。它是唯一帶著設定圖一起生成的那張——場景圖、角色設定圖、道具圖都掛在提示詞上並按名字列出，名字因此是**指向某張參考圖的地址**，不是省略了外貌描寫。同框兩個年輕男子時，通用身份說不清哪張臉配哪句動作。
   - **影片正文（`h3Prompt` 的鏡頭行、Seedance 的 `shot`）不寫名字**，用通用身份（an old ferryman、一名鐵灰袍中年男子）。**這是 MiniMax H3 和 Seedance 官方提示詞規範的硬性要求**，不是我們能放寬的。姓名只許出現在臺詞原文裡。
   角色設定圖、場景圖、道具圖的提示詞同樣禁名字——那幾張是**從文字長出來的**，沒有參考圖可指，名字在那裡就是一個本該寫外貌的空洞。
6. **構圖量化進欄位，段有走位。** 每鏡填 `lens` / `cameraPosition` / `composition` / `eyeline` / `focus` / `stability`；每段填 `blocking`（開場誰在左誰在右、朝向、間距）。寫法見 `shot-writing.md`「構圖要量化」。這是替代分鏡圖的那部分資訊：不出分鏡圖時它們就是構圖的全部來源，出分鏡圖時它們讓圖和正文說的是同一個鏡頭。

## 導演運鏡手感（不設門，但決定像不像專業分鏡）

- **3 秒一切是短劇的呼吸。** 豎屏觀眾的注意力就這個粒度——切快了資訊斷，切慢了人走。節奏帶上應該深淺相間、長短相間。
- **對話切正反打。** 問話給問話人的近景，答話切答話人的近景，來回跳；誰的臺詞資訊量大，誰的臉給得近。同一段裡解決，一次生成。
- **進場三件套，第一切給運動主體。** 每集第一切必須有主體運動（跟拍霧中奔跑，或固定機位裡的人在動）——靜物特寫開場是死畫面，留給第二落點。新空間隨後再定場：運動主體 → 大遠景定場 → 關鍵區域性特寫。觀眾三秒內知道誰在動、在哪、看什麼。
- **關鍵動作獨立成切。**「她一把按住箱蓋」這種拍值得單獨一格 2 秒的特寫插入（insert）——它是節奏的重音。
- **反應鏡頭是免費的戲。** 一句重臺詞之後，切聽者的臉 2–3 秒，不用寫詞。VO 蓋空鏡或特寫，天然省口型。
- **動接動。** 上一切結尾的動勢（手伸向箱子）接下一切開頭的動勢（手被按住），段內連貫性交給 H3，切點選在動作中間而不是動作完成後。
- **段的最後一切留鉤。** 每段結尾的分鏡要麼是懸唸的具象（口袋、銅釦、燈），要麼是下一段的引子——段與段之間也是剪輯點。
- **運鏡剋制。** 固定鏡頭是預設；推給情緒、拉給收場、跟給移動。一段裡超過兩種運鏡就該問自己是不是在炫技。

## 參考圖紀律（分鏡圖品質的一半在這）

分鏡圖生成 = 提示詞 + 參考圖。切鏡時就想好每格要掛哪些參考：

- 場景設定圖（該段場景 + 光照狀態）——必掛
- 畫內每個角色的設定圖——有幾個掛幾個
- 畫內敘事道具的設定圖——有就掛

提示詞與參考圖衝突時，模型聽參考圖的——所以提示詞專心寫構圖、**此刻的位置狀態**（已上船 / 在艙內 / 在橋頭）和姿態，長相材質交給參考圖。畫面裡出現的大資產（船、車、宅門）也要掛它自己的設定圖，不掛就每幀長得不一樣。

## 常見病

| 病 | 症狀 | 治法 |
| --- | --- | --- |
| 舞臺劇病 | 一段一切杵到底 | 對話切正反打，動作給插入特寫 |
| 均勻病 | 每切都是 3 秒中景 | 深淺相間、長短相間才是節奏 |
| 秒數漂移 | 改了分鏡秒數忘改提示詞 | validate 會攔：對齊指令和切點時刻逐字對帳 |
| 臺詞爆倉 | 4.4 秒的臺詞塞 3 秒的切 | 加秒或拆切 |
| 聲景漏改 | 畫面改成搭手卸擔，環境音還寫著銅鈴撞擊 | **聲景也是動作指令**——劇本動作一改，描述、聲景、中文對照三處一起改（踩過：影片真把撞擊演出來了） |
| 特寫失憶 | 大特寫的道具和設定圖長得不一樣 | 掛道具設定圖當參考，提示詞提錨點特徵 |
| 換景不換段 | 一段裡從棧橋切進船艙 | 換景必開新段——一段一個環境錨 |
| 改切不讀鄰切 | 第 1 切改成岸路奔跑，第 2 切還寫著棧橋才露出來，圖卻畫在棧橋上 | 改一切連讀前後切，分鏡圖和文字逐格對照——位置是連續狀態 |
