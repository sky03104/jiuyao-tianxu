# Seedance 影片提示詞 · 寫法規範（內化版）

方法論學自火山引擎《Doubao Seedance 2.0 系列提示詞指南》，**內化成本 skill 自帶檔案，不依賴外部頁面**。**正文內容怎麼寫見 `shot-writing.md`**（一切一個運鏡、動作要做得完、臺詞逐字、聲音分層、不寫畫風），本文只講 Seedance 特有的語法、符號和禁忌。

跟 H3 的差別不是措辭偏好，是協議：H3 靠正文把參考圖釘到秒數上；Seedance 是一個「全模態導演」，把輸入拆成空間層（畫面裡有什麼）和時間層（怎麼隨時間變化），**時間層用鏡頭順序表達，不用秒數**。

## 語言：整條中文

官方示例全部是中文，臺詞、音效、音樂的符號約定也是按中文設計的。整條正文寫中文，運鏡詞用 `schema.md` 詞表的中文詞。**臺詞語言要統一，避免中英混用**（專有名詞除外）。

## 官方進階公式

> 精準主體 + 動作細節 + 場景環境 + 光影色調 + 鏡頭運鏡 + 視覺風格 + 畫質 + 約束條件

在本管線裡各項的歸屬：

| 公式項 | 落在哪 |
| --- | --- |
| 精準主體、動作細節、場景環境、鏡頭運鏡 | **每一切的正文**（本文管這個） |
| 光影色調 | 每一切的正文裡寫光線方向與氛圍，**不寫色調名**——色調屬於畫風層 |
| 視覺風格、畫質 | **畫風層**，由呼叫方在提交時附加，正文不寫 |
| 約束條件 | **全域性約束**，程式拼在末尾：呼叫方用 `--constraints <檔案>` 給（一行一條），程式再補上「無字幕」和多人同框的「禁雙胞胎」 |

## 時間層：鏡頭順序，不寫秒數

官方原話：「模型對精確時間（如 0–3 秒）的支援不穩定，強行限制時長可能導致生成結果異常」，「不強制限制每段時長，優先讓模型根據劇情自然生成節奏」。

所以正文裡：

- **不寫** `0–3 秒`、`第 3 秒`、`00:03.000` 這類時間——總時長由介面引數控制，節奏交給模型
- **不寫** `【鏡頭1】` 這類標題——程式按切的順序加，寫了會重複
- **不寫** `@圖片N`、`<Picture k>`、`[Shot k]`——參考圖編號由程式按真實附件順序加
- 每一切只寫這幾秒發生什麼：**運鏡或切換方式 → 主體動作與表情 → 位置或空間變化**。構圖不靠形容詞，靠 `schema.md` 的量化欄位（焦距 / 機位 / 構圖 / 視線落點 / 焦點 / 穩定性）；聲音歸聲景/配樂欄位

## 你寫哪幾個欄位

| 提示詞裡的位置 | 欄位 |
| --- | --- |
| 「畫面：」行 | 每切的 `shot`（中文，通用身份） |
| 【人物關係與構圖邏輯】 | 每段的 `blocking` |
| 焦距 / 機位 / 構圖 / 視線落點 / 焦點 / 穩定性 | 每切的 `lens` / `cameraPosition` / `composition` / `eyeline` / `focus` / `stability` |
| 音效行、光影行 | 每切可選的 `sfx` / `lighting` |
| `<音景>` / `（配樂）` | 每段的 `soundscape` / `music`（不帶符號，程式套） |
| 運鏡、景別 | 每切的 `camera` / `size` 列舉，程式轉成中文詞 |
| 臺詞 `{}` | 不用寫——程式從劇本認領的節拍逐字取 |

`render --html` 的提示詞面板有 Seedance 頁籤，`export --protocol seedance` 出投產包（每段 `seedance.md` + 附件，根部 `seedance-manifest.json`）。

## 程式拼出來的形狀（示意，你不用寫）

一段一份結構化鏡頭表。參考圖先宣告，再是段級走位，再逐鏡按固定欄位展開，末尾是編號約束：

```
@[圖片1] = 正廳
@[圖片2] = 張三
@[圖片3] = 李四

【人物關係與構圖邏輯】
張三坐於榻沿，李四立於榻前約兩步，兩人面對面。張三在畫面左側，李四在右側。

【鏡頭1】
焦距：50mm 標準，中淺景深
機位：雙人 + 平視正面
構圖：三分法
運鏡：緩慢推鏡
景別：中景
畫面：一名年輕書生猛地從榻上坐起，雙肩後縮；一名鐵灰袍中年男子舉刀立於榻前。
臺詞：{}
視線落點：對方手中的刀
焦點：鎖定年輕書生上半身
穩定性：穩定
音效：被褥摩擦聲

【鏡頭2】
焦距：85mm 長焦，極淺景深
機位：中年男子 + 平視正面
構圖：中心構圖
運鏡：固定鏡頭
景別：近景
畫面：中年男子舉刀不動，下頜繃緊。
臺詞：{逆子！連狀元都敢買，你要江家滿門陪你掉腦袋？}
視線落點：對方面部
焦點：鎖定中年男子面部
穩定性：穩定

<被褥摩擦聲、壓抑的呼吸聲，刀刃細微的金屬顫音>
（低沉鼓點與剋制的弓弦持續音）

視覺風格：<畫風層>

【約束】
1. <video.seedance.prompt 逐句拆成編號>
```

每一行只在有內容時出現：沒填 `sfx` 就沒有「音效：」行，沒有臺詞寫 `臺詞：{}`。`畫面：` 後面括號裡的 `（構圖參考 @圖片N）` 只在這一鏡有分鏡圖時出現；純參考圖出片時沒有它，構圖全靠上面那幾行欄位——這正是它們存在的原因。

## 符號規範（官方規定，程式與門都按這個查）

| 資訊型別 | 符號 | 例 |
| --- | --- | --- |
| 臺詞 | `{}` | 舍友笑著問 {考得怎麼樣呀，過了嗎} |
| 音效 | `<>` | `<遠處傳來狗叫聲>` |
| 音樂 | `（）` | `（背景中播放著快節奏的搖滾樂）` |
| 字幕 | `【】` | **不用**——本管線不要字幕，全域性約束裡禁了 |

- **臺詞逐字進 `{}`**，一個標點都不動；說話人身份、語氣、是否畫外音寫在 `{}` 外面（畫外音寫「以畫外音說」）。不加 `<d>`、語言標籤、`(S1)` 編號
- 小語種臺詞要標註語種：`用日語說道{こんにちは}`
- 音效與音樂由程式從聲景/配樂欄位套上符號，正文裡不重複寫

## 運鏡

直接用標準術語（中景、特寫、全景、緩慢推鏡、平穩橫移、固定鏡頭……）。**一個鏡頭只指定一種運鏡**——官方原話「不要同時要求推拉搖移，會增加畫面的不穩定性」。

## 動作（官方四條，已併入 `shot-writing.md`）

肢體細化 + 程度量化；優先低緩連續小動作；補充動作過渡銜接；情緒具象外化。這些跟協議無關，H3 同樣適用，所以住在共同層。

## 參考圖與主體

- 分鏡路徑傳的是**分鏡圖 + 上一段尾幀**，每張只承擔程式在「素材職責」裡指定的用途
- **不用三檢視 / 多檢視當人物參考**——官方明說會被識別成多個主體，加劇 ID 漂移和「雙胞胎」。人物參考用大頭照 + 全身照，本管線出的分鏡圖本來就是單視角
- 素材總數建議 4–5 個，**不要用滿上限**，多了模型分不清優先順序
- 越需要精準參考的素材越靠前
- 多人同框時全域性約束裡禁雙胞胎：「影片全程禁止出現外形、著裝、配飾完全一致的人物」

## 已知坑（來自官方常見問題）

- **風格漂移**：參考圖寫實而沒寫風格詞，輸出會漂成真人寫實。所以畫風層必須附加，即便是「寫實」也要寫明
- **字幕**：無法 100% 避免，只能降低機率——約束詞「保持無字幕」「避免生成任何文字或字幕」；橫屏出字幕的機率明顯低於豎屏
- **中文發音**：多音字、生僻字易讀錯，臺詞裡可換同音常用字（「螭龍山」→「吃龍山」）
- **片尾噪音**：帶旁白的影片片尾可能有截斷雜音，後期做淡出
