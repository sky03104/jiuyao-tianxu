# 鏡頭正文 · 寫法規範（協議無關）

每一切的正文寫的是**這幾秒發生了什麼**。它跟影片服務無關：同一段正文，發給 MiniMax H3 就套 `h3-prompt.md` 的語法，發給 Seedance 就套 `seedance-prompt.md` 的語法。**協議語法歸那兩份，這一份只管內容。** 兩份協議規範都以本文為前提，不再各自複述。

## 每一切只有一個主運鏡

從 `schema.md` 的 camera 詞表裡選一個，寫進這一切自己的正文裡，寫成自然的動作句（「鏡頭小幅緩推向掐白的指節」），可加幅度（小幅/大幅）與速度（緩/快）。**一切一個運鏡，不疊加**——推完再搖、邊跟邊環繞，模型只會挑一個做，還未必是你要的那個。

## 動作要能在這幾秒內做完

這一切有幾秒，動作就只能是幾秒能做完的事。**遵守 novel-script 的常見動作原則**：挑擔上船、搭手卸擔、抬頭看向岸邊這類模型見過千萬次的動作；精確的物理互動、微表情、手指的細小動作不要寫——寫了也不會被畫對，只會擠掉真正要演的那一下。

**動作怎麼寫**（學自 Seedance 官方指南，對 H3 同樣成立）：

- **肢體細化 + 程度量化**：具體到手、腿、頭、肩背，並帶幅度與速度——「緩慢抬手」「快速轉頭」「用力蹬地」「微微低頭」
- **優先低緩連續的小動作**：緩慢行走、輕輕抬手、順勢坐下；狂奔、大跳、劇烈翻滾這類高爆發動作儘量規避
- **寫出前後動作的承接**：「藉著轉身慣性順勢抬手」「從停頓狀態自然過渡到舉手」，動作才連貫
- **情緒外化成身體細節**，不寫「很悲傷」「非常憤怒」：悲傷是低頭、肩膀微顫、手指攥緊衣角；緊張是頻繁看錶、手指敲桌、眼神閃躲；憤怒是雙拳緊握、下頜繃緊、胸口起伏

## 人物此刻在哪，要和分鏡圖一致

正文裡人物的**位置狀態**（已上船 / 還在岸上 / 在艙內）必須和這一切的分鏡圖一致。圖與文對不上時模型聽圖的，動作就亂。分鏡圖釘的是這一切開始的那一瞬，正文從那一瞬往後寫。

## 臺詞逐字保留，身份寫在臺詞外面

認領的臺詞**一個標點都不許動**，逐字進正文。說話人的身份、年齡段、音色、語氣、是否畫外音寫在臺詞**外面**，不塞進臺詞裡。怎麼標記臺詞（`<d>` 標籤還是中文引號）由協議規範決定，這裡只管「原文不許變」。

## 不寫角色姓名，用通用身份

正文裡寫「一名鐵灰袍中年男子抬頭看向門口」，不寫「張三抬頭看向門口」。

**這是影片服務自己的規範，不是我們的偏好**：MiniMax H3 和 Seedance 的官方提示詞規範都要求
用通用身份指代人物。姓名只許出現在臺詞原文裡（怎麼包住由協議規範決定），臺詞逐字保留，
裡面的稱呼是劇本的事。

注意跟**分鏡圖提示詞**區分開：那一側恰好相反，要直呼其名——分鏡圖是帶著角色設定圖一起生成的，
名字在那裡指的是掛上去的那張參考圖。兩側的規矩不一樣，因為兩側的規範不是同一個人定的。

## 構圖要量化，不能只寫景別

分鏡圖一直在悄悄替正文幹一件事：說清**多近、多滿、誰在哪、眼睛看哪**。純參考圖出片時沒有那張圖，
這些資訊要麼寫成字，要麼就地消失——實測消失的正是它們：景別偏遠、動作偏小、人物擺位隨意。

所以每一鏡除了正文，還要填這幾個欄位（`schema.md`）：

- **焦距 + 景深**（`lens`）：`50mm 標準，中淺景深`、`85mm 長焦，極淺景深`。焦距決定"多近"，景深決定"背景虛不虛"
- **機位**（`cameraPosition`）：對著誰 + 什麼角度。`李四 + 平視正面`、`雙人 + 俯視 30°`
- **構圖**（`composition`）：三分法 / 中心構圖 / 對角線 / 對稱——一鏡一個
- **視線落點**（`eyeline`）：對方面部 / 手中之物 / 閉眼。視線是表演的一半
- **焦點**（`focus`）：鎖定什麼。跟視線落點常常不同：眼睛看對方，焦點在手裡的刀
- **穩定性**（`stability`）：穩定 / 微晃 / 手持。它跟運鏡是兩件事——固定機位也可以微晃

段級再加一條**人物關係與構圖邏輯**（`blocking`）：開場那一瞬誰在畫面左、誰在右、面朝哪、
相距多遠（用釐米或步數）。它是整段的空間地基，各鏡從它出發；只寫一次。

正文（`frame` / 鏡頭正文）照舊寫此刻的動作與狀態，**不再靠形容詞承擔構圖**——
「近景」「特寫」這類詞留給 `size`，「多近」交給 `lens`。

## 參考圖只鎖身份，不鎖構圖

人物、場景、道具的參考圖用來鎖定**身份、臉型、服裝、場景結構、道具造型**。正文不要照搬參考圖的構圖、排版、視角——這一切的構圖由這一切的分鏡圖和正文決定。怎麼在正文裡引用參考圖（`<Picture k>` 還是 `@圖片N`，還是由程式加）由協議規範決定。

## 聲音分三層，各歸各

- **臺詞、歌聲、劇內音樂**（角色聽得見的）→ 寫在鏡頭正文裡
- **環境聲、動作聲、非語言人聲**（喘氣、腳步、銅鈴）→ 聲景欄位，不復述臺詞
- **配樂**（角色聽不見、只有觀眾聽得見）→ 配樂欄位，寫配器與速度；沒有就按協議規範寫「無」

**聲景也是動作指令**：畫面動作改了，聲景必須一起改。聲景裡寫「銅鈴在撞擊時炸響」，影片就真會把撞擊演出來。

## 不寫的東西

- **不新增劇本沒有的**人物、道具、動作、對白、畫面上的可見文字。分鏡是資產合成，不是憑空畫。
- **不寫畫風**。「電影感」「冷灰綠色調」「半寫實」這類是渲染層的事，由呼叫方在出圖/出片時統一附加；寫進正文只會跟當時選的畫風打架。
- **不寫朝代之外的年代詞**。「古代」「古裝」不是畫面；服制、器物、建築形制才是，而這些已經在設定圖裡定了。
