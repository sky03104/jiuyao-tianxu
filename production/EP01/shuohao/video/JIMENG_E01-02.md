## 設定

| 項目 | 值 |
|---|---|
| 功能 | 影片生成 → 選可以放多張參考圖、用 `@` 指定圖片的模式（全能參考／多圖參考），模型選 **Seedance 2.x** |
| 比例 | **9:16** |
| 長度 | **8 秒**（分鏡 7.5 秒；介面沒有 8 就選最接近、不少於 7 秒的） |
| 畫質 | 免費版最高的那檔（720p） |
| 聲音／配樂 | **關**（旁白與音效另外做） |
| 送出前 | 看要扣幾點；超過當天積分就把長度降到 5 秒、刪掉第三鏡那段 |

## 提示詞（整段貼上；`@圖片N` 要用 `@` 從選單點選，變成標籤才算綁定）

```
以 @圖片1 為開場首幀，共三個鏡頭，清晨，天玄院東廊。
主角是一名背著行囊、身穿炭灰色長袍的少年新生，他的臉、髮型、服裝、行囊全程與 @圖片4 的角色設定一致，不換臉、不換裝。

【鏡頭1】參照 @圖片1。中景，鏡頭在他身後略低於肩的高度平穩跟拍，微微手持晃動。他右手攥著入院憑證沿長廊快步往前走，雙腳自然交替、步子一快一慢，途中轉頭看了一眼右側的一排木門。晨光從左側欄杆斜照進來，柱影一道道從他身上滑過。

【鏡頭2】約第 3 秒硬切，參照 @圖片2。全景，固定鏡頭。他迎面朝鏡頭走來，右手握著憑證；兩三名穿學院袍的學生從畫面深處迎面走來，在畫面中段與他錯身而過，之後從畫面下緣走出畫外（路人與他方向相反，不是同向並行）。欄杆外雲海緩緩流動。

【鏡頭3】約第 5 秒硬切，參照 @圖片3。中景，從他右肩後方過肩，鏡頭小幅緩推向門楣旁一塊直立的深色木牌。他停下腳步，抬頭看了一眼木牌，再低頭對照手裡的憑證。木牌上完全沒有字。

畫風：與參考圖一致的高級東方玄幻 3D 動畫電影質感，半寫實、非真人照片、非 2D 動漫。
全片無字幕、無任何文字、無浮水印以外的標示；建築結構與參考圖一致，不扭曲、不融化；人物動作自然，不滑步、不倒著走。
```
