# 九曜天墟EP01 — 角色表

共 5 位角色：玩家、齊衡烈、郁岑燁、厲若楓、蕭曜霖

## 故事摘要

九曜界的天玄院依山而建，通過入門考核的新人以「青嵐新契修」的身份入院。一名沒有背景、也還沒選定流派的新契修拿著入院憑證，被分配到東廊的第七室四人宿舍。門裡住著熱血的刀修齊衡烈、挑剔的劍修郁岑燁與沉默的弓修厲若楓，三人一見面就開始打量這個新室友能不能打。戰技堂教官蕭曜霖的一道集合令，讓他們還沒熟悉彼此，就得一起走上新生演武場。

> 主角 · 剛通過入門考核的普通新契修，拿著入院憑證站在陌生的宿舍門口，連自己能不能打都還說不準。

### 畫像

- **性別**：男（動畫版鎖定；遊戲中可自訂）
- **年齡**：約二十歲的年輕成年人（推斷）
- **身份**：天玄院青嵐新契修，非貴胄、非世家嫡系，尚未確立流派
- 沉靜 / 謹慎 / 觀察型 / 不逞強

**外貌**　中等運動體格，站姿自然但帶一點初來乍到的拘謹。短而蓬鬆的黑髮，幾綹碎髮落在額前；橢圓臉、鼻樑挺直，深棕色眼睛沉靜地打量四周（推斷）。炭灰色交領分層修行袍配暗青內袍、窄袖、寬布腰帶，背上用皮革交叉背帶綁著捲起的行囊；新發的袍子還留著打包時的摺痕（推斷）。腰帶別著統一的學院徽章（青銅章嵌玉石刻紋），除此之外沒有武器與飾物——四人裡唯一沒帶兵器的人。

**性情**　話很少、句子很短，先回答再觀察。被當面打量時不辯解，只把疑問直接問出口；面對教官的命令乾脆應聲。

**動機**　在天玄院站穩腳跟，靠自己一步步累積修行，不靠出身。

**人物弧光**　從拿著入院憑證、被三名舍友打量的陌生新人，到被教官一聲集合推上起跑線，本集只走到起點
