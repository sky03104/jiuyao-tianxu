## 一、改編說明

**一句話核心**　新契修剛踏進天玄院第七室，就被三個性格迥異的舍友當場打量，一句教官的集合令把輕鬆的見面直接推向演武場。

### 保留

| 內容 | 理由 | 原文依據 |
| --- | --- | --- |
| 任務 01 全部 NPC 對白照正史逐字使用 | 遊戲是正史，對白就是角色性格的第一次亮相，一句都不改 | **齊衡烈：**「你就是新來的？」 |
| 開場由天玄院外景推入東廊，玩家持入院憑證站在第七室門口 | 正史開場演出本身就是短影音的建立鏡頭，世界與主角一次交代 | 鏡頭從天玄院外景慢慢推入東廊。其他新生來回穿梭，遠處傳來演武聲。 |
| 蕭曜霖人未到聲先到，截斷明天演武場的約定 | 全集唯一的情緒轉折，輕鬆轉壓力就靠這一句 | **蕭曜霖（門外）：**「不用等明天。」 |
| 玩家反應取選項 A 正常路線 | 線性影片只能走一條路，A 是正史標示的正常路線，也讓玩家在教官面前有一句自己的回應 | A.「知道了。」→正常 |
| 結尾玩家放下行李、畫面定格第七室門牌 | 正史自帶的收尾畫面，門牌就是本集要觀眾記住的名號 | 玩家將新手物品放入房間，畫面短暫定格在第七室門牌。 |

### 砍掉

| 內容 | 理由 |
| --- | --- |
| 玩家反應選項 B、C 及其後續回應 | 互動分支，正史註明三選項不影響劇情；線性影片只取正常路線 |
| 任務完成時厲若楓的明天見 | 緊接在半刻鐘後集合之後，線性觀看會像台詞打架；動畫可以省略、不能改寫，省略不與正史衝突 |
| 系統解鎖與好感度提示 | 遊戲 UI 資訊，不進動畫畫面 |

| 內容 | 對策 |

## 四、分集梗概

### 第 1 集

清晨，依山而建的天玄院雲霧繚繞，鏡頭從學院外景推入東廊，新生來回穿梭，遠處傳來演武聲。玩家握著入院憑證停在第七室門前。門從裡面打開，齊衡烈探頭確認他就是新來的，當場宣稱第七室正缺個能打的；在室內整理佩劍的郁岑燁抬眼拆台，說他根本沒看過新人出手，齊衡烈反說正因如此才要打一場，郁岑燁只回了句無聊。一直站在後方的厲若楓這才開口，點出新人的腳步有點亂；玩家問他們是不是都看得出來，郁岑燁說至少他看得出來。齊衡烈大笑，約好明天演武場見——門外卻先傳來教官蕭曜霖的聲音，說不用等明天。三人同時轉頭，蕭曜霖站在東廊另一端，宣布半刻鐘後新生演武場集合。玩家低頭看了一眼手裡的憑證，應了聲知道了，把行李放進房間，畫面定格在第七室門牌。

- **【鉤子】** 第七室三個舍友一見面就想試新人的身手，這個被說腳步亂的新人到底能不能打
- **【懸念】** 半刻鐘後的新生演武場，教官要考什麼；厲若楓看出的破綻，會不會當場被拆穿
- 場景：S01、S02、S03　人物：C01、C02、C03、C04、C05
- 同框拆解：四名年輕角色只在教官截斷前後給一次群像，其餘拆成單人與雙人：齊衡烈與玩家在門口雙人鏡、郁岑燁室內單人、厲若楓後方單人加玩家腳步插入；蕭曜霖先聲後人，走廊盡頭單人逆光，與四人以過肩鏡頭帶過，不做五人同框
- ⚠️ 預警：人群、手部特寫
