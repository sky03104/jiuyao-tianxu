# 參考圖直接生影片測試（2026-10-07）

咖哩問：別人都是角色圖＋場景圖＋劇本直接生影片，我們為什麼要一格一格出分鏡圖？
可靈 Omni 帳號點數 0（無訂閱、無每日免費點數）、Gemini 為免費版（無 Veo/Flow），所以先用 **Kaggle 免費 GPU 跑開源 Wan2.1 VACE 1.3B** 測試。

- 鏡頭：第 2 場 A05 f2（齊衡烈從裡面拉開門、上下打量机遙、咧嘴拍臂環），約 5 秒、832×480、16fps
- (a) `wan_a_chars`：只給齊衡烈、机遙兩張角色參考
- (b) `wan_b_chars_room`：再加第七室場景參考
- 參考圖：`ref_*.jpg`（從 EP01 已定稿設定圖裁出）；Notebook：`wan_vace_test_LF01.ipynb`；Kaggle kernel `sky03104/jiuyao-wan-vace-test`

看的重點：角色像不像設定圖、動作自不自然、畫風是不是 3D 國漫、跑一段要多久。

## 結果（2026-10-07）：**不可用**

| 版本 | 生成時間（T4） | 結果 |
|---|---|---|
| (a) 角色參考 | 4230 秒（約 70 分） | 一扇亮門在全黑畫面中間，兩人只有門那麼大（佔畫面高度約 1/4），2D 平塗卡通；齊衡烈紅髮、机遙灰衣行囊認得出，但臉沒細節；動作只有齊衡烈伸手搭肩，沒有拉門、打量、拍臂環 |
| (b) 角色＋第七室場景參考 | 4802 秒（約 80 分） | 場景參考沒用上：同樣是黑底中間一扇門，門開了、齊衡烈走出來站到机遙旁邊；人物同樣小、2D 卡通 |

結論：
- 開源 Wan2.1 VACE 1.3B 在 Kaggle 免費 T4 上，5 秒 480p 要 70～80 分鐘，畫質與畫風都遠低於我們的 3D 國漫分鏡圖，**不適合正式製作**（也不適合當動態分鏡）。
- 「角色圖＋場景圖＋劇本直接生影片」這條路要靠商用模型（可靈 Omni、Veo、即夢等）才有可用品質，需要付費點數。
- 維持漫劇式（分鏡圖＋運鏡＋配音），影片只給關鍵鏡；若之後買可靈點數，再用同一鏡（A05 f2）做商用模型對照測試。

## CapCut Seedance 2.5 測試一：分鏡圖當首幀（2026-10-08，咖哩用 CapCut AI Lab 生成）

`capcut_seedance_A12f2_firstframe.mp4`（原檔 1920×1080、30fps、8 秒，左上角有「CapCut Ai」浮水印）；首幀＝已通過的 `storyboard/frames/A12/f2.png`。

| 項目 | 結果 |
|---|---|
| 畫風 | **保持 3D 國漫**，與分鏡圖一致，光線、窗格光影、走廊逆光都穩 |
| 角色 | 齊衡烈紅髮、皮甲，机遙灰衣、亂髮，8 秒內都沒有換臉 |
| 動作 | 齊衡烈回頭用手往後比 → 轉身走出門口、沿走廊走遠；机遙轉頭目送。自然、有重量感 |
| 問題 | 約 2.4～3.2 秒轉身時**大刀變形**：深色刀身一度消失、換成銀色雙刃大劍（道具不連戲）；有浮水印；附帶的環境音很小聲（不用） |
| 可用段 | 0～2.3 秒（回頭比手勢）與 3.2～8 秒（走遠）可剪；剪掉中間或用切鏡蓋過 |

結論：品質遠高於開源 Wan（`wan_*.mp4`），**可以當「關鍵鏡做成影片」的工具**；道具在大動作時會變形，要選動作小、道具不翻轉的鏡頭，或在變形處剪接。

## CapCut Seedance 測試二：角色設定圖＋場景圖直接生影片（2026-10-08）

`capcut_seedance_A05f2_refs.mp4`：CapCut AI 助理用 **seedance2_fast、720p、8 秒**，參考圖＝齊衡烈、机遙、第七室設定圖，提示詞同上方測試二。**原價 8 點／支，這次優惠 0 點**（300 點約可生 37 支）。

| 項目 | 結果 |
|---|---|
| 比例 | **直式 9:16**（提示詞沒寫比例）→ 之後提示詞一定要加「橫式 16:9」 |
| 角色 | **齊衡烈非常像設定圖**：紅亂髮、無袖皮甲、綠玉腰扣、護腕；机遙只有背影＋捲布行囊（沒拍到臉） |
| 動作 | 門從裡面拉開 → 齊衡烈探身、上下打量 → 咧嘴大笑 → 拍右上臂，**照提示詞全部演出來**，表情生動，鏡頭緩慢推近 |
| 場景 | 木格門窗、外廊與樹，風格對；但不完全是第七室設定圖的室內 |
| 聲音 | 模型自己生了一句亂講的中文（辨識為「正好是這样，你应该连派新兵厄海拉」），嘴也跟著動 → 一律靜音換成我們的配音；嘴型不會對上我們的台詞 |
| 偏差 | 齊衡烈偏壯；右上臂赤金臂環沒畫出來 |

結論：**直接生影片可行**，表演比分鏡圖＋運鏡生動很多，日常戲可以改走這條；需要固定構圖、或道具複雜的鏡頭，仍用「已通過分鏡圖當首幀」（測試一）。
