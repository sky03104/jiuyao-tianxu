# LF01 自動出圖執行手冊（給 Codex）

> 對象：**Codex**（ChatGPT 裡能讀寫 GitHub、內建 `$imagegen` 圖像生成的程式代理）。
> 一般 ChatGPT 對話的 GitHub 連接器是**唯讀**，不能把圖存回 repo，所以這份流程要用 Codex 跑。
> 工作佇列：`production/LF01/codex_jobs.json`（由 `tools/lf01_handoff.py` 產生，不要手改）。

## 你的任務

依 `codex_jobs.json` 的 `jobs` 陣列**從頭到尾依序**出圖，每張出完**自己存檔、commit，接著做下一張，不要停下來問人**。

## 每一張的步驟

1. **跳過已完成的**：`out` 路徑的檔案已經存在就跳過。
2. **檢查前置**：`after` 列出的檔案必須都已存在；缺的話代表前面失敗，先跳過這張，全部跑完後再回頭補。
3. **出圖**：用 `$imagegen`，
   - 把 `refs` 列出的 repo 檔案**全部當參考圖附上**（順序＝提示詞裡的 Image 1、2、3…）；
   - 提示詞用 `prompt` 欄位**原文**，不要改寫、不要翻譯、不要刪減；
   - 尺寸用 `size`（設定圖、分鏡圖都是 1536x1024 橫式）。
4. **自我檢查**（不合格就在同一張重畫，最多 3 次）：
   - 畫面裡沒有任何文字、字幕、浮水印、邊框、UI；
   - 分鏡圖是**單一完整畫面**，不是拼貼、不是設定表版面；設定圖則照提示詞的三區版面；
   - 提示詞沒點名的角色沒有出現；點名的角色臉、髮型、服裝、武器和參考設定圖一致；
   - 畫風和參考圖一致（國風仙俠 3D CG），不是寫實照片、不是日式動漫。
5. **存檔**：把選定的那張複製到 `out` 指定的路徑（資料夾不存在就建立），檔名完全照 `out`。
   不要只留在 `~/.codex/generated_images/`。
6. **記錄**：在 `production/LF01/codex_log.md` 追加一行：
   `| 工作 id | out | 重畫次數 | 自我檢查備註 |`
7. **commit**：`git add <out> production/LF01/codex_log.md`，訊息 `LF01: <工作 id>`。
8. 直接做下一張。

## 分支與推送

- 在分支 `claude/video-tool-evaluation-5bqhvg` 上工作（LF01 的檔案都在這個分支）。
- **每做完一個段落（例如 B01 的全部張數）就 push 一次**，避免中斷時遺失。
- 全部做完開一個 PR（或直接 push 到上述分支），標題 `LF01 試片出圖`。

## 額度用完或中斷時

- 圖像生成會比一般對話更快吃掉用量上限。用完了就把目前進度 push 上去，**在 `codex_log.md` 最後寫明停在哪一張**，然後結束。
- 下次重新執行本手冊時，第 1 步會自動跳過已完成的圖，從中斷處接著做。

## 順序說明

1. `phase 1`：4 張新設定圖（江祈璟、聞人澈、赤瞳妖將、陣眼遺跡）。
2. `phase 2`：第 12 場赤瞳妖將戰 17 張（會用到 phase 1 的設定圖）。
3. `phase 3`：第 2 場第七室報到 24 張（只用 EP01 已定稿設定圖）。

設定圖出完**不用等人驗收，直接往下做**；Claude 事後會逐張驗圖，不合格的會標出來請你重畫。

## 不要做的事

- 不要修改 `codex_jobs.json`、`lf01.json`、任何 `docs/` 文件或 EP01 的檔案。
- 不要覆蓋已經存在的圖（除非這份手冊之後明確要求重畫某張）。
- 不要自己改寫劇情、角色設定或提示詞。
