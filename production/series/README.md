## 1. 一集 20 分鐘的結構

| 段落 | 長度 | 說明 |
|---|---|---|
| 前情提要 | 0:30～0:45 | EP02 起才有。旁白配上一集已有的片段，結尾留一句懸念。EP01 改用「世界開場旁白」（`docs/47` 第 3 節）。 |
| 冷開場 | 0:00～1:30 | 可省略。片頭曲之前的一小段戲，用來鉤住觀眾。 |
| 片頭曲 OP | 1:30 | 全系列共用，每季可以換剪接，見 `OP_ED/`。 |
| 正片 | **約 16:00（15:30～16:30）** | 冷開場也算在正片裡。 |
| 片尾曲 ED | 1:20 | 全系列共用。 |
| 下集預告 | 0:20～0:30 | 由一名主要角色畫外配音，畫面用下一集的片段；最後一集改成「全劇終」字卡。 |

**片長由片段秒數加總算出，不用估的**：`clips.json` 裡正片（`part` 為 cold 或 main）的 `dur` 加總要落在 930～990 秒。
第 2 場的經驗是：劇本估 3:20 的戲，實際做出來只有 2:14。改成用片段秒數加總後，估算就是實際片長。

## 4. 劇本格式（`docs/longform/EPxx_SCRIPT.md`）

程式會讀這份劇本來核對台詞，格式要嚴格照下面寫：

```
# EP01〈青嵐試煉〉

## 前情提要
**旁白：**「……」
素材：EP00-S00-00（說明）

## 第 2 場｜天玄院外景 → 東廊 → 第七室｜清晨｜約 2:10
△ 動作描述……
**裴含章：**（翻了一頁名冊）「補錄的。最後一個。」
**机遙（心聲）：**「……」
**蕭曜霖（畫外）：**「不用等明天。」

## 下集預告
**机遙（預告）：**「……」
素材：EP02 第 5 場 妖化青牙狼撲出（片段編號定稿後補）
```

- 台詞一行一句，格式是 `**說話人：**（表演提示，可省）「台詞」`。每行只能有一組「」，台詞裡要引用別的話時用『』。
- 說話人的標記：
  - 心聲寫「（心聲）」，畫外音寫「（畫外）」。
  - 前情提要只能由「旁白」說話；下集預告的說話人要加「（預告）」。這兩種台詞不會出現在片段裡。
- 一個場次就是一個「## 第 N 場」區塊。標題的時長用「約 m:ss」，由片段秒數加總得出。
- `docs/25` 的 ★ 原文台詞可以改，但必須是審查發現邏輯問題，改後標 ★改，並在 review.md 寫明理由（2026-09-27 起動畫是正史，遊戲對照改編）。

## 5. 片段表格式（`production/series/EPxx/clips.json`）

```json
{"episode": "EP01", "title": "青嵐試煉", "clips": [
  {"id": "EP01-S02-07", "part": "main", "scene": "S02", "loc": "L03", "chars": ["C02", "C01"],
   "extras": "", "dur": 12, "mode": "ref", "time": "清晨",
   "setting": "修習室門口，晨光從方格窗斜照進來",
   "staging": "齊衡烈在門內（畫面右），机遙在門外（畫面左）",
   "beats": [
     {"t": [0, 3], "shot": "中景", "action": "門從裡面被拉開，齊衡烈探出半個身子，上下打量机遙",
      "say": [["齊衡烈", "你就是新來的？", "好奇、咧嘴"]]},
     {"t": [3, 5], "shot": "机遙近景", "action": "机遙愣了一下", "say": [["机遙", "應該是。", "拘謹"]]}
   ],
   "camera": "中景與近景交替，鏡頭穩定", "forbid": ["床"],
   "sfx": ["木門吱呀", "遠處演武場呼喝"], "music": "無"}
]}
```

- `part`：可以是 `cold`（冷開場）、`main`（正片）、`op`、`ed`。前情提要和預告重複用其他集的片段，不另外生成。
- `chars`：**最多 3 人**。順序就是上傳的圖1、圖2、圖3，場景圖固定放最後。
- `dur`：4～12 秒，因為 CapCut 的 Seedance 一支最長 12 秒。
- `beats`：要從 0 秒連續排到 `dur`，中間不能有空檔。
- `say` 的格式是 `[說話人, 台詞, 語氣]`。心聲和畫外音也寫進來，程式會改寫成「嘴巴閉著」或「人不在畫面裡」。
- **說話速度**：一個 beat 裡所有台詞的字數 ÷ beat 秒數，不可超過 4.5 字／秒。這條是為了避免第 2 場 v1「配音被加速 1.25 倍硬塞」的問題重演。
- `mode`：
  - `ref`：角色設定圖加場景設定圖直接生影片，日常戲用這個。
  - `firstframe`：先出一張關鍵幀，再以它當首幀生影片。用在大場面、特效、怪物、多人站位複雜的鏡頭，這時要多填一個 `firstframe` 欄，寫關鍵幀的畫面描述。
- `sfx`、`music`：給之後的音效、配樂設計用，不會寫進 Seedance 提示詞。

## 6. Seedance 已驗證的規則（寫片段時就要遵守）

1. 每支最多 3 人。`【角色】` 要寫明確人數，加上「每人只出現一次」。
2. **肢體接觸做不出來**，例如撞人、擁抱、拍肩、扶人、揹人：改成拍單人的反應鏡頭，再加音效和剪接（第 2 場的撞人就是這樣做的）。兵器互砍可以，但要寫清楚是誰的兵器、從哪個方向來。
3. 12 秒長片段加逐秒分鏡、台詞寫完整並註明說話人，對嘴效果最好。
4. 畫面不能有任何文字，木牌、門牌、書頁一律是空白。
5. 外觀固定：
   - 齊衡烈的刀是單刃厚背重刀，不是雙刃直劍。
   - 第七室是沒有床的修習室。
   - 厲若楓是女性。
   - 赤瞳妖將不吼叫、只有紅光。
6. 背景人物寫成「模糊、不看鏡頭、不排隊」。
7. 一個片段只放一個地點。換地點就切到下一個片段。

## 7. 審查流程（每集都要走完）

```
寫分場（docs/48）→ 系列審查（邏輯、揭露上限、前後集連續）→ 改到過關
→ 寫劇本 → script-reviewer 審台詞＋canon-checker 查設定 → 改到過關
→ 寫 clips.json → tools/check.py 程式檢查＋提示詞審查（台詞覆蓋、可生成性）→ 改到過關
→ build_prompts.py 產生提示詞
```

- **過關標準**：沒有「嚴重」或「中」等級的問題，`check.py` 沒有錯誤。
- 同一份東西改了 4 輪還沒過，由 Claude 主持人直接裁定，裁定理由寫進 review.md。
- 審查員提出、需要咖哩才能決定的事（例如改世界觀、改角色身分），寫進 `QUESTIONS.md`，先用預設方案繼續。
