# 03 驗圖手冊

## 負責
咖哩傳回出圖後逐張檢查，決定通過／小修／重出，存檔並記錄。不合格的圖不可拿來當後續參考。

## 檢查清單（每張都過一遍）
1. **比例與尺寸**：長篇 16:9、短影音 9:16、設定圖 3:2。
2. **數量與位置**：照 LAYOUT 逐項數（石柱幾根、人數、左右位置、前後景）。
3. **角色外觀**：對照角色卡與設定圖——髮色髮型、服裝、兵器形制、特徵（額紋、纏布、銅鈴等）。
4. **劇情正確**：誰受傷、誰出手、誰看誰；不能從前一格照抄不該有的東西（例：血痕、衝擊波）。
5. **連戲**：與前後格的光線、場景物件、角色服裝一致。
6. **禁區**：違反 STYLE LOCK（肌肉展示、西方符號如五芒星、字母符文、不該有的顏色）。
7. **不要相信 Gemini 的文字**：它說「已修改」不代表有改；有疑慮就做像素比對（平均差極小＝沒改）。

## 故事版驗圖（多格板）
故事版只驗**構圖與連戲**，不要求細節品質：
- 格數、排列（3×3）、每格是否 16:9、有無文字／編號（有就要重出或裁掉）
- 每格景別、角度、角色站位是否照 SHOT 描述與 LAYOUT
- 同一角色在各格是否同一人（髮型、服裝顏色、兵器）；場景、光線是否前後連得上
- 通過存 `storyboard/boards/<id>.png`，在 README 記一列；個別格子的偏差寫下來，出單格時用 LAYOUT 補正

## 判定
- **通過**：主要項目正確；小偏差寫成「偏差接受」。
- **小修**：一兩個局部錯 → 同對話只改那幾點，或由 Claude 後製（如水平翻轉修左右、修圖去血痕）。
- **重出**：構圖或角色規格錯 → 先修 `lf01.json` 的 LAYOUT／mustLook，再開新對話重出。

## 存檔
- 通過：`production/LF01/storyboard/frames/<段>/fN.png`；後製過的，原圖存 `_rejected/` 並註明。
- 不通過：存 `storyboard/frames/_rejected/`（同一張重複結果可不存，但要記錄）。
- 每張寫一列進 `production/LF01/README.md`「分鏡圖驗圖紀錄」：第幾次、工具、判定、通過理由／偏差接受／不通過原因、經驗。
- 一段完成後更新總覽拼貼（例：`LF01_scene12_contact.jpg`）與 `CLAUDE.md` 進度數字。
