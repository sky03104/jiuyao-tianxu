# 02 分鏡出圖手冊

## 負責
把每一切的畫面規格寫進 `lf01.json`，用程式產生出圖提示詞與參考圖拼貼，交給咖哩在 Gemini 出圖。

## 工具與檔案
- 規格：`production/LF01/lf01.json`（每切 `sec, size, camera, chars, props, frame, lines`，加 `layout`；角色必備外觀寫在 `mustLook`；
  場景光線用 lighting preset，例如第 12 場前段用 `紅霧前兆`）
- 產生交接檔：`LF01_BRANCH=<分支> python3 production/LF01/tools/lf01_handoff.py`
  → `docs/HANDOFF-010_LF01_LONGFORM_TEST.md`、`codex_jobs.json`、參考圖拼貼 `storyboard/chatgpt/<段>/fN-refs.jpg`
  （合併到 main 後把 `LF01_BRANCH` 改回 main 再跑一次）
- 美術最高規範：`docs/MASTER_VISUAL_STYLE_LOCK_V1.0.md`；角色／場景設定圖在 `production/LF01/art/` 與 `production/EP01/shuohao/`

## 寫規格的規則
1. **LAYOUT 段必寫**：物件數量（幾根石柱、幾個人）、位置（左／右／前景／後景）、誰面向哪裡、動作。
   Gemini 對複雜配置守不住，沒寫清楚就會亂。
2. **角色規格寫進 `mustLook`**：容易畫錯的角色（如赤瞳妖將：全身鱗甲、不露肌肉、約兩倍身高、短角脊、無紫色）。
3. **光線連戲**：同一段時間的格子用同一個 lighting preset，不要讓前後格的光源打架（例如光柱出現前不能有光柱）。
4. 規格錯是編劇／分鏡的錯，修 `lf01.json` 再重新產生，不要只在對話裡口頭改提示詞。

## 給咖哩的出圖指示（每次都要講）
- Gemini 用 **Pro** 模型；**每一格開新對話**。
- 只附該格的參考拼貼；同一段的 f2 可以附已通過的 f1，**不要附其他段的圖**（會照抄構圖）。
- 貼**完整提示詞**（不要只給檔名）。
- 同對話修改只適合小修；Flash 修圖常回傳原圖，失敗就換 Pro＋新對話＋把修正寫進 LAYOUT。
