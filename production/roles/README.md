## 流程順序

```
編劇（劇本、台詞）→ 分鏡出圖（每格規格）→ 故事版出圖＋驗構圖 → 單格出圖 → 驗圖
                 ↘ 配音（台詞定稿即可開始，可與出圖並行）
                                      → 剪輯（動態分鏡＋字幕）→ 咖哩看成品
```

## 所有角色共通規則

1. **咖哩是觀眾**：劇情與製作細節由 Claude 決定，做完給成品；只有改動已定案設定（世界觀、角色身分、正史歸屬）、
   或要花錢／改工具分工時才先問（見 `CLAUDE.md`「劇情分工」）。
2. **素材一律進 repo**：出圖、配音、參考稿都 commit；雲端容器重開會清空。
3. **每一切只做一次**：已通過的圖、配音、影片片段，不換工具重做（`production/EP01/shuohao/video/PLAN.md`）。
   要重做必須有明確不合格理由，並記錄。
4. **資料驅動**：段、切、秒數、運鏡、台詞、構圖都寫在 `lf01.json`（各集同名檔），程式從資料產生，不手寫時間軸。
5. **決策寫進文件**：每次裁定、驗圖結果、選用的配音候選，都寫進對應 README／DECISIONS，不只留在對話。
6. **給咖哩東西時給完整內容**：要他去 Gemini 出圖就貼完整提示詞；要他試聽就附檔案，並說清楚要他判斷什麼。
