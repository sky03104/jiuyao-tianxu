# 05 剪輯手冊（動態分鏡）

## 負責
把已通過的分鏡圖、定稿配音、字幕合成動態分鏡（漫劇式：多數格子靜態圖＋運鏡，只有關鍵鏡才做影片），給咖哩看節奏。

## 工具
- `production/LF01/animatic/render_scene12.py`（Python＋ffmpeg）：時間軸全部從 `lf01.json` 與配音清單產生，不手寫。
  - 運鏡：Push In 推近 15%、Tracking 橫移（相鄰兩次方向相反）、Static 極慢微推 4%。
  - 台詞：每切開始後 0.4 秒起依序放、句間 0.35 秒，字幕可跨到下一切（J-cut）；台詞放不下時**自動拉長該切**（尾端留 0.6 秒）。
  - 字幕：ASS，**只放台詞、不標說話人**（咖哩 2026-10-01 裁定），字型文泉驛正黑／Noto CJK；imageio-ffmpeg 沒有 drawtext，一律用 `subtitles=`。
  - 環境音：低頻棕噪暫代，正式配樂另做。
  - `--stills` 只輸出每切第一格，快速檢查。
- 輸出 `LF01_scene12_animatic_vN.mp4`（crf 27，控制在 20MB 左右以便 commit 與傳送）；`cache/`、`stills/` 不進 repo。

## 規則
1. 改時間、運鏡、台詞都改 `lf01.json`／配音清單，再重跑程式；不在剪輯軟體手動對時間。
2. 缺圖或缺配音就停下並列出缺什麼，不用占位素材矇混。
3. 新版本遞增檔名（v1、v2…），舊版保留到咖哩確認新版為止。
4. 影片生成（可靈等）只給關鍵鏡，排程與工具分工看 `production/EP01/shuohao/video/PLAN.md`；每一切只生一次。
