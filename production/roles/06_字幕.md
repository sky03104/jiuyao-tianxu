# 06 字幕與畫面文字手冊

> 2026-10-01 建立（咖哩：「角色工作手冊要加一個字幕」）。字幕由剪輯程式自動產生，本手冊是它的規則；改規則要同步改程式。

## 負責
動態分鏡與成片的中文字幕：文字內容、排版、時間、樣式。之後若出英文或其他語言字幕，也在這裡定規則。

## 來源
- 字幕文字＝`lf01.json` 每切的 `lines`（與 `docs/43` 劇本一致，**繁體**）。配音用簡體只是給 Qwen 唸，字幕不用簡體。
- 時間＝配音檔實際長度：該句配音開始時出現，**對白至少停 1.2 秒、且不短於「講完再加 0.3 秒」；旁白、心聲至少停 1.8 秒、且不短於「講完再加 0.6 秒」**（2026-10-06 起，參考 lemo-opuscar 的閱讀時間規則；它的 1.8 秒規則是給旁白短片的，套在快節奏對白上 44 句有 30 句不合格、會拖慢鬥嘴節奏，所以對白放寬）；遇到下一句字幕就提早收，句與句不重疊。程式會列出被下一句擠到低於規則的字幕，交給剪輯調整停頓。
- 程式：`production/LF01/animatic/render_scene12.py` 的 `sub_text()`（排版）與 ASS 樣式段。

## 規則
1. **只放台詞，不標說話人名字**（咖哩 2026-10-01 裁定）。
2. **一律白字、同一字型**，心聲也不另外上色（咖哩 2026-10-02 裁定，取代 10-01 的「心聲淺藍」）。
3. **畫外音、閃回、心聲、前情提要旁白**：與對白相同白字，不另外標示。
4. **標點**：句中的「，。、；：」改成全形空格；句尾的句號、逗號去掉；「？！……——「」」保留。
5. **一行最多 18 字**，超過就從最靠近中間的空格或問號、驚嘆號斷成兩行；最多兩行，三行以上表示台詞太長，回報編劇拆句。
6. **樣式**：1920×1080 下字級 50、白字黑邊 3、輕陰影、底部置中、離底 60px，字型文泉驛正黑或 Noto Sans CJK TC。
   直式 9:16（短影音）字級與邊距另定，屆時補進本節。
7. 字幕不可遮住畫面重點（角色臉部、關鍵道具）；遇到這種格子，記錄下來給分鏡出圖調整構圖，或把該句字幕移到畫面上方（ASS `\an8`）。
8. 出圖畫面裡的文字（招牌、門牌）一律無字；地名靠後製加的地點卡，人名靠台詞。

## 畫面文字（地點卡）
- 片中**不用旁白**介紹地點（咖哩 2026-10-02 裁定）；換到新場景時，在畫面左下顯示**小字區域名＋大字地點名**（例：「青嵐古林／陣眼遺跡」）。
- 資料寫在 `lf01.json` 該切的 `caption`：`{"top": "青嵐古林", "main": "陣眼遺跡"}`；同一地點只在第一次出現時顯示。
- 顯示 0.5～4.7 秒（**至少停 4 秒**）、淡入淡出；有地點卡的切，台詞等地點卡淡出後才開始，避免和字幕疊在一起。
- **字型由咖哩選定**：候選見 `production/LF01/animatic/字型選擇_畫面文字.jpg`（A 明體粗／B 港式明體／C 古典刻本明體／D 楷書粗／E 手寫楷／F 黑體特粗，皆為 Google Fonts 開源字型、支援繁體）。
  第二批書法候選（2026-10-02，來自 GitHub `jaywcjlove/free-font` 收錄）見 `字型選擇_書法.jpg`：
  G 刻石錄顏體（GPL，王漢宗顏體改）、H 青柳隸書（日本免費字型，商用條款待查）、I 崇羲篆體（中研院，授權待查）、J 字嶼雲遊手書（授權待查）、
  K 霞鶩臻楷（OFL）、L 秋水書體（OFL）、M 王強書法體（方正手跡，商用需授權）、N 演示夏行楷（作者聲明免費商用）；M、N 缺繁體字，以簡體字形代替。
  **商業發行前，選定字型的授權須再確認**（OFL、GPL 用在影片畫面上沒有問題）。
  選定後字型檔放 `production/LF01/fonts/`，檔名填 `lf01.json` 的 `captionStyle.font`。毛筆書法字型（志莽行書、馬善政等）缺繁體字（嵐、陣、遺…），不可用。

## 檢查清單
- [ ] 字幕與 `lf01.json` 台詞逐字一致（只差標點處理）
- [ ] 沒有說話人名字
- [ ] 所有字幕白色同一字型
- [ ] 每行 ≤ 18 字、最多兩行
- [ ] 字幕與配音同步、不重疊、不遮重點
- [ ] 字幕停留時間合規則（程式警告清單為空）
- [ ] 換場景的第一切有地點卡、沒有旁白
