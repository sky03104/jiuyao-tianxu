# 04 配音手冊

## 風格
**大陸國漫配音**（參考《鬥破蒼穹》旁白的氣勢）。台灣腔方向已被咖哩否決。

## 工具
- Qwen3-TTS **VoiceDesign**（`Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign`）：用提示詞設計聲音直接唸，固定亂數種子。
- Qwen3-TTS **Base 照唸**：齊衡烈用 EP01 v1 參考聲音（`production/EP01/shuohao/voice/qwen3tts-v1/ref/C02_齊衡烈.wav`）。
- 在 Kaggle（T4 GPU）跑：筆記本 `production/LF01/voice/qwen3tts_guoman_kaggle_LF01.ipynb`，
  Claude 經 Kaggle API 直推（`SaveKernel` → `GetKernelSessionStatus` → `ListKernelSessionOutput`；Kaggle CLI 不能用）。
  雲端抓不到 Output 檔，筆記本把 MP3 以 `@@MP3 <檔名> <base64>` 印進執行紀錄，回收時解碼；筆記本原始碼上限 1MB（參考音檔用 FLAC 內嵌）。

## 鐵律
1. **提示詞與台詞一律簡體**（opencc t2s）。繁體會變粵語。
2. **同一角色固定種子與提示詞**（`production/LF01/voice/selection.json`）：旁白 s11、机遙 s33、郁岑燁 s22、厲若楓 s11、
   院方執事 s22、江祈璟 s11、赤瞳妖將 s22、蕭曜霖 s11／s33。新句子每句出 3～4 個種子候選，同分優先選定種子。
3. 新角色（例：聞人澈）第一次配音要給咖哩試聽確認，確認後寫進 `selection.json`。
4. 心聲：同角色聲音，做成貼近耳邊、小聲、輕殘響（響度 -19 LUFS）。

## 篩選
- 用 OpenAI `gpt-4o-transcribe`（經代理）逐檔辨識，轉簡體後與原台詞比對相似度；相似度低＝唸錯、漏字或變粵語，淘汰。
- **音高篩選**：全員男聲，候選中位基頻超過 165Hz 多半聽起來像女聲（齊衡烈照唸、非選定種子最常出現），`pick` 自動淘汰；全部偏高時標 ⚠ 重配。
- **語速**：提示詞不要寫「疲憊、不急不躁、低柔」這類會拖慢的詞，戰鬥場景寫「語速正常偏快、干脆、不拖音」（聞人澈第一版太慢的教訓）。
- 辨識只能抓字錯；語氣、音色仍要咖哩聽過才算定稿。
- 回收、辨識、挑選、混音一條龍：`production/LF01/voice/scene12_v2_process.py`（`decode` → `asr` → `pick`）。

## 混音與響度
- 混音鏈：`equalizer=f=110:t=q:w=1:g=5,equalizer=f=3500:t=q:w=1.5:g=2,acompressor=threshold=-20dB:ratio=4:attack=5:release=120:makeup=4,aecho=0.8:0.6:60|120:0.25|0.15`
- 響度：短句單次 loudnorm 會失準 → 先 `apad=pad_dur=2,ebur128` 量出整合響度，再 `volume=(-16-I)dB,alimiter=limit=0.84:level=false`。
- 定稿放 `voice/final/`（或各批次的 `final/`），檔名依劇本順序編號；配音清單的 `file` 指向定稿檔。

## 檢查清單
- [ ] 提示詞、台詞皆簡體
- [ ] 每句至少 3 個候選；辨識相似度都已記錄
- [ ] 沒有粵語、沒有漏字、沒有像女聲的候選（音高 ≤165Hz）
- [ ] 響度一致（台詞 -16、心聲 -19 LUFS）
- [ ] 新角色已請咖哩確認；選用結果寫進 `selection.json` 與 voice README
