## 為什麼用程式動畫

2026-09-27 評估過兩條省錢路線（對話紀錄整理）：

| 路線 | 結論 |
|---|---|
| Higgsfield（Seedance／Kling 等模型的整合平台） | 依額度計算的單價**不比** Seedance 官方 API 便宜；真正省錢的是限時「無限生成」，但只到 720p、排隊較慢、會輪替模型，且 Trustpilot 評價約 3.2、退款條件嚴格。適合 EP01 正片試片抽卡，不適合出成品。若要試，月付即可，不要年繳 |
| Claude 寫程式逐格畫動畫＋程式合成配樂（參考網路流傳的「162 個 Claude 作品指令包」中 C35／C36／C41／C43 的做法） | 幾乎只花 Claude 用量、可重現、可版控。畫不出與角色卡一致的人物，所以**只用在不需要角色一致性的短片**：世界觀科普、編年史、勢力介紹、預告 |

分工原則：**正片**（角色要與定裝稿一致）照 `production/EP01/shuohao/` 流程走參考稿＋影片模型；
**短影音日更**走本資料夾的程式動畫。

## 內容規則

- 劇情只能用 `docs/21` 的**表層認知＋前期官方說法**（例：「九曜脈動異常，導致天墟裂口重新出現」），
  不可揭露中層／長期真相（天墟是被切離的舊界層等），結尾用懸念代替答案。
- 配色照 `docs/MASTER_VISUAL_STYLE_LOCK_V1.0.md` 第七節：深青、墨黑、暗藍、暗棕、暖金、少量朱紅、少量靈力光。
- 不引用任何既有作品名稱或造型（指令包裡「功夫熊貓風」「英雄聯盟」這類提示字眼一律不用）。
- 人物只出現小剪影，不對應特定角色。

## 重新產出

需要 Node 22、Playwright（雲端環境已全域安裝）、ffmpeg、Noto Serif CJK 字型（`apt-get install ffmpeg fonts-noto-cjk`）。

```bash
cd production/shorts/S01_what_is_jiuyao
ln -s "$(npm root -g)" node_modules   # 讓 render.mjs 找得到全域的 playwright（node_modules 不進版控）
node audio.mjs                         # 產生 music.wav（不進版控，可重現）
node render.mjs --stills 2,8,14,20,27.5  # 先看幾張靜態格檢查構圖
node render.mjs                        # 逐格輸出 → S01_what_is_jiuyao.mp4（約 3～4 分鐘）
```

直接用瀏覽器打開 `index.html` 可即時預覽（無聲）。改字幕／秒數只要改 `index.html` 裡的 `SUBS` 與各段時間，
配樂時間點在 `audio.mjs` 開頭註解，兩邊要一起改。
